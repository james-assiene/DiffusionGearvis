GPU Rendering

Cycles can render on a graphics card instead of the processor. A scene renders the same either way; on a supported card it usually renders much faster.

Supported hardware

Cycles runs on NVIDIA cards through CUDA or OptiX, on AMD cards through HIP and on Intel cards through oneAPI. Each Blender build carries kernels for a fixed list of card generations.

  • NVIDIA cards from compute capability 5.0 up are supported through CUDA, and through OptiX with a recent driver, as long as the Blender build has kernels for the card's generation (see below).
  • NVIDIA Blackwell (RTX 50 series, compute capability 12.0) needs Blender 4.4 or later. Earlier builds do not include kernels for these cards.
  • AMD and Intel cards are covered in their own sections (not part of this demo copy).

Configuring

  1. Open Edit › Preferences › System.
  2. Under Cycles Render Devices, choose CUDA or OptiX.
  3. Tick the GPU you want to render with.
  4. In the scene, set Render Properties › Device to GPU Compute.

If the list under Cycles Render Devices is empty, Blender found no card it has kernels for. See the error messages below.

Error messages

Kernel not found

CUDA binary kernel for this graphics card compute capability (X.Y) not found.

This Blender build has no kernel for your card's compute capability. The driver is not the cause, and changing it does not help. Install a Blender version that supports the card (see Supported hardware above).

Out of memory

CUDA error: out of memory

The scene does not fit in the card's memory. Simplify the scene or render with tiling enabled.
