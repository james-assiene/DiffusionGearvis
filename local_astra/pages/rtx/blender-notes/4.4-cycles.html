Blender 4.4: Cycles

GPU rendering

  • Cycles: added support for NVIDIA Blackwell GPUs (RTX 50 series).
  • CUDA and OptiX kernels are now built for compute capability 12.0 as well.
  • The minimum NVIDIA driver for OptiX is unchanged.

Performance

  • Faster scene preparation for large instanced scenes.
  • Lower memory use for textures with tiling enabled.

Fixes

  • Fixed light linking with instanced objects.
