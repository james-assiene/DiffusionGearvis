RTX 5090 not listed in Cycles Render Devices on 4.2.3

Resolved #134001 · Module: Cycles · Type: Report

Report

System: Linux and Windows, NVIDIA driver 572.16, Blender 4.2.3 LTS.

Under Edit › Preferences › System, the device list is empty on both CUDA and OptiX. Rendering on the GPU prints:

CUDA binary kernel for this graphics card compute capability (12.0) not found.

Older cards in the same machine show up as expected.

Cycles module, triage

Confirmed. The card reports compute capability 12.0 and the 4.2 builds were compiled before kernels for it existed.

Cycles module, closing comment

The Blackwell kernels shipped in 4.4.0. They are not in 4.2 builds and will not be added to them. Install Blender 4.4.0 or later, then pick the card under Cycles Render Devices. Closing as resolved.
