## Goal

The model decides when a step is high-stakes, and asks (H-T107). The conductor adds no judgment of its own. It only makes the model's own question binding. If the text the session voices for a step ends a sentence with a question mark, the call drafted in that same step is refused before it can execute or be repaired, and the turn ends with the question voiced. "The text the session voices for a step" means step 1's spoken prefix, or a loop step's voiced text.

The user's answer arrives as an ordinary new turn, with the question in history (H8) and a fresh screen. Nothing is held across turns: no slot, no yes reader, no deadline. Routine steps are untouched.

This task also records the ruling in docs/01 §3, docs/02 §5 and docs/03 Q13. It makes no prompt change (that is T-0107c), no `tools_v1` change and no turn-machine change.

## Acceptance criteria

**Definition.** `asks_user(text: str) -> bool` lives in the new pure module `local_astra/toolcall/ask_first.py`. It returns true iff the text holds a `?` (U+003F or U+FF1F) that is:
- optionally followed by closing quotes or brackets (`"'”’)»`);
- and then followed by one of:
  - optional whitespace and the end of the text;
  - whitespace, an optional opening quote or bracket (`"'“‘(«`), and an uppercase letter (A–Z, À–Þ).

A space before the `?` (French spacing) is allowed. The function is total and deterministic, imports only the stdlib, and never raises.

`ASKED_FIRST_REASON = "asked the user first"`.

1. **The predicate.** Checked against a hand-written oracle.
   - True for:
     - `Shall I place the order for 42.99 euros?`
     - `Send it to Omar? He is in your chats.`
     - `Je passe la commande ?`
     - `Delete the standup event?"`
   - False for:
     - `I will click the Forgot password? link.`
     - `I will click the 'Forgot password?' link.`
     - `""`
     - `Done.`
     - `what? no idea.`
     - `Is it 3?4`
   - `Should I go ahead? (It can't be undone.)` is settled by the test-author against the definition.
   - Hypothesis: the function is total and deterministic.
2. **Step 1 (pass 1).** With a `ToolKit` set and `asks_user(spoken_prefix)` true, `_judge_tool` hands the machine `ToolDraft(status="refused", reason=ASKED_FIRST_REASON)`, whatever the verdict (valid, repairable or refused). The existing rows (R5) then give:
   - no `tool.execute`;
   - no repair request;
   - `tool.cancel(refused)`;
   - the card `refused`, with that reason;
   - the question voiced and stored in history exactly as at BASE;
   - `tool_loop_end == "refused"` when the loop is on.

   The `tool.call` record gains `asked_first: true` and `verdict_status: <original>`, only on these calls.
3. **Loop step k ≥ 2.** The same rule applies to the step's voiced text. The loop ends, and no step k+1 request is sent.
4. **Never in the same turn.** Over the fakes: in any scripted turn where a step's voiced text asks, no `ToolInvocation` reaches the executor after that step's answer text is committed.
5. **Nothing held.**
   - A typed `yes` in the next turn starts an ordinary `llm.start`, whose history holds the question.
   - If the model re-issues the call there, and its own voiced text does not ask, the call executes in dry run as at BASE.

- **Human, 2026-10-19:** the agent must be autonomous ("I don't want it to bother me every 2 seconds"). No confirmation for clicks, typing, Enter or keys. - Orchestrator, 2026-10-19: the re-plan (prompt-led asking plus this same-step backstop; T-0107b measures a candidate sentence; T-0107c adopts it only if the human accepts the result) replaces 84352ca's hold machine.
- Orchestrator, 2026-10-19, on the test-author's report (0939e9b). The R1 sweep found nothing. The bracket form `Should I go ahead? (It can't be undone.)` asks. The readings in the module docstrings are accepted. **Definition widened for a safety backstop** (a spec change to the Definition, applied before implementation):
  - after the `?`, an optional run of `!`, `?`, `.` or `…` may follow (`Pay?!` and `Pay?.` ask);
  - a single space may sit before a closing `»` and after an opening `«` (French guillemet spacing);
  - "whitespace" means `str.isspace()`, so NBSP counts;
  - "uppercase letter" means `str.isupper()` (Ā and Ω count; `×` does not, since it is not a letter).

  Everything else in the definition stands. The byte-identity rows close to the merge range at merge (T-0094).
- **Orchestrator, 2026-10-19, after reviewers A and B (both APPROVE).** Both found that the definition as written misses real questions, which is the unsafe direction. Examples: NBSP before `»` (correct French typography; the call executed in B's probe), `**Shall I pay?**`, `"Shall I pay?".`, `Shall I pay? — Then`, and `?` followed by an emoji. The definition is therefore **replaced** by a simpler rule (a spec change, applied before merge):

  > `asks_user(text)` is true iff some `?` (U+003F or U+FF1F) satisfies both of these:
  > (a) the character right after it is not a letter or digit (`str.isalnum()`), so `3?4` and `pass?word` don't ask;
  > (b) after skipping every following character that is not alphanumeric, one of these holds:
  >   - the end of the text is reached;
  >   - the first alphanumeric character is not lowercase (`not ch.islower()`), so it is uppercase or a digit.
  >
  > The function scans in linear time, which also fixes reviewer A's quadratic case.

  Consequences for the rows. The listed false forms stay false, because each is followed by a lowercase word:
  - `Forgot password? link`
  - `'Forgot password?' link`
  - `what? no idea.`
  - `?! then`
  - `» puis`
  - `« réunion`
  - `? ω`

  These become **true** (now over-refusals, the safe direction): `? × 3`, `?.4`, and a question followed by a numbered list (`Proceed?\n1. Yes`).

  The 3,570-trial re-read must still give 0. Reviewer A's M9 gap is closed by a step-2 version of the `after_end_of_turn` row (test-author). At merge, the byte-identity rows and the `check_section3_status` paragraph check close to a fixed BASE..TIP.
