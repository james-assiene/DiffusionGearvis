## Goal

The census answered T-0007a criterion 12's open questions with real messages. Four message types
arrive on the wire: `Ready` (once, `{'type': 'Ready'}`), `Step` (every 80 ms of audio,
`{'type', 'step_idx', 'prs', 'buffered_pcm'}`, `prs` a 4-vector), `Word`
(`{'type', 'text', 'start_time'}`, seconds, e.g. `0.72`) and **`EndWord`**
(`{'type': 'EndWord', 'stop_time': 1.44}`, seconds — one per word, carrying the *end* of the word
that just arrived). `MoshiSttClient._handle` maps only `Word`/`Step`/`Marker` (ruling A8: total on
purpose until the census), so today: (a) every `EndWord` and the `Ready` become an `SttErrorEvent`
("unknown message") — five error events for a five-word sentence, which on a live session reach the
error path once per word; (b) every `SttWordEvent` has `end_ms == start_ms` because the client
never learns the end (the census's word-events block shows `720 ms .. 720 ms 'one,'`); (c) `stats()`
counts them under `unknown_messages`. T-0032 endpoints on the last word's `end_ms`, so (b) would
make the end-of-turn time the *start* of the last word. This task maps both types and keeps the
"unknown type is loud" rule for everything else.

## Acceptance criteria

1. **`EndWord.stop_time` closes the most recent open word.** After `Word(text, start_time=s)` then
   `EndWord(stop_time=e)`, the emitted `SttWordEvent` carries `start_ms = round(s*1000)`,
   `end_ms = round(e*1000)`, `end_ms >= start_ms`. Delivery rule, decided here: the word event is
   emitted **when its `EndWord` arrives** (a word without an end is not yet a word to the session);
   a `Word` that is followed by another `Word` with no `EndWord` in between is emitted at the second
   word's `start_time` as its end, with `stats()["words_without_end"] += 1`. A trailing open word at
   `Marker` echo or `close()` is emitted with `end_ms = start_ms` and counted the same way — never
   dropped (docs/02 §4 row 6: the flush confirms every word ≤ t_eot was delivered).
2. **An `EndWord` with no open word is counted, not an error.** `stats()["stray_end_words"]`
   increments; no event is emitted.
3. **`Ready` is consumed silently and counted once.** `stats()["ready_seen"]` becomes 1; no error
   event. A second `Ready` on the same connection is *also* just counted (the server restarted its
   stream — the reconnect path already handles the clock base).
4. **Everything else stays loud.** Ruling A8 holds for every other `type`: `_unknown()` still emits
   the error event and increments `unknown_messages`. *Negative:* a message with `type` = `"Word"`
   but no `text`, or `EndWord` with a non-numeric `stop_time`, is still an unknown, not a crash.
5. **The flush ordering contract still holds.** `SttFlushedEvent(t_eot)` is emitted after every
   word whose `end_ms <= t_eot` — including the trailing open word closed at the marker echo
   (criterion 1). The T-0007a contract rows pass unmodified.
6. **`docs/02-architecture.md` §5's STT wire table gains the two rows** (`Ready`, `EndWord`) with
   the real key sets and units from the census; the fake (`tests/fakes/moshi_stt_double.py` /
   `tests/fakes/stt.py`) speaks `EndWord` too (fakes move with the interface, CLAUDE.md). The
   `start_time`/`stop_time` unit is **seconds**; `SttStepEvent` gains nothing (the `prs` vector is
   already carried; its length 4 is recorded for T-0032 criterion 12).

## Rulings

- **A2 (criterion 4).** A malformed `EndWord` is loud and leaves the open word open; the next valid `EndWord` closes it.
- **A3 (criterion 4).** A `Word` without `text` opens no word (there is nothing to emit); a following `EndWord` is a stray.
- **A4 (criterion 5, T-0007a unit rows).** The delivery rule (a word is published when its end arrives) changes the expected event
