# T-0036 — the HUD rehearsal becomes a fast integration test

**Status:** done 2026-09-14 (merged; reviewer APPROVE) · **Blast radius:** low (tests only; one reviewer) · **Depends on:**
T-0028 group A, T-0024, T-0030 (all merged) · **Origin:** the 2026-09-14 HUD rehearsal over fakes
(real page in Chrome against the real `HudServer` and the real `Session`, no GPU, no audio).

## Goal

Nothing in the repo pairs the real page with the real server: page-side modules drive `HudStub`,
server-side modules drive a Python client, and the only crossing module is
`tests/integration/test_hud_live.py`, which is `gpu`-gated, has never been executed, and waits 30 s
on `#state-chip` — an element that does not exist (`hud/index.html` has `id="turn-chip"` and the
`[data-turn-state]` attribute every other page test uses). The rehearsal ran the whole path for the
first time today and it worked; this task lands that rehearsal as a non-gpu integration module so
the next selector typo is caught in the fast lane, and fixes the dead selector.

## Acceptance criteria

1. **The live gate is alive.** `tests/integration/test_hud_live.py` waits on `[data-turn-state]`
   (never `#state-chip`); the selector is one the fast suite also exercises, so a rename breaks
   both.
2. **A crossing module exists and runs without GPU or audio.** A new
   `tests/integration/test_hud_rehearsal.py` (markers `integration` only, `requires_chrome`
   skip like `tests/unit/test_hud_headless.py`) drives the real `hud/` page in headless Chrome
   against the real `HudServer(port=0)` and the real `Session` built on the fakes and recorders in
   `tests/unit/_hud_rig.py`, on wall time. Rows, each asserting from the DOM or the wire:
   (a) handshake — one `astra.hello`, chip reads the server's state, synthetic-capture banner up;
   (b) a `?source=canvas` frame is routed (`routed ≥ 1`, `frames_rejected == 0`);
   (c) one full turn — transcript pane shows the user text, chip shows THINKING while the fake LLM
   is held, two spoken utterances appear, the quiz fixture renders exactly one `<a2ui-surface>`;
   (d) clicking the surface's action yields exactly one `astra.ui.action` and a second turn;
   (e) barge-in — `UserSpeechOnset` mid-utterance strikes exactly the unplayed tail
   (`text-decoration-line: line-through`), the text is never removed;
   (f) closing the browser yields one `ClientDisconnected` after the grace and a fresh page
   reconnects; a `SECRETTHOUGHT…` thought commit appears in no DOM, no wire message and not in
   `turns.jsonl`.
3. **Budget.** The module completes in under 90 s on this box and is skipped, not failed, without
   Chrome. It is not part of `tests/unit`/`tests/contract` (the fast suite stays under its ceiling)
   but runs under `uv run pytest tests/integration -q -m "not gpu"`.
4. **Nothing under `local_astra/` or `hud/` changes.** Defects the module finds are findings for
   T-0037 (hello replay) or T-0033 (page URL), not edits here.
