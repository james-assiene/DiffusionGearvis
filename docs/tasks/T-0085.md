## Goal
The T-0084e native dev run stopped at 9aee66d after 11 cases. On case click-01, cell `native/T4/named/end_projection`, the model wrote a
stray `<channel|>` after its spoken sentence:

    …<channel|>I will click the Sign in button.<channel|><|tool_call>call:click_at{x:488,y:517}<tool_call|>

The router kept the marker in `spoken_prefix`, and T4 continued `spoken_prefix + "<|tool_call>"`. The pinned template's `strip_thinking`
deletes every `<channel|>` in assistant content, so vLLM v0.29.0 (via transformers) refused the request with 400 "final message does not
appear in the chat".

The cc T4 path has the same defect. It never fired, because no stored cc answer contains a stray close: 0 markers in all routed spoken
prefixes of T-0080c and T-0082c.

After this task:
- the router's `spoken_prefix` holds no channel marker in any route kind, so the voice channel never gets one and the T4 continuation
  survives the template;
- the driver refuses, before sending, any T4 continuation the template would change or that carries a structural marker;
- the fake server rejects such continuations as vLLM does;
- a stopped mixed report no longer prints a format winner.

This amends T-0080a criterion 2 and T-0082a criterion 2 (what `spoken_prefix` is), and T-0084 criterion 2's "router unchanged" (that
negative was scoped to T-0084's sub-tasks).

## Acceptance criteria
1. **The spoken prefix is template-clean.** For every `str` and route kind:
   - `<channel|>` and `<|channel>` are not in `r.spoken_prefix`;
   - the tag is found in the scanned text *before* any removal, and the first tag still wins;
   - removing a marker never creates a tag: `<|tool_<channel|>call>` does not route `native`;
   - `r.spoken_prefix` equals the text before the tag (or the whole scanned text for `none`) with only channel markers removed;
   - `TAGS[tag] + draft_call_text + draft_close` is still exactly the scanned text from the tag onward;
   - drafts are untouched;
   - `route` never raises.
2. **Agreement with the template.** A new pure function, `router.template_content(text) -> str`, mirrors the pinned template's rendering
   of assistant string content (`strip_thinking`: delete `<channel|>`, drop from `<|channel>` within each piece, trim).
   - For every `toolcall` route and both tags, `template_content(spoken_prefix + TAGS[tag]) == (spoken_prefix + TAGS[tag]).strip()`.
   - The click-01 text verbatim gives `spoken_prefix == "I will click the Sign in button."`, `tag == "native"`, and the draft unchanged.
3. **Pre-send continuation guard (driver, both formats).** Before any T4 request (routed or picker), with `c = spoken_prefix + tag`, the
   request is **not sent**, and the run stops with `continuation_guard: <reason>` (exit 1, `stopped`, report written), when either holds:
   - (a) `template_content(c) != c.strip()` (`template`);
   - (b) the spoken part contains a structural marker: `<|turn>`, `<turn|>`, `<|channel>`, `<channel|>`, `<|tool_call>`, `<tool_call|>`,
     `<|tool_response>`, `<tool_response|>`, `<|tool>`, `<tool|>`, `<|think|>`, `<bos>` or `<eos>` (`marker`).
   
   The native `prompt_guard: continuation` stays as it is.
4. **The fake rejects what vLLM rejects** (contract row; real side `gpu`). For a `continue_final_message` request, the fake renders as
   transformers does (final content + sentinel, stripped match). If the stripped final content does not appear, it answers 400 with vLLM's
   text, before the script sees the request.
   - The real side asserts the same 400 for the click-01 content.
   - The real side asserts acceptance, with the prompt ending in 48, for the cleaned content.
5. **Stored evidence is consistent.** On the four stored cc artifacts under `logs/` (T-0080c dev and test, T-0082c dev and test), `rescore`
   gives route fields identical to the stored ones, with no refusal, and T-0082a criterion 11's counts are unchanged. On a hand-built row
   with the click-01 text, `rescore` raises `ValueError` naming `spoken_prefix`.
6. **The regression, end to end on the fake.** A scripted mixed run whose native pass 1 is the click-01 text completes with exit 0. Every
   native T4 cell is sent with content `"I will click the Sign in button.<|tool_call>"`, and the fake's prompt ends in 48. A mutant router
   that keeps the marker fails at the driver guard (criterion 3), never at a 400.
7. **A stopped mixed report has no winner.** When `stopped` is non-empty:
   - `format_selection` has `choice` None, `winner` None and a `reason` starting with `stopped`;
   - the markdown prints `format winner: none (run stopped; no decision)`;
   - the step tables are omitted.
8. *Negative:*
   - cc-only reports are byte-identical to main on the four stored artifacts;
   - the cc golden run (`t0084c_cc_golden.json`) is identical;
   - unchanged: `select`, `select_format`'s rule text, `SYSTEM_PROMPT` (`fa5dace3…`), `NATIVE_SYSTEM_PROMPT`, `seed_ids`, `score.py`,
     `native.py`, `tools_v1.json`, `decoding/**`, `plugin/**`, `conductor/**`, `contracts/**`, `thresholds.py`, and every
     `scripts/locked/*.sh`;
   - all stored artifacts, including the 9aee66d partial, are byte-unchanged;
   - the router keeps its import fence;
   - no network.

## Implementation notes
- **Where things live:** the fix is in the router, which also protects the future voice channel. The guard is in the driver, as the
  backstop.
- **Order in `route`:**
  1. strip closed thoughts;
  2. find the first tag;
  3. then clean the spoken part.
  
  Do not touch `_DRAFT_NAME`, `_TERMINAL_CLOSE` or the `</cc>` logic; stdlib only.
- **`template_content` is a mirror.** No jinja2 at runtime; its truth is the oracle test against the pinned template (sha `36e3a42e…`).
- **The guard** is pure and runs before `_post`, on the exact string `pass2_body` appends.
- **Criterion 7** must not change the CLI's exit behaviour or the selection file.
