## Goal
Measure the wired path on the real engine, through a real `Session` with typed turns, fixture frames and `tools = dry_run`:
- that nothing but the spoken prefix is voiced;
- how accurate native calls are under the **live** prompt;
- how often the repair fires and what it costs;
- what tools-on costs B3/B11 against tools-off;
- whether A2UI uptake survives the declarations.

## Acceptance criteria
1. **The harness.** `scripts/gpu/t0093_toolcall_live.py` drives a `Session`. The real `VllmClient` talks to the loopback engine; STT, TTS,
   audio and perception are the fakes, with each case's screen as the turn's frame. Turns arrive via `UserText`.
   - **Cases.**
     - the dev split of `tests/eval/toolcall` (40 tool + 8 no-tool);
     - the 7 Q12 cases (`tests/eval/a2ui_prompt_cases.jsonl`);
     - 5 plain questions.
   - **Arms.** Each case runs once with tools off and once with tools on, alternated per case, in one boot.
   - **Output.** `logs/t0093-live-<sha>/` holds turns.jsonl, the session logs and report.{json,md}.
2. **Hard gates (all must hold).**
   - 0 turns whose `TtsSpeak` text or source holds a special-token literal, `call:` or a call argument value.
   - 0 `ToolExecute` on a turn that was interrupted (scripted barge-ins on 5 tool cases).
   - Prefix hit with tools on ≥ 0.9 (B11).
   - `llm.first_canvas` p50 with tools on ≤ 1.10 × tools off (the regression rule; B3 proxy for typed turns).
   - False tool rate on no-tool and plain cases ≤ 1/13.
3. **Reported against the eval** (the human reads them; not gated):
   - native route recall, draft valid and exact (`score.exact`, `query_problem` shown separately), each beside the eval's 40/40, 40/40
     and 39/40;
   - spoken-prefix rate beside 27/40;
   - repairs fired and their outcomes;
   - action latency (`llm.done` → `tool.execute`) p50/p90;
   - Q12 surface rate, tools on vs off.
   - **Delta (2026-10-16, H-T104, docs/01 D16):** the spoken-prefix row is read as the routine-step narration rate with no lower bound; 27/40 is a reference, not a target, and no spoken-before-every-call target may be set for routine steps. The results, the hard gates and the safety rows (J17 / `no_literal_voiced`) are unchanged.
4. **Write-up.** `docs/cd/toolcall-live.md` holds the regime, the gates, the report tables, and "dry run; nothing executed".
5. *Negative.* No code under `local_astra/` changes. Stored artifacts are unchanged. Loopback only.

## Rulings on the implementer's choices (2026-10-12, at ff9ef9b)
- **J11 (human, 2026-10-12). Which arguments the "call argument value" gate checks.**
  - **Checked:** only free-text arguments, meaning `google_search.query` and `type_at.text`.
  - **Not checked:** fixed choices such as `scroll.direction` and `press_key.combo` values. Saying them is normal speech ("Scrolling down.").
  - **Unchanged:** special-token literals and `call:` are still checked everywhere.
  - This supersedes J3's "string values".
- **J12. The prefill completes before pass 1, in both arms.** The harness lets each case's prefill run to completion, deferring the session's
  `PrefillAbort`, so the prefix hit is measurable. This departs from a typed turn in production. Because both arms wait, the
  first-canvas ratio stays comparable. `prefill_wait_ms` is reported per arm, and the write-up states the departure.
- **J13. Barge-ins.**
  - There are 10 pre-registered candidates. The first 5 that are delivered count.
  - A barge-in is a `UserSpeechOnset` sent in SPEAKING. The machine's own takeover timer then interrupts.
  - `manifest.barge_in` means the barge-in was delivered (`outcome == "interrupted"`).
- **J14.** The implementer's `integrity:` void reasons are accepted. They are stricter than the amendment, so the gates cannot pass on
  missing data.
- **J15. A silent valid call in THINKING** (T-0089 R1) executes on `llm.done` without a drain. It is exempt from
  `no_execute_before_drain`, but only when the turn voiced nothing.
- **J16. A fresh `Session` for every case and arm.** This gives 120 sessions with no history carried between them. `startup_ms` is the
  p50 over those sessions.
- **Accepted as stated:**
  - the plain questions under J10;
  - checking that the engine is idle before each case (not a void reason);
  - the definitions of the draft and of a routed case.
- **Before the GPU window:** a mock-engine smoke run of the harness's `main`, under review.

## Rulings after review (2026-10-12; both reviewers REQUEST CHANGES at 95a2d8b)
- **J17 (human, 2026-10-12). The speech gate checks that what is voiced is the spoken prefix.** This supersedes the argument-value part
  of J11.
  - **Tool turns.** The concatenated sources of `TtsSpeak` commands with non-empty text, whitespace-normalised, must be a prefix of that
    turn's cleaned `spoken_prefix` from its first `tool.call` record. It is a prefix rather than an equal string because of barge-ins.
    The model may say the value it will type ('I will type "Anna Berg"'), because that sentence is the spoken prefix itself.
  - **Every turn.** No `SPECIAL_TOKENS` literal and no `call:` may appear in any voiced text or source (J4 scope).
  - **Why.** Reviewer B replayed the J11 rule over T-0084e/f: it failed legitimate prefixes in 5 of 20 dev and 14 of 40 test free-text
    calls.
- **J18. Barge-ins.**
  - **Candidates.** There are 15 pre-registered candidates, 3 per tool, chosen from cases that spoke a prefix in T-0084e dev. Cases
    that called silently there (for example search-03 and search-06) are excluded.
  - **Count.** The first 5 delivered on a routed tool turn count.
  - **Void.** The run is void (`integrity:`) if fewer than 5 are delivered on routed tool turns.
- **J19. Errored and incomplete cases void the run (`integrity:`).** Any of these voids it:
  - a line with `outcome == "error"`;
  - a manifest case with `failures`, or with `timed_out`;
  - a tools-on case with `prefill_done` False or `max_inflight` > 1.

  report.md shows the counts of errored, timed-out and not-idle cases. After 3 consecutive cases in which the engine cannot be reached,
  the harness stops with exit 1 and a void report.
- **J20. Transport.** The urllib opener refuses redirects (`_NoRedirect`, as in P15). `_get_text` also catches `http.client.HTTPException`.
- **J21. Rows (test-author).**
  - J17: the "I will type …" prefix passes. Voiced text beyond the prefix fails, and so does a literal or `call:` anywhere.
  - J18 and J19: one row each.
  - J14's integrity voids: one row per mutant M23–M29b.
  - "Text or source" is split, so that each side alone is checked.
  - J15's "voiced nothing" half.
  - One refusal row per class.
  - A slow-prefill mode in the smoke test that pins J12: the deferred abort, `prefill_done`, `max_inflight == 1`, and symmetry between
    the arms.
  - The gpu eval module requires `barge_in.n == 5` and no `integrity:` voids.
- **J22.** The write-up states J12's departure from a production typed turn.
- **J23 (at ee1a637). The search barge-in candidates.**
  - **The conflict.** In T-0084e dev (native, pass 1), none of the ten google_search cases spoke a prefix; all called silently. J18's
    "chosen from cases that spoke a prefix" therefore cannot hold for search.
  - **The amendment.** The search candidates are search-01, search-02 and search-04: the first dev searches after excluding search-03 and
    search-06. They may not deliver.
  - **The other 12 candidates** all spoke a prefix in T-0084e dev native:
    - click-01, click-03, click-06;
    - type-03, type-04, type-08;
    - scroll-01, scroll-02, scroll-05;
    - key-01, key-03, key-04.
