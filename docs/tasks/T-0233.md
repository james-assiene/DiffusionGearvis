## Acceptance criteria

**A. Vendored KaTeX and the renderer module**

1. `hud/third_party/katex/` holds exactly:
   - `katex.mjs`, `katex.min.css` and the 20 `fonts/KaTeX_*.woff2` files, byte-identical to `package/dist/` of `katex@0.16.22`;
   - `LICENSE` (verbatim MIT);
   - `PROVENANCE.md`: version, tarball sha512, the sha256 of every file, the fetch date, "no patches", and the font decision.

   No `.woff` or `.ttf`. Total ≤ 950,000 B (0.16.22 measures 893,289 B).
2. `scripts/vendor_katex.py <tarball>` is offline, run with `python -I`, and reads the tarball as data only. It reproduces criterion 1 byte for byte, and refuses a tarball with the wrong sha512.
3. Fonts are woff2 only, all 20 faces. `katex.min.css` is verbatim. Chromium never requests `.woff` or `.ttf` (row C6).
4. NOTICE gains item 8, KaTeX. Every other item is unchanged.
5. `hud/src/math.js` (new) exports:
   - a pure `splitMath(text)` → pieces `{kind: "text"|"math", source, tex?, display?}`, whose `source` pieces concatenate to `text`;
   - `renderMathInto(doc, element, text, {render})`. Text pieces become text nodes. Each math piece goes into a `<span class="math">` (plus `math-display` for display maths), filled by `katex.render(tex, wrapper, OPTIONS)`.

   `OPTIONS` is frozen: `{displayMode, trust: false, throwOnError: false, strict: "ignore", maxSize: 20, maxExpand: 1000, output: "htmlAndMathml"}`, with no `macros` key. Text with no span gives exactly one `textContent` write, as today.
6. The span rule matches T-0224 R-6 (Pandoc `tex_math_dollars` plus `tex_math_single_backslash`):
   - `$$…$$` is display and may span lines.
   - `$…$` is inline only when the opener is followed by a non-space, the closer is preceded by a non-space and not followed by a digit, and there is no newline inside.
   - `\(…\)` is inline and `\[…\]` is display.
   - `\$` is literal.
   - The earliest opener wins, and spans do not nest.
   - An unclosed opener is literal. This matters while text streams in.
   - `$` inside backticks is literal.
   - A span over 2,000 characters, or any span after the 64th, is literal.
7. Fallback: if `katex.render` throws, the span's source, delimiters included, is set as a text node. KaTeX's own `.katex-error` element (from `throwOnError: false`) is accepted.
8. Security. For the hostile inputs below, the DOM has:
   - no `a`, `img`, `script`, `iframe`, `object`, `embed`, `style`, `link`, `use`, `image` or `foreignObject` element;
   - no `href`, `xlink:href`, `src`, `srcset`, `action`, `formaction`, `id` or `on*` attribute;
   - no `url(` in a `style` attribute;
   - no class token taken from the model text.

   Hostile inputs: `\href{javascript:alert(1)}{x}`, `\url{…}`, `\htmlClass/\htmlId/\htmlStyle/\htmlData`, `\includegraphics`, hostile `\color`/`\colorbox`, and raw `<img onerror>` / `</span><script>`. Raw HTML outside a span stays one text node.

   Limits:
   - `\gdef` does not leak into later spans.
   - `\def\a{\a}\a` terminates.
   - `\rule{1000em}{1000em}` is capped at 20em.
   - `\kern-500em` cannot paint outside its wrapper: `.math` is overflow-clipped, and display maths scrolls horizontally.

**B. A2UI Text**

9. A `Text` component renders its spans per criterion 5. Two exceptions stay `textContent`: `flabel` Texts, and Texts inside a `Button` (a gate-made button sends its label back, per the GenUI ruling of 2026-10-17). No other component kind renders maths.
10. T-0164 A7 holds: an identical canvas mutates nothing, and a changed string replaces the element's children once. A Text that streams from `$x^` to `$x^2$` shows literal text, then one `.katex`.
11. Negative: a card with no span renders byte-identically to main. The existing rows in `ui_render.test.mjs`, `ui_cards_v2.test.mjs` and `test_hud_card_parity.py` stay green unedited, except the named A4 amendment.

**C. Conversation pane (assistant utterances as received)**

If a span straddles the cut, the cut moves to the span's start. Sources still concatenate to `utterance.text`, and `[data-unplayed]` still holds the tail.
13. Negative: everything else renders as on main:

    - the thought disclosure and the thinking pane;

    Only `spoken.js` and `ui/render.js` import `math.js`.
14. Negative for the whole task: no file changes under `local_astra/`, `plugin/`, `services/` or `tests/fakes/`, and no new message type. The page loads nothing off loopback.

## Implementation notes

- Use `katex.render` (`createElement`), never `renderToString` plus a markup sink.
- `katex.mjs` touches no `document` at import, so it loads in node.
- Keep T-0030's invariant: unheard text is struck, never removed.
- `hud_static.py` needs no change: Python 3.11 maps `.mjs`, `.woff2` and `.css`, and the server sets no CSP. A future CSP needs `style-src 'unsafe-inline'`.
- `.math` gets `display:inline-block; max-width:100%; overflow:hidden`, and display maths gets `overflow-x:auto`. No `@font-face` in `styles.css` (the T-0056/T-0128 rule).
- Side note (T-0224 gap, out of scope): `\(…\)`/`\[…\]` are voiced raw.
