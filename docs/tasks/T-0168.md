## Goal

`scripts/locked/t0125_search_smoke.sh` refuses on any HEAD that contains `Merge T-0160 group C`, so it can run only at the pre-web commit 298f486d, not at the release. T-0160 C made real websites the default in `--tools live`. With that default, phase 2's Chromium may connect to public hosts through the egress proxy, so the strict connect rule (loopback, resolv.conf nameservers on :53, `ALLOWED_HOSTS` addresses only) no longer holds exactly. After this task:

- phase 2 passes `--no-web`, so the agent browser stays on the loopback start pages and the strict rule is exact again;
- the ancestor refusal becomes a requirement: HEAD must contain `Merge T-0160 group C impl`, so `--no-web` is guaranteed to exist (a removed guard would fail late, at argparse, after phase 1 had already spent GPU time);
- search stays on by default in phase 2 (no `--search` flag), the shipped default;
- phase 2 measures live search with web off. The web path is covered by `scripts/locked/t0160_web_smoke.sh`.
