## Why

T-0226 B (2026-11-02, 39 real pages; PROGRESS Runs): Gearvis invented a mistake on 5 of 15 correct pages. The built-in Education tutor text (T-0225) says "find the line with the mistake", which presupposes there is one.

## Acceptance criteria

**Group A (CPU).**

A1. The `education_tutor` built-in in `hud/src/settings/prompts.js` becomes exactly:

> You are a patient tutor. When I show you my work, check it line by line. If a line is wrong, point to it, explain why, and ask me a guiding question before giving the fix; then give the corrected step and the correct final answer. If everything is right, say so plainly and don't invent a problem. Speak in plain words, not symbols, and keep each reply short.

- It passes `prompt_builder.validate_instructions` and is at most 1000 code points.
- Every other built-in (Default, Gaming companion, Browser specialist), their order and names, the library's storage key, and the Export/Import format are byte-identical.

A2. The T-0226 harness (`scripts/gpu/t0226_real_attempts.py`) changes as follows:
- `QUESTION = "Can you double-check my work?"`.
- Its `TUTOR_INSTRUCTIONS` literal equals the new built-in. The existing equality row against `prompts.js` holds.
- The report note that the built-in text presupposes a mistake (`PRESUPPOSE_NOTE`) is replaced by a note naming the instructions and question in force.
- Nothing else in the harness or its locked wrapper changes: refusals, judge, budget, labels, privacy and the manifest pin are all unchanged.

A3. The T-0226 eval (`tests/eval/test_t0226_real_attempts.py`) checks the tutor text and the question against the values recorded in the run's own report or regime, plus the current literals. This lets it still re-derive the 2789ec90 run (old text) and also the new run.

A4. `docs/tasks/T-0225.md` keeps its historical text. The README's prompt-library paragraph names the built-ins without quoting their text, so it is unchanged. docs/02 gets a one-line T-0229 spec delta.

A5. Negative:
- `local_astra/**`, `hud/src/` other than `settings/prompts.js`, `services/**` and `tests/fakes/**` are byte-identical.
- T-0223's harness, wrapper and tests are byte-identical. Its own short tutor text is a different, historical literal.

**Group B (`/launch`).**

B1. `scripts/locked/t0226_real_attempts.sh <manifest>` is run once at `Merge T-0229-a:` or later, on the same private manifest (sha256 3a8693b9…). Everything else matches T-0226 B: tools off, search off, 1120 visual tokens, lean, n = 1, order seed 0.

B2. The main session hand-audits the run against the same answer key and writes a PROGRESS Runs entry comparing it with T-0226 B (2789ec90). The comparison covers:
- invented mistakes on correct pages (5/15 before);
- right line on mistake pages (10/19 before);
- silent turns (1 before);
- thinking, and the first word.

Counts only, no page content. It is report-only: no bar, n = 1 per page, so differences of a page or two are noise and the entry says so.
