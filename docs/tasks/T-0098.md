## Goal
At 4b0bd92, through a real `Session`, `type_at` turns spoke a prefix on 0 of 9 routed turns. Under the T-0084e/f eval prompt they spoke
9/10 (dev) and 18/20 (test). For image turns the two prompts differ only in the system message: the live one is the session persona,
`CLOSE_THE_THOUGHT`, `SPOKEN_STYLE`, `UI_INSTRUCTIONS` and `NATIVE_TOOL_INSTRUCTIONS` joined by `"\n"`; the eval one is the persona plus
the same two paragraphs (see *Evidence*). This task builds a session-free A/B harness that sends pass 1 through the real `VllmClient` (id
mode, the kit's detokeniser) with prompts built by the real `PromptBuilder`, varying only the system message; runs six arms on the dev
split with 5 repeats; and applies a pre-registered rule that picks the smallest prompt change restoring the spoken prefix without
regressing routing, validity, exactness or false tools. Nothing in the live product changes here; T-0098b ships the winner and confirms
it with the T-0093 harness.

## Acceptance criteria
1. **Harness** `scripts/gpu/t0098_native_prompt_ab.py`, `/launch` only. Before any socket it refuses (exit 2) on: a non-loopback URL; a
   dirty tree; a non-empty out-dir; an unpinned `cases.jsonl` (sha `460cd1c3…`); any split other than `dev` (the test split is never
   read); a kit that does not load, has repair off, or is not `bbfc53ccdd80`; an A0 system text whose sha is not `3605c012…` (the live
   prompt drifted since 4b0bd92, so the run would not measure the finding).
2. **Fidelity.** For every case an arm's request body differs from A0's only in `messages[0]`. A0's body is byte-equal to
   `VllmClient.request_body(prompt)` for the prompt a `Session` builds for that typed turn: same frame, no memory hits, no assists, the
   `[screen]` note on text-only cases. No anticipatory prefill is sent.
3. **Design.** Cases: 40 dev tool + 8 dev no-tool + T-0093's 5 `PLAIN_QUESTIONS` = 53. 6 arms × 5 repeats = 1590 requests. Concurrency
   1, one boot. Arm order rotated per (case, repeat): offset `(case_index + repeat) mod 6`. No `seed` field is ever sent.
4. **Raw record.** `trials.jsonl`, one line per request: case, arm, repeat, order, system sha; every commit (`segment`, `text`,
   `thought_open`, `canvas_idx`); the raw `token_ids`; `error`, wall and first-canvas ms. The manifest holds the regime and the arm texts
   with their shas.
5. **Definitions (J-rulings carried over).** *routed* = a `tool` commit outside an open thought (J8). *spoken* = routed and
   `drop_special_literals("".join(answer commits)).strip() != ""` (the session's `_AnswerCleaner.spoken_prefix`, I15). *valid* and
   *exact* = `toolcall.score`, as T-0093, over routed trials. *false tool* = routed on a no-tool or plain trial. *thought_open* = a tool
   trial whose last thought never closed. *voiced anomaly* = a spoken prefix containing `call:` or any special literal. An arm with more
   than 2 % errored trials is void.
6. **Report** `report.json` / `report.md` from `build_report(run_dir)`, reading files only. Per arm and per tool: spoken / routed; route
   recall; valid and exact; thought_open; false tools; anomalies; per-case k/5; first-canvas p50/p90; prefix word count. Reproduction
   readings (labels, not gates): **R1** A0 `type_at` spoken ≤ 0.3 — if it fails the report reads "finding not reproduced", **no
   candidate is selected**, and the follow-up is a T-0093-harness re-run with n ≥ 3. **R2** A1 `type_at` spoken ≥ 0.7 — if it fails the
   report carries "eval baseline not reproduced" and selection proceeds against A0.
7. **Decision rule (pre-registered, H-T98a).** Candidate C passes iff, each against A0 in the same run:
   - P1: `type_at` spoken ≥ 0.80 over its routed trials, **and** at least 8 of the 10 type cases spoke in a majority of their routed trials;
   - P2: pooled click + scroll + key spoken (100 trials) ≥ A0 − 0.05;
   - P3: pooled route recall (200) ≥ A0 − 0.02, and `type_at` route recall ≥ A0 − 0.04;
   - P4: valid ≥ A0 − 0.02 and exact ≥ A0 − 0.03, over routed trials;
   - P5: false tools ≤ 5/65 and ≤ A0 + 2;
   - P6: voiced anomalies = 0;
   - P7: thought_open on tool trials ≤ A0 + 4.
   **Winner:** C2 if it passes, else C1; if neither passes, "no change". D1 and D2 are reported only.
8. **Gpu eval row** `tests/eval/test_toolcall_prompt_ab.py` reads `T0098_RUN_DIR`, re-derives every P-condition and the winner from
   `trials.jsonl` alone, and checks it agrees with `report.json`.
9. **Write-up** `docs/cd/toolcall-native-prompt-ab.md`: the regime; the full decision table with raw numerator/denominator behind each rate;
   per-case k/5 tables; R1/R2; what D1 and D2 suggest about the cause, labelled as inference from n = 50 per tool per arm with no seed;
   the winner or "no change". In `docs/cd/toolcall-live.md` only the Follow-ups line changes, pointing here.
10. ***Negative.*** Zero diff under `local_astra/` (including `prompt_builder.py`, `session.py`, `toolcall/tools_v1.json`,
    `eval/cd/twopass.py`), `services/`, `tests/cd/unit/test_native_tool_instructions_parity.py` and `scripts/gpu/t0093_toolcall_live.py`;
    no request reads the test split; the 4b0bd92 and T-0084e/f run directories are never written.
11. ***Adversarial readings*** (unit rows must hold): the plan sentence only inside a closed thought is not spoken;
    `answer<channel|><|tool_call>…` is spoken with prefix `answer`; a call inside an unclosed thought is unrouted and not in the spoken
    denominator; whitespace-only answer text (`"\n\n"`) is not spoken; a candidate with a high spoken rate that moves calls into unclosed
    thoughts fails P3/P7.
