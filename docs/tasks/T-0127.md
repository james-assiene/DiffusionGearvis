## Goal

When the model writes a Card with `children`, the user sees the card. The gate repairs it deterministically:
- one id: `child` is that id;
- several ids: the ids are wrapped in a gate-made Column, which is the wrapping the catalog itself prescribes.

Independently of any repair, the gate stops calling an incomplete card clean:
- every component the model wrote and the gate did not emit is named in `problems`;
- every gate call carries a `complete` verdict;
- the turn line gains `ui_complete_final`;
- a turn that ends on an incomplete surface writes a note.

Canvases no repair touches are emitted exactly as today, and a shown partial is never retracted (H-T108 (c)).

A CPU replay of the desk session's `ui` commits becomes the check agents run before asking the human to test at the desk.

## Acceptance criteria

1. **CC, Card children** (`component_repair.py`; a new rule in docs/12 §1.1's set). It applies to a Card that the catalog rejects, that has no string `child`, and whose `children` is non-empty and holds only strings that are neither the Card's own id nor in the reserved namespace.
   - (a) **One distinct id:** set `child` to it and remove `children`. No new id is created.
   - (b) **Several ids (H-T127-1, approved by the human):** set `child` to `__gate_<cardid>_body` and remove `children`. A lifted `{"id":"__gate_<cardid>_body","component":"Column","children":[<ids, order kept, first occurrence>]}` follows the Card.
   - (c) Inline objects in `children` go through LI-style lifting first. An object with no id refuses the repair, and so does a cycle.
   - The repair is all-or-nothing.
2. **The reserved namespace stays closed.** CC adds only the id `__gate_<cardid>_body` and the kind name `Column` on that component, and these are exempt in `_repair_grounded`. A model-written `__gate_` id is never borrowed, duplicated or repaired over. Reserved ids are never resampled.
3. **Losses are named** (a spec delta to T-0010's "pruning is reported only as resample"). `report.problems` gains one line per lost id, giving its kind and the reason:
   - a component written on this canvas, after repair, that is absent from the emitted messages;
   - an id dropped by salvage.

   A dangling reference to an id the model never defined is listed as "reference pruned", which is not a loss. `ok` keeps its meaning: emitted iff it validates.
4. **`GateResult.complete` and `GateResult.lost`.**
   - `lost` is the tuple of lost ids, excluding pruned references.
   - `complete` is true iff all of these hold: a surface was emitted; the accumulated tree holds `root`; every component in the accumulated tree is reachable from `root`; and `lost` is empty.
   - The ui.gate log record gains `complete` and `lost`, and its `problems` is the new list.
5. **Turn line `ui_complete_final`.** It is `None` when nothing was gated, and otherwise the last gated call's `complete`. `ui_valid`, `ui_valid_final` and `ui_shown` are unchanged.
6. **Incomplete final, noted.** When the last call's `complete` is false, `_publish_final_surface` writes one session-log `note`: `{"what": "final ui surface is incomplete", "root": bool, "unreachable": [...], "lost": [...]}`. It holds ids only, never text. The final re-send itself is unchanged (H-T127-4). There is no note when the surface is complete or none was shown.
7. **Restore never overwrites a fresh definition.** `_restore_references` skips ids that arrive on the current canvas. The hand repro ends with the fresh `r3`, and t8's canvas 2 emits 2 messages, not 3.
8. **Desk cases, exact.** Use a fixture copied verbatim from the log. Gate every `ui` commit of each turn in order with a fresh `UiGate` and `final=False`.
   - (a) **Today's behaviour is reproduced byte for byte** with the rules disabled: the emitted messages equal the logged surfaces at seq 3362, 9867, 10745, 6900 and 7808.
   - (b) **After the task:**
     - t5, t6, t8, t9 and the sixth case are `complete`, with every model-written component present (allowing for the documented repair) and every model string present;
     - t3 is **not** complete, because List items and Text variant are out of scope, and `lost` names the two Lists and the Texts the gate dropped;
     - t3's root Card is repaired.
   - (c) **With CC disabled,** every case is incomplete, `lost` names the Card, and `problems` is non-empty.
   - (d) **The sixth case** is located in the log by the test-author.
9. **CPU replay eval** (`scripts/replay_ui_gate.py <session.jsonl>`). It gates each turn's `ui` commits in order and prints, per turn, `turn_id`, `complete`, `lost`, the unreachable ids and the repairs by rule. It exits non-zero if any turn's last call is not complete.
