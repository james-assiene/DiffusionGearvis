## Implementation notes

1. **Vendor findings (read from the bundle, 2026-10-25).** Basic catalog elements extend `BasicCatalogA2uiLitElement`, whose `createRenderRoot()` returns `this` (light DOM). `<a2ui-surface>` uses the default `LitElement` shadow root, so page CSS reaches the components only from inside that shadow root. The bundle's `injectBasicCatalogStyles(targetRoot)` already adopts its own sheet the same way. List items carry `.a2ui-list-item-none`; cards are `.a2ui-card`. The bundle has no `--a2ui-*` property for dividers, row justification or heading weight. Unverified: the shadow root's mode, and the markup Text uses for h3 and caption.
2. **Thread rendering.** The thread is the one owner of conversation DOM. Inside its own slot, a renderer may replace its own children. It must never replace the thread, an article, the card slot or the action list. `renderUtteranceText` and its cut logic are reused unchanged.
3. **Turn attribution.** `turn_id` comes from transcript, spoken, `spoken.played`, `tool.call` and fence messages. A surface's turn is its `surface_id` minus the `turn-` prefix (as `fenceIsAbout` does). No protocol field is added. Unverified: whether every gate prefix is `turn-` (check `local_astra/conductor/ui_gate.py`).
4. **Fixture surfaces.** Pre-T-0127 wire surfaces render as the gate made them then; group C re-gates the turns the UI fixture covers.
5. **Composites.** Render in Chromium or with Pillow from the `vision` extra; no new dependency. Re-render the committed `hud.html` at 1440×900 rather than scaling the 1600 px PNG.
6. **Motion.** The state pill's glyph may animate only as decoration. The reduced-motion block stays last in `styles.css`.
7. **The rehearsal test** reads `[data-ui-surface]` with a singular `querySelector`; with several cards it must address the newest one.
8. **Load-sensitive tests** (`test_bracket_repair` linear-time, the `test_hud_text_mode` ask-box race, and the four in memory): report, do not chase.
