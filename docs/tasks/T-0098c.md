prompt_builder.py:556-560) `type_at` turns speak no prefix: 1/50 in T-0098's A0. Removing `UI_INSTRUCTIONS` (D1) restores 45/50 without
hurting routing, but D1 cannot ship (it removes the shown channel's instructions). This task extends the T-0098 harness with a second arm
table (no copy), adds the 7 Q12 surface cases scored "surface shown" with the real `UiGate` as the session calls it, runs 7 arms on the dev
split with 5 repeats (A0, D1, two diagnostics that bisect the UI block, three candidates), and applies a pre-registered rule: pick the
first candidate, in a fixed order, that restores the spoken `type_at` prefix with no regression in routing, validity, exactness, false tools
**or the UI channel**. Nothing in the product changes; T-0098d ships a winner, if any.
