## Goal
`local_astra/conductor/session.py` stops being a stub and becomes the one place where the merged
pure components are driven: a `Session` that takes **every** service as one of the
`contracts/protocols.py` protocols (LLM, STT, TTS, audio, perception, memory) plus a clock and a
`TurnMachine`, pumps their events into `step(state, event)` in arrival order, executes the
commands that come back, and writes one `TurnRecord` per turn to `turns.jsonl`. Because every
edge is injected, the whole loop runs in the fast suite against `tests/fakes/` with a scripted
clock — the docs/03 §6 e2e shape without hardware — and the same object, handed the real clients,
answers a question on this box with vLLM, Pocket TTS and Kyutai STT up. The deliverable at the end
of this task is a hands-on rung: `scripts/demo/session_rung.py --image shot.png "what is on this
screen?"` speaks an answer through the **production** turn machine, speech gate, prompt builder,
LLM client, filler policy, ui_gate and memory store, and leaves a `turns.jsonl` line carrying its
whole regime. This implements docs/02 §2.2 (the Unmute fork's replacement), the executor half of
§4, §5's protocols and §8's observability.

## Acceptance criteria

Criteria 1–14 are **group A**: they are proved by the fast suite against `tests/fakes/` with the
`VirtualClock`, on any machine, with no GPU, no PipeWire and no network. Criteria 15–20 are
**group B**: they are proved on the 5090 box with the three services up, each run through
`/launch`. Every criterion below is checkable without the implementation existing.

### Group A — the whole session over fakes (fast suite)

1. **Injection is total, and the module cannot reach a service by itself.** `Session` is
   constructed from the six protocol objects, a clock and a `TurnMachine`, and a scripted turn
   completes with the six fakes and nothing else. *Negative (static test over the owned files):*
   no `import httpx`, `websockets`, `sounddevice`, `soundfile` or `socket`; no `http://`/`ws://`
   literal; no default argument that constructs a concrete client. The concrete clients are named
   only in `scripts/demo/session_rung.py` and (later) T-0007b. (docs/02 §5, §9; docs/03 §1.2.)
2. **The command executor is total.** A test enumerates the members of the `Command` union in
   `contracts/commands.py` and asserts each one dispatches to a named executor; a command type
   with no executor fails the test rather than being dropped, and an unknown object raises. This
   is the same guard T-0003 A18 added for `EVENT_TYPES` — it found three rowless event types then.
   *Negative:* executing `LlmAbort`, `TtsCancel` or `PlaybackFlush` twice performs the effect once
   per cause, raises nothing, and emits no second event (`IDEMPOTENT_COMMANDS`, docs/02 §4).
3. **One pump, one clock, time only as `Tick`.** Every producer (STT events, playback events, LLM
   commits, perception events, timers, HUD ingress) is merged into a single queue consumed in
   arrival order by one task; `ArmTimer`/`CancelTimer` are implemented **only** by scheduling the
   session's own tick, with no second timer mechanism; a tick reaches the machine at least every
   50 ms while any timer is armed (the machine's shortest deadline that matters is
   `eot_settle_ms=120`). *Negative:* `local_astra/conductor/turn_machine.py` is **not** in Owned
   files and is byte-identical after this task; nothing in the owned files calls `machine.step`
   from more than one place. (docs/02 §4, `.claude/rules/conductor.md`.)
4. **One speech gate per turn, discarded — never closed — on a barge-in.** The session builds the
   `TurnMachine`'s `segment` callable from a per-turn `SpeechGate` using the adapter shape pinned
   in `tests/unit/test_turn_invariants.py` (assert `gate.pending` is a prefix of the machine's
   unspoken tail, feed only the suffix, never repair the gate's output, `close()` only when the
   machine asks with `final=True`). A new gate is created when a turn opens; the gate of a turn
   cut off by `UserTakeover`/`INTERRUPTED` is dropped **without** `close()`. *Adversarial:* the
   held half-clause of an interrupted answer must never be voiced during the next turn — the
   session-level twin of `test_turn_edges.py::test_a_takeover_discards_the_gates_held_clause…`.
   (T-0004 rulings A5/A9.)
5. **A latched `TtsSpeak(text="")` is skipped, and the turn still ends.** An utterance whose
   normalised `text` is empty (post-EOS / post-`<|think|>` latch, T-0004) is never sent to
   `TtsBackend.speak` and never played. *Adversarial and load-bearing:* an answer whose **every**
   sentence latches to `""` must still return the machine to `IDLE` — the session marks the drain
   so `PlaybackDrained(played_text="")` arrives, because with `llm_done=True`,
   `playback_drained=False` and the `llm_timeout` timer already cancelled the machine has no other
   way out (docs/02 §4 `SPEAKING | playback.drained ∧ llm.done | IDLE`). *Negative:* the skipped
   utterance contributes nothing to `played_text` or to history.
6. **Never voice uncommitted text; never store thinking.** Only `Commit(segment="answer",
   thought_open=False)` of the **live** request id reaches the gate. A property test over
   generated commit scripts (Hypothesis, `--hypothesis-seed=0`) asserts: every `speak(...)` text
   derives from an answer commit of the live request; every `HistoryTurn.assistant_spoken` is
   composed of `TtsSpeak.source` strings actually reported played. *Negative:* a token that
   appeared only in a `thought` segment appears in no `speak` call, no `Episode`, no
   `TurnRecord.extras`, and no `turns.jsonl` line. (CLAUDE.md; docs/02 §4 invariants;
   T-0009's answer-only rule.)
7. **Request ids are unique for the lifetime of the backend object.** Across ≥ 20 turns —
   including turns ended by abort, a `Session` whose machine is re-initialised (`initial()` resets
   `turn_seq` to 0) and concurrent captioner runs — no prefill / generate / caption id is issued
   twice to the same `LlmBackend`. *Adversarial (the bug this criterion exists for):* abort a
   request that has already **finished**, then start the next turn — the next generate must yield
   its commits. A tombstone from the finished abort swallowing the new request is the failure
   (T-0005 B13 finding, recorded in PROGRESS: "T-0007 must make ids unique per turn").
8. **Concurrency guard: one generate + one prefill + one captioner, never more.** A property test
   over `FakeLlm.active` asserts the count never exceeds 3 and that the *generate* count never
   exceeds 1; `PrefillAbort` at end-of-turn and `CaptionerAbort` at onset each call
   `LlmBackend.abort`; `PrefillReissue` is rate-limited by the executor to ≥ 750 ms between
   re-issues for the same turn. (`.claude/rules/conductor.md`; docs/03 I8.)
9. **Frame at onset, prompt layout unchanged, prefix identical to the prefill's.**
   `SnapshotFrame(at_ms)` resolves via `PerceptionClient.get_frame(source, at_ms=onset_ms)` — never
   `latest` — and the resulting `Prompt` is built **once** with `PromptBuilder.prefix(...)`, passed
   to `prefill`, and extended with `full(...)` at `LlmStart`; `prefix.shares_prefix_with(full)`
   holds on the object actually sent. The history-frame `resolve` callback (T-0005 ruling B9) is
   supplied and answers identically for the prefill and the final request. *Negative:* the prefix
   is not rebuilt between prefill and generate, and `thinking` is never toggled per request (the
   whole prefix cache misses on `<|think|>`, CLAUDE.md).
10. **Assists are frozen at turn open and logged per turn.** The turn's `AssistFlags` come from
    `AssistState.freeze()` when the turn opens, travel in the `Prompt`, and reach the record via
    `Regime.with_assists(prompt.assists)` — the only sanctioned setter (its validator rejects a
    badge that disagrees). *Negative:* a toggle that arrives mid-turn does not change that turn's
    prompt or its logged regime; assists remain off by default (T-0012, docs/01 D12a).
11. **Filler bookkeeping: exactly one ack, at most one interim update, no double-play.** The turn
    machine already emits `PlayClip(kind="ack")` at `llm.start` and counts it in
    `fillers_this_turn`; the session calls `filler_policy.decide` **only** for the interim update
    on ticks while THINKING, seeding `fillers_this_turn` and `last_filler_age_ms` from the
    machine's own ack so `decide` cannot return a second `clip:ack`. The **unknown-EMA mapping**
    (T-0013 merged note) is pinned here: when `MachineState.first_canvas_ms is None`, the session
    passes `predicted_first_canvas_ms = FillerPolicyConfig.ack_threshold_ms + 1` — unknown counts
    as slow. *Negative:* `generate_short` is never executed (v1, T-0013 criterion 5); no filler is
    played after the first canvas commits; two ack clips in one turn fails the test.
12. **`turns.jsonl`: one line per turn, whole regime, Q11 fields.** Exactly one `TurnRecord` per
    opened turn, written on the turn-ending row (not on process exit), with: `Regime` filled from
    the active profile, `services/versions.lock`, the git commit and the audio path;
    `outcome ∈ {spoken, interrupted, error, vetoed, silent}`; `spans` drawn only from
    `telemetry/spans.py` (`unknown_spans() == []`); and `extras` carrying **`ui_repairs`**,
    **`ui_resamples`**, **`ui_valid`** (T-0010 ruling A6 named these; criterion C6 is this task's),
    plus `prefix_tokens` and `prefix_tokens_reported`. *Negative:* no line for a turn that never
    opened; no span name added to `spans.py` by this task; no thinking text anywhere in the line.
13. **Errors never kill the loop, and degradation is the machine's decision.** A client that
    raises becomes the corresponding event (`LlmError` with the request id, `SttError`, `TtsError`,
    `ClientDisconnected`); the pump survives, queued events are not lost, and the machine's row
    decides the outcome. With the TTS fake failing, a turn still yields a transcript and the
    session emits `Degrade(text_only)`; with it restored, the next turn speaks (docs/03 I7).
    *Negative:* no `except Exception: pass` that swallows an error without producing an event —
    a test asserts the event is produced for each of the four failure injections.
14. **Barge-in ordering and the played clock.** On `UserSpeechOnset` during SPEAKING, the
    executor's first action is `pause()` on the audio object (no LLM/TTS/HTTP work ahead of it in
    the handler); `TruncateHistoryToPlayed` and `CommitHistory` use the `played_ms`/`played_text`
    the audio module reported. *Negative:* the session never recomputes `played_text` from TTS
    word timings or from what it sent — that is T-0006 criterion 6's, and re-deriving it is how
    history acquires words nobody heard (docs/02 §4 invariant; T-0006 "Seam to session.py").

## Implementation notes
Constraints and known landmines; the design is the implementer's.

- **The machine is pure and is not yours.** No `asyncio`, `time` or I/O may appear in
  `turn_machine.py`; it is not in Owned files. Everything time-shaped happens by feeding `Tick`.
- **The segmenter adapter is policed by the machine.** `_speak` raises `ValueError` when
  `"".join(sources) + remainder != pending`. Feed the gate only the suffix beyond `gate.pending`,
  return its output unmodified, and never "repair" it — a repair here is how uncommitted text
  reaches TTS (T-0003 criterion 10, T-0004 A1).
- **`TtsSpeak.source` vs `.text`.** `source` is the committed substring the §4 invariant is
  checked on and what `play(..., source=…)` must receive; `text` is the normalised rendering that
  goes to `speak()`. Do not swap them, do not send `source` to TTS.
- **Keyword-only `xargs`.** `LlmBackend.generate` declares `*, xargs`; `VllmClient.generate` takes
  it positionally. Call it by keyword so the fake and the real client are both satisfied.
- **`FakeLlm.generate` is an async generator**: `generate(...)` does nothing until the first
  `__anext__`, which is exactly the window barge-in lands in (T-0005 M5). The executor must make
  abort meaningful in that window.
- **Thinking is a session setting** (`Prompt.thinking`, template kwarg). Never per request:
  `<|think|>` is the first system token and toggling it misses the whole prefix cache (CLAUDE.md).
- **`IdleCaptioner(llm, memory)`** takes the concrete store (it needs `next_uncaptioned`), runs
  `run_once()` only after ≥ `IDLE_BEFORE_CAPTION_MS` (10 s) in IDLE, and `abort()` on every onset —
  the session owns the idle clock, the captioner owns no clock (T-0009 A1).
- **`Episode.thumbnail_path` is a path**, so the session writes thumbnails under the data dir
  (`~/.local/share/local_astra/`, docs/02 §9). No task owns a data-dir helper; keep it inside the
  owned files and make the directory configurable so tests use `tmp_path`.
- **`ui_gate`** is per turn: call `gate(raw, turn_id=…, canvas_idx=…, final=…)` with the turn id so
  surface ids are rewritten per turn, only for `segment="ui"` commits, and accumulate
  `repaired`/resample counts for criterion 12.
- **Reflex-lane budget:** nothing in the pump may block the event loop for more than 20 ms
  (`.claude/rules/conductor.md`); LLM and TTS work belongs in tasks, not in the handler.
- **Spans:** use only the names in `telemetry/spans.py`; adding one is a separate change that the
  bench reader must learn about.
- **Loopback:** every endpoint comes from `config.Services`, whose validator already refuses
  non-loopback URLs. Do not accept a URL from anywhere else.
- **`scripts/demo/session_rung.py`** lives under `scripts/demo/` deliberately (T-0016 ruling D5:
  ungated, one review per question is friction). It must not write into `artifacts/` and must not
  claim a measurement; harnesses that measure go to `scripts/gpu/` and need a `/launch` token.
