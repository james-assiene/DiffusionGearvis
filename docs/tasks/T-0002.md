# T-0002 — Protocol contracts + codec round-trip

**Status:** seeded by the scaffold (2026-09-12) · **Blast radius:** medium · **Depends on:** —

## Goal
Every internal event/command and every HUD wire message is a strict Pydantic model in
`local_astra/contracts/`; the HUD codec is total (docs/02 §5, docs/03 §3 "Protocol codecs").

## Acceptance criteria
1. Every event in `EVENT_TYPES`, command in `Command`, and message in `ASTRA_MESSAGE_TYPES` round-trips through JSON via its discriminated-union adapter. *(done: `tests/unit/test_contracts_roundtrip.py`, `tests/contract/test_protocol_codec.py`)*
2. `decode` never raises: unknown `astra.*` → `Unknown`; non-astra → `RealtimeEvent` passthrough re-encoded byte-for-byte equivalent; malformed → `Malformed` with a field path. *(done)*
3. Sampling options outside `{top_k, top_p, max_tokens, stop}` are rejected at construction; plugin args ride under `vllm_xargs`. *(done: `tests/unit/test_llm_options.py`)*
4. Remaining: the OpenAI Realtime subset Unmute actually uses is enumerated (after T-0007 vendors the handler) and gets typed models instead of passthrough.

## Owned files
- local_astra/contracts/**

## Out of scope
Any behaviour — contracts only.

## Evidence required
`uv run pytest tests/unit/test_contracts_roundtrip.py tests/contract/test_protocol_codec.py -q`, `uv run mypy local_astra`.
