# T-0082a — The router strips a closing `</cc>` from the draft; offline re-score of the T-0080c artifacts

**Status:** done (2026-10-09; verified at 5263d55); planned 2026-10-09 · **Blast radius:** medium (one reviewer) · **Branch:** `T-0082a-cc-strip` from `main` (ec9621d) ·

## Goal
The model often closes its tool-call tag. On the T-0080c test split, 33 of the 49 invalid drafts end in `}</cc>`, and the router leaves the
tag in `draft_call_text`. A complete call therefore fails to parse, goes to constrained decoding, and is seeded with text no grammar accepts
(copy 0/48).

After this task:
- the router removes exactly one terminal `</cc>` that follows the call's closing brace, and records what it removed;
- the eval driver scores, derives and seeds from the stripped draft;
- an offline tool re-scores the stored T-0080c artifacts under the new router, with no GPU.

This amends T-0080a criterion 2 ("`draft_call_text` — the text after the tag").

## Acceptance criteria
1. **The strip (H-T80c; amends T-0080a criterion 2).**
   - **When it applies:** the route's tag is `cc` and the text after `<cc>` matches `}\s*</cc>\s*\Z` (Python `re`, `\s` as in `str`).
   - **What it produces:** `Route.draft_call_text` is the text up to `</cc>`. A new field `Route.draft_close: str` holds the removed suffix
     (`</cc>` plus any trailing whitespace).
   - **Otherwise:** `draft_close == ""` and the draft is unchanged.
   - **Limits:** at most one tag is removed, and whitespace before `</cc>` stays in the draft.
   - The strip runs on the scanned text, after closed thoughts are removed.
2. **The amended invariant.**
   - Every route with a tag satisfies `spoken_prefix + TAGS[tag] + draft_call_text + draft_close == scanned`.
   - `kind == "none"` gives `draft_close == ""`.
   - `route` never raises.
3. **Not stripped (guards against a strip that is too wide):**
   - the `native` or `genui` tag;
   - `</cc>` followed by any non-whitespace;
   - `</cc>` not preceded by `}`, for example a truncated `..."text": "a</cc>`;
   - `</cc>` inside a JSON string of a parseable draft.
   
   For `X}</cc></cc>`, only the last tag is removed, so `draft_call_text == "X}</cc>"`.
4. **Monotone.** If `score.parse_call(raw_draft)` succeeds, then `draft_call_text == raw_draft`: the strip never changes a draft that
   already parses.
5. **`draft_name`** is computed from the stripped draft.
6. **Spoken channel.** For `kind == "toolcall"`, `"</cc>"` never appears in `spoken_prefix`.
   - *Negative:* routes of kind `none` are byte-identical to main, including a `spoken_prefix` that holds `</cc>` after a malformed `<cc {`
     (the search-22 shape). This task pins that behaviour; fixing it is T-0083.
7. **The scorer stays strict (negative).** `score.parse_call('{"name": "scroll", "arguments": {"direction": "up"}}</cc>')` still returns
   `ParseFailure("not JSON")`. `local_astra/toolcall/score.py` is byte-identical.
8. **Seeds follow (T-0081b criterion 2 and R2).** `seed_ids` is unchanged.
   - A pass-1 draft ending in `}</cc>` + stop gives a seed whose decoded text contains no `</cc>`.
   - For each thought (T1, T2, T4) and each of the 5 v1 tools, `replay.accepts(compile_toolcall(scope=<tool>, thought=<t>), seed)` accepts
     that seed.
   - The raw seed, built with `</cc>`, is rejected (the control).
9. **Driver rows and report.** Pass-1 rows record `draft_close`. `report()` and `render_markdown` show a line per artifact: drafts with a
   stripped close, k / routed.
   - *Negative:* for every non-seed cell, request bodies, counts and rows (apart from `draft_close` and the draft fields the strip changes)
     are identical to main on the same scripted scenario.
10. **Offline re-score.**
    - **Function:** `twopass.rescore(rows, tools, cases)` returns the rows with each pass-1 row's `route`, `draft_call_text`, `draft_close`,
      `draft_parse`, `draft_call`, `draft_schema_valid` and `draft_exact` recomputed from its stored `text` (current router and scorer).
      Pass-2 rows come back untouched.
    - **Refusal:** it raises `ValueError` if any stored `text` differs from `_decode(token_ids)`, or if re-routing changes `kind`, `tag`,
      `spoken_prefix` or `draft_name`.
    - **CLI:** `scripts/cd_toolcall_rescore.py --evidence-root <dir> --artifact <path> --sha256 <hex> --out-dir <dir>` writes
      `report-rescore.{json,md}`. It contains `draft_only` and `cd_on_invalid:<cell>` / `cd_always:<cell>` for every unseeded cell. Seeded
      cells are listed as *stale (seeds built before the strip)* and excluded from the policy table.
    - **No selection:** `select` is not called.
    - **Refusals, exit 2 with nothing written:** an artifact sha mismatch, an existing out-dir, an artifact with `stopped` set.
    - **Input safety:** every input is opened read-only.
11. **The re-score on the real artifacts (verifier, CPU).** On the pinned T-0080c test artifact (sha `1c69a9c2…`), it must reproduce review
    B's independent counts:
    - 33 drafts stripped;
    - 25 newly schema-valid, 23 newly exact;
    - `draft_only'` schema 52/76 and exact 47/80;
    - no refusal under criterion 10.
    
    On dev (sha `b0fd71cc…`): 10 stripped. A mismatch is investigated, never adjusted.
12. **Negative.** These stay unchanged:
    - `local_astra/toolcall/{score.py,tools.py,tools_v1.json}`, `local_astra/decoding/**`, `local_astra/contracts/**`, `local_astra/conductor/**`,
      `plugin/**`;
    - `local_astra/bench/thresholds.py`, `scripts/locked/t0080_toolcall.sh`, `docs/cd/toolcall-v1.md`;
    - `twopass.SYSTEM_PROMPT` (sha256 `fa5dace3…`);
    - the T-0080c artifacts (byte-identical).
    
    No network.

## Rulings at activation (orchestrator, 2026-10-09, from the test-author's report at 6a5d3b7)
- **A1 (criterion 3's `X}</cc></cc>` example).** The regex in criterion 1 governs. In that string the last `</cc>` follows `>`, not `}`, so
  **nothing is stripped**: the draft stays invalid, and constrained decoding repairs it. The example's stated result was a planning error.
  "At most one tag removed" is pinned by `…}</cc>}</cc>` → `…}</cc>}`. The test-author adds one row for the literal example.
- **A2 (criterion 6 scope).** The property is scoped to answers whose spoken part has no `</cc>` before the first tag (first tag wins,
  T-0080a). Accepted.
- **A3 (API).**
  - `rescore(rows, tools, cases)` takes `cases` as the list of case dicts from `cases.jsonl` and returns rows in input order.
  - `--artifact` is relative to `--evidence-root`.
  - The CLI exposes `main(argv) -> int`, as in `cd_reselect.py`.
- **A4 (CLI JSON).** Only the policy names and a seed-cell "stale" flag are pinned, plus an md `draft_only` line with both k/n rates and the
  word "counterfactual" in the caveat. The CLI must not call `select`, so it cannot use `twopass.report()` as it is; it builds the table from
  `derive`.
- **A5 (criterion 9).** "Identical to main" is tested as identical to the tag-free run on this branch; the unedited full-run rows pin main.
- **A6.** A `rescore` `ValueError` reached through the CLI is a refusal: exit 2, a `REFUSED:` message, nothing written. The test-author adds a
  row.
