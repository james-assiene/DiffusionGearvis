## Acceptance criteria

**A1. Reuse, read-only.** T-0211's harness is imported by path under a fixed `sys.modules` name as `A`. Turns run through `A.C._one_turn(run, hid, arm, repeat, search_kit=nosearch_kit)` unchanged (`A.C` is T-0208's harness; one copy). Reused unchanged: `A.C.run_probes` (P1–P3), `A.C.probe_ph1`, `A.C.probe_ph2`, `A.C.probe_verdicts` (P-H3 with T-0211 A1's switch rule), `A.C.arm_counts`, `build_report`'s audit, `step1_action`; `A.used_browser`, `A.no_browser_claim`. No attribute of `A`, `A.C` or `A.D` is assigned. `scripts/gpu/t0208_handoff_run.py`, `scripts/gpu/t0211_guidance_ab.py` and `scripts/gpu/t0205_demo_run.py` must equal literal git blob shas pinned at implementation time; a mismatch is exit 2.

**A2. The no-search kit.** `nosearch_kit(kit)` returns `dataclasses.replace(kit, tools=…, tools_version=…, tool_set=…)` from a reference kit built once by `cli.load_tool_kit(lean, search=False, **opts)` (`opts` = cli's live options, T-0211's `A.kit_options`). `search` and `web_search` stay `None`; every other field, the executor included, is the turn's own. It raises unless `"google_search" not in tool_set.names`, `tool_set.names` equals the on-set's names minus `google_search` in order, and `tools_version` is the sha256 of `cli._NOSEARCH_PATHS[(overview, wait)]` and differs from `D.cli_kit_sha256(overview, wait)` (T-0215 criteria 1, 2).

**A3. P-A, before any socket.** `D.session_keywords(lean)["tool_guidance"] == cli._tool_guidance("v3", True, wait, search=False)`; that text has no `google_search`; guidance resolves to v3. Otherwise exit 2. `manifest.json` records both shas, the declared names, the guidance sha256 and `search: false`.

**A4. Refusals (exit 2, before any socket).** Everything `A.C.main` refuses before its engine check; an existing `logs/t0220-handoff-nosearch-<sha7>/`; no `Merge T-0215:` merge reachable from HEAD (a branch merge does not count); A1's pins; A2 or A3 failing. No engine or no prefix-cache counters: exit 1.

**A5. Run shape.** `A.C.order(0)`: 18 turns; concurrency 1, 300 s per turn, no engine seed; fresh server, executor, Session and HUD per turn. `HARD_LIMIT_S = 30*60`, `RUN_BUDGET_S = 22*60`; a turn starts only if `elapsed + 480 + 60 <= HARD_LIMIT_S`. After `G.ERRORED_STOP` consecutive errored turns the run stops. A raised turn is `A.C._not_run`'s line, counted errored, never dropped. A stop still writes the report, labelled `incomplete`.

**A6. Withdrawal evidence per turn, from the session log read after the rig exits** (T-0215 R-3). The run is `void` if any fails:
- (a) every `llm.request` record's `data.prompt.tools` declares exactly the reference names, none `google_search`;
- (b) no system-message text of any request contains `google_search`;
- (c) the raw session-log text contains `SEARCH_NOT_CONNECTED` zero times;
- (d) the trial's `tools_version` equals the no-search sha;
- (e) the turn line's `Regime.tools` carries its sha12 (T-0215 R-2).

`google_search` call attempts are counted as `undeclared_search_calls` (each should end `refused`); an executed one makes the run `void`.
