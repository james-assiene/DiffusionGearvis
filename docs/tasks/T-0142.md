## Goal

**Evidence (planner, read-only, from both A/B log directories; re-derived by the test-author's eval row):**
- **T-0134 at e59aa69:** 6 of 874 non-prefill requests collapsed (arm A 0, B 4, C 2), all of them step requests:
  - B S5#8, B S5#2, B S5#9 and B S5#1;
  - C S2#10, and C S2#15, which timed out after 19 canvases ("the. the. …", then dots), made arm C ineligible, and turned the A/B into `inconclusive`;
  - the other five ran to `llm.done` with only thought commits, and the turn ended `final` with no spoken answer: only the step-1 preamble was voiced;
  - 3 of the 6 still scored success, because the cart was already right.
- **T-0132 at 2ccff41:** 4 of 1,178 collapsed: 2 step requests (S5#6, S1#5) and 2 ReGround pass-2 requests (S5#8, S5#6).
- **Shape:** the committed thought text degenerates into a 1–3 token unit repeated back to back (`the`, `the.`, `the to`, `, the`), and from there into runs of dots.
- **Margin:** with a rule of "unit ≤ 3 tokens repeated ≥ 12 times, or one character run ≥ 64", all 10 requests trip at thought commit 2–4 of 3–19. Over the other 1,976 requests that had thought commits:
  - the longest back-to-back repeat of any ≤3-token unit is 2;
  - the longest single-character run is 8.

  Tokens here are `re.findall(r"\w+|[^\w\s]+", text.casefold())`.
- The A-vs-B/C split (0 vs 6) is not evidence about the label (Fisher p ≈ 0.18). T-0140's A/B reports collapses per arm.

**What changes:** the session watches each request's committed thought text, never drafts. When it trips, the session:
- aborts the engine request;
- discards anything that request commits afterwards;
- logs a `note`;
- ends the turn through the existing `LlmError` path, the way the loop's `over_budget` end does (T-0114).

A collapsed step costs 2–4 canvases instead of 19 plus a 20 s timeout, and a locked A/B can no longer be voided by it. A ReGround pass-2 collapse falls back on pass 2's existing failure path.

## Acceptance criteria

**A1. The pure detector: `local_astra/conductor/degeneracy.py`.**
- `degenerate(text: str) -> Trip | None`, pure and stdlib-only. `Trip` is a frozen dataclass: `unit: str`, `repeats: int` and `kind: Literal["ngram", "char_run"]`.
- Constants: `MAX_UNIT_TOKENS = 3`, `MIN_REPEATS = 8`, `MIN_CHAR_RUN = 64`.
- Tokens are `re.findall(r"\w+|[^\w\s]+", text.casefold())`.
- It trips when some unit of 1–`MAX_UNIT_TOKENS` tokens occurs at least `MIN_REPEATS` times back to back, or when one non-whitespace character occurs at least `MIN_CHAR_RUN` times in a row.
- It is evaluated on the request's whole committed thought text so far, the concatenation across canvases, so a collapse that straddles a canvas boundary trips.

**A2. Replay gate: `scripts/replay_degeneracy.py <log-dir>...`** (CPU, read-only, the T-0127 pattern).
- Per request, it prints `tripped`/`clean` with the commit index at which the detector first trips.
- It exits non-zero if any request trips, unless `--expect N` is given and matches.
- Over the two log directories it reports exactly the 10 requests above as tripped, each at or before the commit where the K = 12 rule trips, and 0 others.

**A3. Session wiring (`Session(..., degeneracy_guard: bool = False)`).** With the guard on, for every request whose stream carries `Commit(segment="thought")`:
- the generate, every tool-loop step, ReGround pass 2, and the captioner if it thinks;
- prefill excluded: it commits nothing.

On a trip, in this order:
1. One `note`: `{"what": "degenerate thought: request aborted", "request_id", "attempt_id", "canvas_idx", "unit", "repeats", "kind"}`.
2. The engine request is aborted through the existing `llm.abort` path.
3. Every later commit and `llm.done` of that attempt is dropped and logged as dropped. None reaches the turn machine, TTS, history or the HUD.
4. **Generate or tool-step request:** `turn.tool_loop_end = "degenerate"` when a loop is on, and `E.LlmError(request_id=machine_id, message=DEGENERATE_MESSAGE)` is submitted. `DEGENERATE_MESSAGE` is a module constant.
5. **ReGround pass 2:** the outcome is pass 2's existing failure outcome. Pass 1's call is judged exactly as when pass 2 times out today. Nothing else changes.

**A4. Never spoken.**
- No `TtsSpeak` is caused by a trip.
- An answer commit that arrives after the trip from the same attempt is never voiced.
- No fixed or "stuck" phrase is added (the speaking policy; stuck speech is T-0137's).
- History stores only what was already spoken.

**A5. Logging.** With the guard on, every turn line gains `degeneracy_guard: {"on": true, "tripped": <n requests>}`. With it off, no key is added. There is no new span and no new log kind.

**A6. cli.** `_build_graph` passes `degeneracy_guard=True` in every mode. There is no flag or profile key (ruling R-n).

**A7. Docs.** One `docs/02-architecture.md` §5 paragraph, `**Spec delta (T-0142`, stating:
- the rule and its constants;
- that it judges committed thought only;
- the abort-and-end behaviour;
- the pass-2 fallback;
- that there is no retry;
- the evidence counts.

**A8. Negative.**
- With `degeneracy_guard=False`, these are byte-identical to BASE in every mode: request bodies, turn lines, session-log records and the `machine.events()` sequence (the T-0134 differential harness, imported).
- With the guard on and no trip, the same holds except for the A5 key.
- The detector never sees draft or canvas text, only `Commit` text.
- These are byte-identical over the closed range: `turn_machine.py`, `speech_gate.py`, `llm_client.py`, `contracts/**`, `tests/fakes/**`, `prompt_builder.py`, `toolcall/**`, `computer/**`, `services/**`.
- The docs/02 §4 invariants are unchanged, and none is weakened.

## Implementation notes

- **The `over_budget` end (session.py around the tool-step builder) is the precedent:** a `tool_loop_end` value, a `note`, then `E.LlmError` for the machine id. Reuse it. The turn machine already handles `LlmError` on the active generate.
- **Abort before submitting the error**, so the fake's abort record precedes the error. Use the existing `_safely(self.llm.abort(engine_id), "llm.abort")`.
- **The guard is per attempt.** A T-0135 recovery or a repair is a different request, judged on its own text.
- **No retry (H-T142-1).** A retry would be an extra unmeasured request whose sample is unseeded. The evidence says the turn is already lost in 5 of 6 cases, as silence.
- **Never "fix" a collapse by editing text.** The guard only stops.
- The implementer never edits `tests/`. No heredocs. Never export `GIT_DIR`.
