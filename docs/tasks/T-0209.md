## Goal

Two demo scenarios for an RTX 5090 audience, both starting from the user's shared screen. Each has loopback copies with a pure judge (A1/A2), a GPU measurement (B), a real-site rehearsal (C) and a desk check (D).

- **R1, the priority.** The user shares a Blender error and asks "why is Blender doing this?". Gearvis reads the error off the shared image and searches it with `google_search`. It opens the source pages and cross-checks the version notes. It answers with the specific fix, the exact setting to change and a source. Nothing is bought, nothing is irreversible.
- **R2.** The user shares `nvidia-smi` and asks for "a coding model I can run on this card with 32k context". Gearvis browses Hugging Face, opens a model's Files page and compares quant sizes against the VRAM plus the KV cache at 32k. It names one file, its size and the reasoning. It never downloads.

The known failure this task targets is the one from T-0205 D, where D2 and D8 answered from search snippets without opening a page. Both judges here fail an answer that opened no source page (note `no_page_opened`). In R1 the top search snippet is a wrong forum answer.

**How search works on loopback (H-T209-1):** through the real `google_search` tool.
- The Session gets a pure in-package index, `LoopbackSearch` (`pages/rtx_search.py`), as `ToolKit.search`, with `web_search="ddgs"`. The tools and the prompt are then the live search-on ones.
- Results carry real-looking `https://` URLs.
- The model opens a result the live way: Ctrl+L opens the start page, it types the address, Enter.
- The rtx root's `/web.html` is a stand-in for the live start page. It maps those addresses to loopback paths through a pinned `ROUTES` table.
- No byte leaves loopback.

**What does not change:**
- One image source per step.
- No typing into div or canvas; every text field is a real `<input>`.
- No downloads or uploads, no sign-in, no card or password typed.
- The egress proxy is the only path to real sites (C). Search stays a scoped exception (C only; A and B use the loopback index).
- Session, executor, cli, config, prompt, guidance, labels, turn machine and contracts are untouched. So are `pages/server.py`, `pages/static/**`, `pages/scenarios/**`, `scenario_tasks.py`, `pages/handoff*` and `search/**`.
