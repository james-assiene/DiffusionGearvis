## Goal

While the model thinks, the always-visible Thinking pane shows the real per-step canvases of the request being denoised, from the T-0011 tap (ZeroMQ PUB on `tcp://127.0.0.1:8002`, two-part `[b"astra.canvas.step", msgpack(dict)]`, ≤ 30 Hz per request). The conductor gets a loopback-only, never-blocking subscriber that admits frames only for requests starting while a turn is open, coalesces them, and publishes them unchanged as `astra.canvas.step` through the HUD transport, where canvas frames are droppable and never cost a connection. The page draws a 32-column grid on a `<canvas>` in `[data-denoise-root]`, matching the mockup's Thinking pane, labelled `canvas k · step s/N`. Cell states come only from received frames (noise, kept, stable, revised, committed); nothing is drawn before the first real frame; nothing is interpolated or synthesised. The plugin, the turn machine, the LLM client and the speech path do not change.

## Acceptance criteria

### Group A — the conductor relay (`local_astra/conductor/canvas_relay.py`)

A1. **Loopback only.** Endpoint `ASTRA_TAP_ENDPOINT`, default `tcp://127.0.0.1:8002` (= `services/versions.lock` `[plugin] tap_endpoint`). Only `tcp://127.0.0.1:<port>` or `ipc://…` are accepted; anything else (`0.0.0.0`, `*`, `localhost.evil`, `127.0.0.1.nip.io`, a routable IP, `epgm://`, empty) raises `ValueError` before any socket exists. A SUB that `connect`s, never `bind`s.

A2. **Real frames only, unchanged.** Every published `astra.canvas.step` equals, field for field, one payload received and validated as `AstraCanvasStep`. Invalid payloads are counted, never published. The relay creates no frame, `request_id`, step or `astra.canvas.synthetic`. *(Amended by T-0159 A3, 2026-10-26: unchanged except `argmax_pieces`/`committed_pieces`, which the relay adds from the frame's own ids.)*

A3. **Order and coalescing.** Per request, received order is kept. Denoise frames are latest-wins per request, flushed at ≤ 30 Hz per request on the injected session clock, aggregate ≤ 60 msgs/s. Commit frames are never coalesced away; a pending denoise frame of canvas ≤ k is discarded when commit k arrives and is never published after it.

A4. **Admission by turn state.** A request id whose first frame arrives while `session.turn_state_message().state` is IDLE is refused for its lifetime (the idle captioner). A request id first seen in any other state is admitted and stays admitted after IDLE (its final commit still arrives). Both tables bounded (LRU ≤ 64).

A5. **Never stalls the turn.** No blocking call on the event loop; receive HWM ≤ 256. With the relay attached, a fake turn's spoken output and turn record are byte-identical to the same turn without it. A silent port publishes nothing and costs nothing. Engine restarts are survived by ZeroMQ's reconnect.

A6. **Canvas frames are droppable in the HUD transport.** `Outbox.offer` never closes a connection because of an `astra.canvas.*` message; at most 8 canvas messages queued per connection; a newer denoise frame of the same request replaces a queued one; overflow counted in `Outbox.dropped`; a non-canvas message is never refused because canvas frames filled the queue; `TurnJournal` still ignores `astra.canvas.*`. Spoken lines are still never dropped.

A7. **Compact session-log row.** The `wire.out` of an `astra.canvas.step` carries `{type, request_id, canvas_idx, step, max_steps, phase, canvas_length, n_committed, n_kept, n_stable}`; every other type's `wire.out` is unchanged. One `note` per closed turn: `{denoise: {turn_id, request_ids, received, published, coalesced, refused_idle, invalid}}`. *(Amended by T-0159 A3, 2026-10-26: the note also carries `undecoded`; the `wire.out` row stays without text.)*

A8. **Says when it is off.** If the relay cannot start (pyzmq missing, endpoint refused), `astra session` prints one stderr line naming the reason, the session log records a `note`, and the session runs without it. If a turn closes with zero tap frames received since the session started, one `astra.error(code="denoise_no_tap", …)` per session.

A9. **pyzmq is a core dependency.** `uv.lock` re-resolves with no new package.

A10. **Negative.** Byte-identical to the branch base: `plugin/**`, `local_astra/conductor/turn_machine.py`, `local_astra/conductor/session.py`, `local_astra/conductor/speech_gate.py`, `local_astra/conductor/llm_client.py`, `local_astra/contracts/**`, `services/**`. B16 is unaffected by construction. With no tap frames, a fake turn publishes zero `astra.canvas.*`.

### Group B — the page (`hud/src/denoise/`, `hud/src/protocol.js`)

B1. **Decoder mirrors the contract.** `astra.canvas.step` in `hud/src/protocol.js` mirrors `AstraCanvasStep` exactly: `canvas`/`argmax`/`stable` nullable, `phase` ∈ {denoise, commit}, `committed_tokens`, optional `accepted`/`entropy`/`segment`/`text_preview`, plus `_lengths_agree`. Denoise: all three rows, no committed ids, `0 ≤ step ≤ max_steps`. Commit: no rows, non-empty ids, `0 ≤ step ≤ max_steps`. Every shared decode-corpus case gets the same verdict in Python and JS.

B2. **Cell states from the frame only** (pure `hud/src/denoise/model.js`, no DOM, no clock). Denoise: **stable** if its `stable` bit is set; else **kept** if `canvas[p] == argmax[p]`; else **noise**; shown **revised** if `argmax[p]` differs from the previous frame of the same `(request_id, canvas_idx)` where p was stable. Commit: p < `len(committed_tokens)` is **committed**, the rest **empty**.

B3. **The grid.** 32 columns, `ceil(canvas_length/32)` rows, gap 2 px, cell radius 2, square cells filling the pane's content width, one `<canvas>` sized for devicePixelRatio. Colours from CSS tokens at draw time: stable/committed `--accent` α 1.0; kept `--accent` α 0.45; noise `--accent` α 0.12; revised `--accent-2` α 1.0; empty `--accent` α 0.06. A theme change redraws within one frame. `aria-label` states the label and the four counts.

B4. **Honest label** in the Thinking heading row, right-aligned, 12 px, `--muted`: `canvas {canvas_idx} · step {step}/{max_steps}` (denoise) or `canvas {canvas_idx} · committed at step {step}/{max_steps}` (commit), verbatim from the drawn frame.

B5. **Never fabricated.** Before the first decoded `astra.canvas.step`, `[data-denoise-root]` has no element children (T-0128 criterion 5 kept); the canvas element is created at the first frame; no frame → no draw, no animation; `Math.random`/`crypto.getRandomValues` still absent from `hud/` (except `ws.js`); no `requestAnimationFrame` loop without a pending frame. The empty line becomes "no denoising data yet — the model's real canvases appear here while it thinks" (amends T-0128 criterion 5's copy only). On `astra.error` `denoise_no_tap` the empty line shows that message; on `astra.canvas.synthetic` nothing is drawn and the line shows "synthetic canvas refused: {reason}".

B6. **Which request.** The request whose first frame arrived most recently; other requests' frames are ignored while the shown one has had a frame within 1500 ms (page clock).

B7. **Between turns.** The last drawn frame and label stay until another request's first frame; a reload shows the empty state until the next frame; canvas frames are not replayed.

B8. **Reduced motion.** Under `prefers-reduced-motion: reduce`, redraw at most twice per second (latest wins); the label still updates every frame.

B9. **Counters.** `[data-denoise-root]` carries `data-denoise-frames`, `data-denoise-draws`, `data-denoise-digest` (FNV-1a of the drawn state array, from `model.js`).

B10. **Matches the mockup.** At 1440×900 in both themes, the Thinking pane matches the mockup's `.rail > .panel:nth-child(2)`: column count; cell size ±1 px; gap ±1 px; lit cell ΔE ≤ 2; label font size ±0.5 px, colour ΔE ≤ 2, right edge ±2 px. Named deviation: the thinking-time meter sits between the heading and the grid.

B11. **Negative.** T-0128 criterion 4 layout rows and the T-0154 P1/P2/P3 parity rows stay green unmodified; `node --test tests/hud` stays under 5 s.

## Implementation notes

- **Wire facts** (`plugin/astra_vllm_plugin/astra_vllm_plugin/tap.py`): two-part `[b"astra.canvas.step", msgpack(dict)]`; denoise frames carry `canvas`, `argmax`, `stable` (hex, MSB first, whole bytes); commit frames carry `committed_tokens` and `canvas_length`, no rows; `accepted`/`entropy` never sent; `max_steps` is the engine cap of 48.
- **Validation:** `AstraCanvasStep.model_validate`; do not re-encode or mutate.
- **Threads:** `zmq.asyncio` on the loop, or a reader thread handing off via `loop.call_soon_threadsafe`; `HudServer.publish` on the loop thread only. Own a `zmq.Context`, `LINGER 0`, close sockets before `term()`; never `Context.instance()`.
- **Where it lives:** `hud_server.py` must not construct the relay (`test_hud_server_no_egress`); `cli.py` builds it with injected `publish`, `clock`, `state` (`session.turn_state_message`) and `session_log`; `session.py` untouched (A10).
- **Cell semantics:** `canvas[p] == argmax[p]` is the "kept" proxy; a random refill equal to argmax has p ≈ 1/262K — say so in a comment. Thought/answer dimming is out of scope (H-T128c-2).
- **Reduced motion:** test pages use `transition-property: none` (tests.md); the reduced-motion block stays last in `styles.css`.
- **Label placement:** add a sibling label element aligned with CSS; do not restructure the heading markup that T-0154's parity rows measure.
- **Fast suite:** ephemeral ports or `ipc://` in tmp_path only, never 8002; new fast rows total < 3 s.
- **Never raise a threshold;** bring a spec question to the orchestrator.
