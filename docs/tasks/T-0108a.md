## Goal

Under the T-0108 gate most flight-style cards reach the user with "last call OK", but the gate has pruned their interactive components. The model writes:
- a TextField with `placeholder` and no `label`;
- a Button with `text` instead of `child` + `action`;
- a DateTimeInput or ChoicePicker with no `value`;
- ChoicePicker options as strings.

Today the UI block shows only Column, Row and Text.

This task adds a T-0108a table to the T-0098 harness. It runs A0 against two candidate UI blocks that name the required fields compactly. The run uses T-0098c's 60 cases, with 40 repeats on the four Q12 positives. A rule fixed before the run gives one outcome: a winner (which T-0108d ships), no change, or inconclusive. The primary metric is the complete-card rate. Nothing in the product changes in this task.
