# T-0046 — `gpu`-marked tests never run by accident

**Status:** done 2026-09-16 (main session; test-config change) · **Origin:** T-0044 ruling A3 — a path-only pytest invocation of the
eval directory ran 12 live generations without a `/launch` review.

## Goal / change

`pyproject.toml` `addopts` gains `-m 'not gpu'`: a path-only invocation deselects every `gpu` row; a reviewed run states `-m gpu`
(or `-m "gpu or audio"`) explicitly and a later command-line `-m` replaces the default. `tests/unit/test_pytest_config.py` pins the
option, proves the eval directory collects nothing when selected by path, and proves an explicit `-m gpu` still selects (all three by
running pytest itself).
