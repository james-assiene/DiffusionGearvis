## Goal
The Conductor grows the socket the HUD has been talking to a stub through. `conductor/hud_server.py`
serves `ws://127.0.0.1:8000/v1/realtime` — the URL `hud/src/ws.js` already defaults to — and is the
one place where a real `Session` meets a real client: `astra.frame` in becomes perception,
`astra.assist.toggle`/`astra.frame.text` in becomes `AssistState`, `astra.ui.action` in becomes a
user turn (`[ui] <name> <context>`, docs/02 §2.2), and `astra.turn.state`/`astra.transcript`/
`astra.spoken`/`astra.ui.surface`/`astra.assist.state`/`astra.error` go out to every connected page.
The transport knows nothing about turns and the session knows nothing about sockets: the session
gains one typed publisher seam (it already has the stub `publish_hud`/`hud_out` outbox) and the
server is a dumb, total, loopback-only pipe over `contracts/codec`. The second half is the `astra`
CLI: `astra session` builds the production object graph for a profile, mounts `BrowserFrameSource`
as the `PerceptionClient`, serves the endpoint and prints the page URL; `astra up` starts the
profile's services and health-probes them on loopback. After this task the demo is "open the page,
share a tab, ask a question" instead of "run a script", and T-0024's round trip stops at
`astra.ui.action` no longer — it ends in a turn.

### The endpoint (group A)

1. **It serves the URL the page already points at, on loopback only.** `HudServer` binds
   `127.0.0.1` and serves the path `/v1/realtime`; the port comes from `config.Services.conductor_port`
   (8000). *Negative:* constructing it with any host other than `127.0.0.1`/`localhost`/`::1` raises
   before a socket exists; the listening socket's `getsockname()` is `127.0.0.1`, never `0.0.0.0`
   or `::`; a request on a path other than `/v1/realtime` is refused with 404 and no session state
   changes. (docs/02 §9, docs/03 E8, CLAUDE.md "all services bind to loopback only".)
2. **Origin fence.** A WebSocket handshake whose `Origin` is neither absent/`null`/`file://` nor a
   loopback origin is refused with HTTP 403 **before** any message is read, and nothing reaches the
   session. *Adversarial (this is the criterion's reason):* a page on a remote site in the user's
   own browser can open `ws://127.0.0.1:8000` — loopback binding does not stop it. A test drives the
   handshake with `Origin: https://evil.example` and asserts 403, zero events submitted, and that a
   subsequent legitimate connection still works.
3. **Decoding is total and direction is enforced.** Every inbound frame goes through the real
   `contracts.codec.decode` and reaches exactly one of: a `CLIENT_TO_SERVER` type → routed; an
   `astra.*` type that is *server→client* → refused with `astra.error(code="wrong_direction")`; a
   known-but-unhandled/unknown `astra.*` → ignored and counted; a non-`astra.` `RealtimeEvent` →
   ignored and counted (v1 relays nothing); `Malformed` (bad JSON, missing `type`, bad fields, over
   `codec.MAX_MESSAGE_BYTES`) → `astra.error(code="malformed")` and counted. In all five the socket
   is still open afterwards and the pump is unaffected. *Adversarial:* a client sends
   `astra.spoken` (decodes fine, wrong direction) and an 8 MB oversize message back to back; neither
   produces an event, neither closes the socket, neither raises out of the connection handler.
   Mirrors T-0008 criterion 2 on the server side.
4. **Hello first, fail-closed.** No message from a connection that has not sent a valid `AstraHello`
   is routed into the session (it is refused with `astra.error(code="no_hello")` and counted). A
   valid hello is answered with the current `astra.assist.state` and `astra.turn.state`, so T-0025's
   panel and T-0008's chip start from the server's truth rather than from a guess. A hello whose
   `protocol_version != PROTOCOL_VERSION` gets `astra.error(code="protocol_version")`, the socket
   stays open so the page can display it, and that connection stays fail-closed for ingress.
   *Negative:* a second hello on the same socket does not reset the assist flags.
5. **Frames reach perception unmodified.** `astra.frame` is handed to the injected frame sink
   (`BrowserFrameSource.ingest`) and nothing else; the session's `SnapshotFrame(at_ms=onset)` then
   resolves to that frame. *Negative:* the server does not decode the JPEG, does not resize, does
   not recompute or validate `phash`, and does not re-implement any part of `perception/policy.py` —
   `BrowserFrameSource`'s own validation (T-0008 criteria 14–18) is the only one, so there is no
   second bucket/quality rule to drift (`.claude/rules/perception-memory.md`).
6. **Assists: the server echoes, it never derives.** `astra.assist.toggle` → `session.assists.toggle(msg)`
   and the returned `AstraAssistState` is broadcast **verbatim** to every connection;
   `astra.frame.text` → `session.assists.accept_frame_text(msg)`, whose fail-closed drop (T-0012)
   is counted, not rescued. *Negative:* no code path in the owned files builds a badge string or
   flips a flag — `AssistFlags.badge()` stays the single derivation (T-0012 criterion 8, T-0025
   criterion 4); an `astra.frame.text` for a kind that is off produces no `FrameText` and no event.
7. **`astra.ui.action` becomes a user turn — the seam T-0024 stops one inch short of.** With the
   machine IDLE, an action is submitted as `events.UiAction` and the session opens an ordinary user
   turn whose transcript is `[ui] <name> <compact-json context>` (docs/02 §2.2: "turns
   `astra.ui.action` events into user turns"), running the normal rows: assists frozen at open, one
   prompt, one speech gate, one `TurnRecord`. A contract test drives the whole loop over fakes —
   a `ui` commit → `astra.ui.surface` out → `astra.ui.action` in → a second turn whose transcript
   starts `[ui] ` → the reply's surface out — closing T-0010 criterion 5 / T-0024 criterion 7
   ("the message is on the wire" ends here). *Negative:* the action does **not** synthesise
   `UserSpeechOnset`, `SttWord` or any other speech-shaped event beyond what the machine needs to
   open a turn, and nothing invents audio timestamps that no microphone produced.
8. **An action while a turn is live is refused, not smuggled in.** With the machine in any state
   other than IDLE, an `astra.ui.action` yields `astra.error(code="busy")`, opens no turn, and
   leaves the live turn's state, gate and history untouched. *Adversarial:* the click arrives during
   SPEAKING, one hop before `PlaybackDrained` — the live turn still ends with exactly one record and
   the refused action leaves no residue in the next turn's prompt. (This is a policy decision taken
   here rather than a machine row; it is one of the `/spec` deltas listed in "Out of scope".)
9. **Egress is complete, ordered and typed.** Over one scripted turn a connected client receives, in
   arrival order: an `astra.turn.state` for every machine state change, `astra.transcript`
   (`final=false` per partial, one `final=true` at end-of-turn), one `astra.spoken` per utterance
   handed to TTS with the machine's own `utterance_id`, one `astra.ui.surface` per validated canvas
   with `final=true` on the last of the turn, `astra.assist.state` on every change, and
   `astra.error` for each `HudError` command. Every message re-decodes under the real codec and its
   type is in `SERVER_TO_CLIENT`. *Negative:* no `astra.canvas.step`/`commit`/`synthetic` is ever
   sent (T-0011b/c owns the relay), no client-direction type is ever sent, and no field is invented
   that the models in `contracts/protocol.py` do not declare — in particular **no played-text field**
   (T-0008b owns that; T-0007 ruled it out of this family).
10. **The thinking meter is derived, not timed separately.** `AstraTurnState.thinking_ms` is
    `clock.now_ms - MachineState.llm_start_ms` while the state is THINKING and `None` in every other
    state. *Negative:* no second clock and no timer is introduced for the meter (criterion 3 of
    T-0007: `ArmTimer`/`CancelTimer` remain the session's only timers).
11. **Thinking never reaches the wire.** A property test over generated commit scripts (Hypothesis,
    `--hypothesis-seed=0`) asserts that a token appearing only in a `thought` segment appears in no
    egress message of any kind — not in `astra.spoken`, not in `astra.transcript`, not inside an
    `astra.ui.surface` payload, not in an `astra.error` message. The wire-side twin of T-0007
    criterion 6 (CLAUDE.md: never store or show assistant thinking).
    *Amended by T-0180 (R-1, James 2026-10-27/28): narrowed — except the `text` of `astra.thought`. A thought token may appear only in that field, and in the DOM only inside `[data-model-thoughts]`. When the script had a thought commit, the row asserts that it does appear there; it stays absent from every other message, `turns.jsonl` and history.*
12. **A slow client cannot slow the turn.** The pump never awaits a socket: publication is a
    non-blocking hand-off to a **bounded** per-connection queue. *Adversarial (the failure mode this
    task most likely ships):* a client that stops reading for 5 s must not delay any executor
    command — with the barge-in test from T-0007 criterion 14 running against a stalled reader,
    `audio.pause()` still happens on the barge-in hop. On overflow the only message kind that may be
    dropped is `astra.turn.state` (latest-wins, idempotent); overflow of anything else closes **that**
    connection with a logged reason rather than silently losing a spoken line and desyncing the
    transcript. *Negative:* no unbounded outbound queue, and no `await` on a send inside the pump
    task or inside any `CommandExecutor` handler (`.claude/rules/conductor.md`: nothing in the pump
    blocks the loop for more than 20 ms).
13. **Many clients, and a clean disconnect.** Two connections both receive every egress message; a
    disconnect of one changes nothing for the other; `events.ClientDisconnected` is submitted exactly
    once, when the **last** connection goes, and never on a reconnect. A reconnect (T-0008's backoff)
    sends a fresh hello and gets the current assist and turn state (criterion 4) while the session
    keeps running with its history intact.
14. **The transport stays out of the session.** *Negative, static, over the owned files:*
    `session.py` and `executor.py` import no `websockets`/`httpx`/`socket`/`aiohttp` and contain no
    URL literal — the existing `tests/unit/test_session_no_egress.py` (T-0007's, unmodified) must
    still pass with its current `LIBRARY_FILES` list. `hud_server.py` may import `websockets` (it is
    the transport) but constructs no concrete service client, names no non-loopback host, and reads
    its bind address only from `config.Services`. The session's egress is one injected publisher
    with a default that touches no I/O.

### The CLI (group A) — split to T-0029 if the checkpoint is hit

15. **`astra session` builds the production graph and serves it.** `uv run astra session
    [--profile lean] [--data-dir DIR] [--turns PATH] [--audio-path …] [--sink …] [--source screen|camera]`
    constructs the real `VllmClient`/`MoshiSttClient`/`PocketTtsClient`/`PipeWireAudioIO`/`SqliteMemory`
    plus a `BrowserFrameSource` used **both** as the session's `PerceptionClient` and as the server's
    frame sink, starts the session and the endpoint, and prints the page URL and the bound port.
    `--dry-run` prints the resolved profile, the endpoints and the object graph and exits 0 having
    constructed no socket and no device. A test asserts the flag set of `astra session` is a superset
    of the regime flags `scripts/demo/session_rung.py` accepts (read-only parity pin, so the two ways
    of starting a session cannot disagree about the regime). *Negative:* every endpoint comes from
    `config.Services` (loopback-validated); the CLI never accepts a URL argument.
16. **Ctrl-C is clean.** SIGINT closes the session (`aclose`), stops the server, and exits 0. No
    `turns.jsonl` line is written at shutdown: records belong to turn-ending rows only (T-0007
    criterion 12). *Negative:* an interrupted in-flight turn produces either its own turn-ending line
    or none, never a synthesised one.
17. **`astra up` starts a profile and proves it, or says why not.** `astra up --profile X --dry-run`
    prints the exact ordered start plan (the `services/*.sh` invocations the profile's backends need)
    and runs nothing. Without `--dry-run` it executes the plan through an injected runner and then
    health-probes each loopback endpoint from `config.Services` until healthy or `--timeout`,
    printing per-service pass/fail with the failing reason. A fake runner in the fast suite pins the
    order, the probe loop and the failure report. *Negative:* `astra up` never downloads a model
    (`fetch-models` is the only network egress, docs/02 §9), never writes to `artifacts/`, and never
    probes a non-loopback URL.
18. **Nothing else in the CLI moves.** `config` still prints the resolved profile; `down`, `status`,
    `bench`, `eval`, `forget`, `fetch-models` still exit 2 with today's message, byte-identical.
    *Negative regression fence:* a test pins their exit code and stderr.
19. **Failures are loud and exit non-zero.** A failed health probe, a port already in use, or a
    missing PortAudio exits non-zero with the cause named (the port, the service, the device).
    *Negative:* `astra session` never falls back to a different port, a different interface or a
    different device when its first choice fails — silently moving the endpoint is how the page ends
    up talking to nothing.

## Implementation notes
Constraints and landmines; the design is the implementer's.
- **The session must not learn about sockets.** The publisher is a callable/protocol taking an
  `AstraMessage`; `hud_server` subscribes. Inverting this (session imports the server) both breaks
  criterion 14 and makes the session untestable without a socket.
- **Nothing in the pump awaits the wire** (`.claude/rules/conductor.md`, 20 ms budget). Publication
  is `put_nowait` on a bounded queue plus a per-connection writer task; a writer that cannot keep up
  is *that connection's* problem.
- **The machine is pure and is not yours.** `turn_machine.py` is not in Owned files and must stay
  byte-identical (T-0007 ruling A6 pins its SHA-256). `ui.action` is rowless in the machine by
  design — the turn is opened by the session, from the session's own events.
- **`AssistState` is the one authority.** Route toggles and frame-text through it and send back what
  it returns; never construct an `AstraAssistState` from local flags (T-0012 criterion 8).
- **`BrowserFrameSource` already validates frames** (base64, JPEG magic, ring, hysteresis, 600 cap):
  do not add a second validation, a second ring or a second rate limit.
- **`utterance_id` comes from the machine** (`MachineState.utterance_seq`, derived from `turn_id`,
  never from a clock) — T-0008 criterion 8 keys the spoken pane on it, so a fresh id per send would
  duplicate lines in the page.
- **No `played_text` on the wire.** T-0007 ruled `AstraSpoken.played_text` out of this family
  (T-0008b). Do not fake strike-through from timing and do not send a field the codec does not model.
- **Codec limits are the codec's** (T-0027: UTF-8 bytes, `MAX_MESSAGE_BYTES`); do not add a second
  size rule on either direction.
- **`websockets` `max_size`:** pick it deliberately and say why in the docstring — above the codec
  limit means oversize is *reported* as `astra.error` (T-0008 criterion 2 expects that), below means
  the library kills the connection first and the page sees a bare close.
- **`astra up` runs `services/*.sh`**, which the Bash guard gates; the CLI does not bypass the guard
  and does not re-implement what the scripts do. No systemd unit files exist yet — writing them is a
  separate task, not a side effect of this one.
- **Loopback:** every endpoint comes from `config.Services`, whose validator refuses non-loopback.
  Do not accept a URL from argv, the environment or a message.

- **A1 (2026-09-14, tests landed b224cc8 + 276ddd2, 40 pending).** `AstraSpoken.text` is the TTS-normalised text as handed to TTS (the model docstring); `source` stays off the wire until T-0008b. - **A5.** Criterion 7's negative is read as: the only speech-shaped event synthesised for a click is the `UserSpeechOnset` the machine needs to open a turn, stamped at the click time; the transcript is injected as the turn's word buffer content; no backchannel/takeover/offset/pause/step is ever synthesised.
