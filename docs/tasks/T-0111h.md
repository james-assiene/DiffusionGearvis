# T-0111h — The widened action set (`tools_v2`): double-click, right-click, drag, open_url, wait

**Status:** planned 2026-10-19 (outline; re-read before activation) · **Blast radius:** high (a new tools file changes the cached prefix of every tools-on request, and its GPU A/B needs two reviewers) · **Branch:** `T-0111h-tools-v2` from main after T-0111g merges · **Parent:** T-0111 (row T-0111c's widened list); T-0111c; H-T111a-6 · **Sequencing:** owns the executor package files below and `tool_executor.py` while open.

**Protocol cannot be skipped:** the tools sha changes, and with it the prompt prefix and the eval baseline.

## Goal

`toolcall/tools_v2.json` is v1 unchanged, in v1's declaration order, plus five tools:
- `double_click_at(x, y)`;
- `right_click_at(x, y)`;
- `drag(x, y, x2, y2)`: one anchored call, so a press point can never be lost. This is the cua §2.2 lesson, where every drag failed until a late executor fix.
- `open_url(url)`: allowed only to origins the fence allows, so loopback until H-T111c-E. Synthetic Ctrl+L never reaches the address bar, so without this tool the agent cannot navigate at all.
- `wait(ms)`: 100–5000.

Both the executor and the dry run support all five. A profile key `tools_version = "v1" | "v2"` defaults to `v1` until the GPU A/B passes and the human switches it.

`done`, `fail` and `zoom` move to T-0111d:
- `done` and `fail` change how the loop ends, which is turn-machine work.
- `zoom` returns an image.

## Acceptance criteria (outline)

1. **tools_v2.json.**
   - `tools_v2.json` validates.
   - Its first five declarations are byte-for-byte v1's.
   - New schemas use 0–999 integers and `additionalProperties: false`.
   - `open_url.url` is at most 2048 characters; `wait.ms` is 100–5000.
   - `tools_v1.json` is unchanged.
2. **Dry run.** `DryRunToolExecutor` describes each new tool. Its v1 outcomes are unchanged (differential).
3. **Live, against loopback fixtures.**
   - A double click gives one `dblclick` and two `click`s.
   - A right click gives one `contextmenu` and no `click`.
   - A drag gives `pointerdown` at the anchor, at least 5 `pointermove`s, and `pointerup` at the target; after a cancel, `buttons == 0`.
   - `open_url` refuses non-loopback, `file:`, `chrome:`, `javascript:` and `data:`.
   - `wait` lasts at least `ms`, measured on an injected clock.
4. **Profile key.** It defaults to `v1`, and `--dry-run` prints the sha. With `v1`, request bodies equal BASE's.
5. **GPU A/B (pre-registered).**
   - Cases: `tests/eval/toolcall/cases_v2.jsonl`, at least 10 per new tool, plus the v1 dev split rerun under v2.
   - Bar: per tool, v1-case accuracy under v2 is at least v1's accuracy minus 10 % (relative).
   - New-tool accuracy is report-only.
   - Switching the default is the human's call (H-T111c3-1).
6. **Negative.** These are byte-identical: `turn_machine.py`, `contracts/**`, `tests/fakes/**` and `tools_v1.json`.
