# T-0004 — Speech gate

**Status:** merged 2026-09-13 (a640f89; re-review MERGE, all six mutations red) · **Blast radius:** medium · **Depends on:** T-0002

## Goal
`local_astra/conductor/speech_gate.py` turns committed *answer* text into TTS-ready sentences
(docs/03 §3 "Speech gate"; docs/01 D3).

## Acceptance criteria
1. Rejects `thought`/`ui` segments and `thought_open` commits with `GateInputError` *(already enforced; tests active)*.
2. Splits on sentence boundaries handling abbreviations ("e.g.", "Dr."), decimals ("3.14"), ellipses, URLs and file paths; emits the first sentence as soon as it is complete.
3. Holds an unfinished clause until the next commit or `close()`; `close()` flushes it.
4. `normalise_for_tts` is narrow: file paths, code identifiers, fenced code (→ "a code block") and stray special tokens / text after EOS; numbers, dates, currency and URLs are left to the TTS engine (X4 measures whether that holds). Each emitted `Sentence` carries `source` (exact committed substring) and `text` (normalised).
5. Property: the concatenated `text` of emitted sentences (whitespace-normalised) equals `normalise_for_tts` of the concatenated committed answer, and the concatenated `source` equals the committed answer — nothing lost, nothing invented.
6. Trims text after an EOS/special token and drops stray `<|…|>` tokens.

## Owned files
- local_astra/conductor/speech_gate.py

## Out of scope
Voice selection, TTS client, filler clips.

## Evidence required
`uv run pytest tests/unit/test_speech_gate.py -q`, fast suite, mypy.

## Amendments (2026-09-13, rulings after test activation)

**A1 — conservation is byte-exact and the separator rides on the PRECEDING sentence.** The
inherited tests demanded `source == "It is a stack trace."` and `pending == "The error is on
line"`, leaving the space in between belonging to neither — unsatisfiable against T-0003's
segmenter contract, which raises `ValueError` unless `"".join(sources) + remainder == text`.
Ruling: whitespace following a terminator is absorbed into the preceding sentence's `source`
(`"It is a stack trace. "`), and the TTS `text` is that source stripped. `pending` therefore always
starts at a word. Either placement was satisfiable; this one is chosen for determinism.

**A2 — criterion 6: EOS tokens TRIM, other special tokens DROP in place.** An end-of-sequence
token (`<end_of_turn>`, `<eos>`, `<|endoftext|>`) means the model is finished: everything after it
is trimmed from `text`. Any other `<|…|>` token mid-text is a tokenizer artifact, not a stop:
it is removed and the surrounding text is joined (`"Four. <|pad|> Five."` → `"Four. Five."`).

**A3 — criteria 5 and 6 reconcile through the two fields, and nothing is held forever.**
Conservation is on `source`; cleanliness is on `text`. Post-EOS or dropped-token text is still
emitted as part of a `source` (so the turn machine's check passes) with a trimmed or empty `text`
(so TTS never voices it). After `close()`, `pending == ""` always — a gate that holds text
indefinitely is a bug, not a policy.

**A4 — criteria 2 and 4 stay pinned only by the inherited fixtures.** Segmentation of arbitrary
abbreviations/ellipses and the normalisation of arbitrary paths/identifiers are unspecified; the
implementer handles the fixture rows and the no-terminal-punctuation property and does not invent
rules beyond them. Extending either is a spec task with its own fixtures.

**A5 — the T-0003 postcondition, for whoever wires the gate in (not this task).** Adopt the
test-author's stronger form rather than an "or held" escape: accumulate `TtsSpeak.source` per turn
in the stateful model and assert it is always a prefix of `committed_answer`, and equals it on
`llm.done`. That restores "nothing committed is silently dropped" at the one point it is required,
names no private field, and catches a gate that holds text forever.

## Rulings after review (2026-09-13, verdict REVISE → test-author)

**A6 — `<|think|>` TRIMS and LATCHES; A2 is amended.** `<|think|>` is not a tokenizer artifact, it
is the thought-channel delimiter (`prompt_builder.py`, `contracts/llm.py`, docs/02 §2.4). A2's
"drop in place" rule would voice thinking, which CLAUDE.md forbids absolutely. Ruling: `<|think|>`
joins the trim list, and — for every EOS/trim token — the gate **latches**: every later sentence in
the same turn has `text == ""` (its `source` is still emitted, so conservation holds). The
implementation already does this; the suite must pin it with inputs where a *completed* sentence
follows the token (`"Four.<end_of_turn> junk. Five."`, `"Ready.<|think|> secret. Reconsider."`).
Without those rows a gate that voices the thought channel passes 46/46 (reviewer mutation).

**A7 — balance rule: parentheses and fences hold, double quotes do not.** The implementation added
an unspecified `_is_balanced` hold (unclosed `(`, `"` or ``` ``` ``` defers emission). Ruling: a
terminator inside an open parenthesis or an open code fence is not a sentence end — keep and pin
(`"Consider (a. b). Done."` emits nothing until `)`, then one sentence). The double-quote clause is
**removed**: unbalanced `"` is common in model prose and an apostrophe-free heuristic cannot tell
an opening quote from a stray one, so holding on it defers first speech to `llm.done` (criterion 2,
docs/01 §8). `He said "stop. Now fine.` emits `He said "stop.` first. Closers (`)`, `"`, `'`)
following a terminator stay attached to the sentence — pin that too. The abbreviation list is the
implementation's whole rule (A4): pin every entry with one parametrised row each.

**A8 — the separator placement of A1 is pinned exactly.** One exact-equality assertion on the
first `source` (`"It is a stack trace. "`) and on `pending` (`"The error is on line"`), so the
"pending always starts at a word" invariant is a test, not a comment.

**A9 — one gate per turn.** The gate is constructed fresh per turn by the wiring (T-0007); `close()`
is the only way to flush and it *speaks*, so a barge-in/takeover discards the gate object instead
of closing it. Consequences: `emitted` need not be cleared, `_stopped` need not reset, and T-0007's
tests must cover "takeover never calls close()". Recorded here for T-0007; nothing to pin in T-0004.

**Follow-up, not this task:** an unclosed code fence at `close()` is read aloud verbatim (docs/02
§5.2 says "do not speak code blocks"). A4 scoped unclosed fences out; it becomes its own task with a
fixture row (needs `/plan`). Also for T-0007: `test_nothing_lost_nothing_invented` compares the
normaliser against itself — fine for segmentation, carries no criterion-4 weight; the fixture table
is the spec there.

**A10 (after the A6–A9 test pass, 9bfbc00) — abbreviation matching is case-insensitive** (the
list is lowercase, the lookup lowercases; `Dr.`/`Prof.`/`St.` rows pin it). The coverage guard that
reads `_ABBREVIATIONS` stays: A4 makes the list the spec, so an unspecified entry must fail loudly.
Implementer's pass: delete the `"` clause of `_is_balanced` (the test-author verified that is the
whole delta: 80/80) and make the module docstring enumerate `_is_balanced` and `_CLOSERS` as rules.

**Merged 2026-09-13 (a640f89).** Reviewer follow-ups, not blockers, carried to their owners:
`_IDENT_RE` splits `iPhone`/`eBay` into "i phone" (prose false positive — same follow-up as T-0022's
fixture work, A4 makes it a spec change); `p.m.` is not in the abbreviation list; a latched sentence
still yields `TtsSpeak(text="")` — T-0007's wiring must skip empty-text utterances rather than send
