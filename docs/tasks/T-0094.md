## Origin
`.claude/rules/tests.md` (after T-0089) says to pin scope and contract checks to a literal base SHA, never a moving ref. At 6a8600b:
- **Moving base.** Seven guards diff against `main`, `merge-base(HEAD, main)` or a branch-name fallback chain. On main,
  `merge-base(HEAD, main)` is HEAD, so six can never fail (vacuous). The seventh (G1) is meaningful only while a local branch
  `T-0062-perstep-cd` exists.
- **Moving tip.** Four cd-group guards (five rows) pin a literal base but compare it with the *working tree*. They went red on main once
  T-0088–T-0092 legitimately edited `local_astra/conductor` and `local_astra/contracts`; the cd group is not in the Stop hook's
  selection, so nobody saw it. Measured at 6a8600b: `5 failed, 393 passed` on the cd scope-guard subset.
- **The rule's own form.** "Pin the base" fixes one end only. A pinned base against the working tree goes red when a later task
  legitimately touches a guarded file, and exemption lists (`LATER_TASK_OWNED`) hide that until someone forgets one. T-0069 ruling F1
  (`tests/cd/integration/test_cd_tap_composition.py`) already uses the form that does not decay: a closed range between two literal
  SHAs.

## Goal
Every scope or contract guard in `tests/` compares two fixed things: (a) a **closed commit range** `BASE..TIP` of the owning task, for
"this task touched only its files"; or (b) a **content pin** (sha256 literal or inline literal), for "this text must never change". No
guard reads `main`, `origin/*`, `merge-base(HEAD, <branch>)` or the working tree for a finished task's scope. The cd group's scope guards
are green on main without exemptions; the six vacuous guards can fail again; a fast-suite meta-row stops a moving-ref guard returning.

## Acceptance criteria
1. **No moving refs.** No row in `tests/` passes `main`, `origin/<x>`, a `main:`-prefixed object name, a range with a `main`/`HEAD` end,
   or `merge-base … HEAD <branch>` to git to decide pass or fail (enforced by criterion 10). Exceptions: provenance-only
   `rev-parse HEAD` / `status --porcelain`; commands inside a scratch repo the test created; the two monotone `HEAD`-as-descendant
   controls in `test_cd_tap_composition.py`, allowlisted by exact location.
2. **Closed ranges.** G1, G2, G4–G7 and R1–R4 each name two literal constants with a comment citing the task and its merge commit:
   `<TASK>_BASE` = `git merge-base M^1 M^2` of the task's merge commit M; `<TASK>_TIP` = `M^2` (values in the inventory). Each guard
   asserts its original property over `git diff --name-only BASE TIP -- <its original paths>` (and `--diff-filter=MDR` for G5's `logs`
   half). Neither the guard's path set nor its "only these owned files may change" set shrinks.
3. **Proof of the range.** Each closed-range guard first asserts BASE is an ancestor of TIP and TIP an ancestor of M
   (`merge-base --is-ancestor`, never HEAD), and that M is an ancestor of the literal `6a8600b`. If any commit is absent (shallow clone),
   the guard **skips** with a reason naming the SHA; it never passes.
4. **Power, per guard (adversarial).** The same predicate over `BASE..6a8600b` (literal) reports at least the known later change:
   G1, R1, R4 → `local_astra/conductor/executor.py`; G2, G6, G7 → `local_astra/toolcall/router.py`; G4 → `cd/automaton.py`;
   G5 → `local_astra/conductor/executor.py`; R2 → `local_astra/cli.py`; R3 → `local_astra/contracts/llm.py`. Mutation: a predicate that
   always returns `[]` turns every power row red.
5. **Exactly the owned files.** G6 still reports `decoding/toolcall.py` as the only `local_astra` change in its range and allows it; G7
   likewise `eval/cd/twopass.py`. A row over T-0084a's range with `ALLOWED_CHANGES` emptied must report `decoding/toolcall.py` (the
   "too strict" companion).
6. **Wrong base is caught (adversarial).** A row asserts T-0084b's predicate over the declared base `1e06a24..a1ef4dd` reports
   `local_astra/toolcall/router.py` (T-0082a's change via the mid-branch main merge), documenting why 4a4513a is required.
7. **G3 content pin.** The M1 row compares `sha256(section(current, M1_HEADING))` with a literal computed from
   `git show 7ad65e0:hud/README.md`. A provenance row checks the literal equals the hash at 7ad65e0 (skip if absent). Adversarial: the
   section with one byte appended fails. The existing first assertion ("astra hud" in current) stays.
8. **G4 runs on CPU.** Its four fenced-path rows move to a non-gpu module (`tests/contract/test_vllm_tap_fields_scope.py`), same paths,
   closed range f21c682..0bd3346. `test_vllm_tap_fields_gpu.py` loses only those rows (and `_git` if unused); every other gpu row is
   byte-identical.
9. **Exemption lists retired, no assertion lost silently.** `LATER_TASK_OWNED`-style dicts used *only* by converted guards are removed
   with the rows that test only those dicts; exemptions still used by unconverted `NOT_OWNED` rows stay (e.g. `LATER_TASK_OWNED_PLUGIN`
   in `test_cd_logmatmul_backend.py`). The PR description lists every removed assertion
   (`git diff 6a8600b -- tests/ | grep -E "^-[^-]" | grep assert`) and the row that replaces each.
10. **Meta-row** (`tests/unit/test_guards_use_fixed_refs.py`, fast suite). Walks the AST of every `tests/**/*.py`: string constants that
    are arguments of a `subprocess` call or of a helper whose argv starts with `"git"` (not docstrings or comments). Fails on criterion
    1's constants.
    - Too wide: run over the 6a8600b blobs of the seven G modules (`git show 6a8600b:<path>`, skip if absent), it flags all seven G sites.
    - Too narrow: it does not flag `hasattr(m, "main")`, `getattr(m, "main", None)`, a docstring quoting `git show main:`,
      `rev-parse HEAD` provenance, or scratch-repo calls.
    - It passes on the post-T-0094 tree.
11. **Green.** `make fast-parallel` green; `make cd-test` green on the touched modules, with the full run's result quoted; the 5 red rows
    pass and none is skipped.
12. **Negative.** No file under `local_astra/`, `plugin/`, `services/`, `scripts/` or `hud/` changes; no threshold changes; no
    `pending`/`skip`/`xfail` markers added apart from criterion 3's absent-commit skips.
13. **Rule.** `.claude/rules/tests.md`'s "fixed commit" bullet gains one sub-bullet: after merge, a scope guard compares `BASE..TIP`
    (both literals, from the merge commit's parents), never the working tree; an invariant meant to hold forever pins content (sha256
    literal); exemption lists for later tasks are a smell that the range is open (ruling L3).
