## Goal

At c398fdf, T-0115a's E rows elided the step holding the fact. With the old stub `{note:"earlier result omitted",results:5}` the model searched again in 9/40 requests, said "I couldn't find it" in 30/40, and never invented the fact (exploratory re-read, docs/cd/toolcall-loop-requests.md). T-0120b changed the search stub to "earlier result omitted; search again if you need it" (H-T120b-0).

This task re-runs only the E rows that answer the question, in one fresh-boot `/launch` at a commit containing T-0120b: old placement COMPACT 40 + FULL 40; kept placement COMPACT 40 (control); warm requests as before. The accepted lists now carry the spelled-out number forms a voice assistant says. The outcome says whether the new stub makes the model search again, without inventing the fact and without hurting answers when the fact is still in the prompt. Nothing in the product changes.
