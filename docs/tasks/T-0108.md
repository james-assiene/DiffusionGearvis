# T-0108 — GenUI reliability (fixes 1 and 2): a deterministic structural (bracket) repair in the UI gate, a gate that never raises, and a turn-level validity metric judged on the turn's last gate call

**Status:** done (merged at aa333f2; status corrected 2026-10-23 from 'in progress', T-0147 audit: no implementation in flight) · earlier: in progress 2026-10-16 (ruled; tests at 2e3d0aa, activated at 7288570; implemented on `T-0108-impl`, awaiting review) · **Blast radius:** high (`conductor/session.py` and the gate that every A2UI surface passes through; two reviewers) · **Branch:** `T-0108-ui-structural-repair` from `main` at `14cde78` · **Depends on:** nothing open · **Blocks:** T-0109 (seeded retry after a shown partial, H-T108a), T-0108a (fix 3, prompt A/B), T-0108b (fix 4, resample) · **Origin:** the human's direction of 2026-10-16, "GenUI reliability is the priority; go ahead". This task covers fixes 1 and 2.

## Goal

Today about a third of the A2UI surfaces the model writes never reach the user intact. The JSON is malformed in a few structural ways:
- a duplicated opener `{"{"id":…`;
- a missing separator `"From:" "{"id"`;
- a wrong closer `"City or Airport"]},{"id"`;
- a stray `"]`.

json_repair turns these into junk messages that fail the schema.

After this task the gate runs one more stage. When strict parsing fails, a deterministic, linear-time pass edits the text before json_repair sees it. That pass only inserts or deletes structural characters and never changes any string's content. The gate also stops raising on deeply nested input.

The turn log gains a validity metric judged on the turn's **last** gate call (the fence body is cumulative, so that call sees the whole surface). The old sticky-AND `ui_valid` stays beside it, unchanged, for comparison, as H-T97 did. Nothing that fails validation reaches the renderer, as before. Valid input is handled byte-for-byte as today.

## Acceptance criteria

1. **Where the stage goes.**
   - The structural repair is a pure function `text -> (text, edits)` in a new module.
   - `UiGate._repair` calls it only after `parse_concatenated_json(raw)` has failed, and before `_fix`.
   - The repaired text goes through the existing fixer branch unchanged: json_repair (with an empty log if it is now valid), the grounding at line 171, then per-component salvage.
   - `edits` = structural edits + json_repair log entries + salvage edits.
   - Every later stage is unchanged.
2. **Valid input is untouched (negative; T-0010 A5).**
   - For any text `parse_concatenated_json` accepts, the repair returns it **byte-identical** with 0 edits.
   - The gate's result equals today's (same messages, `repaired == 0`, same report).
   - tests/unit/test_ui_gate.py and tests/unit/test_json_repair_contract.py pass unmodified.
3. **"A repair never invents content", made precise (ui_gate.py:31-33).** For every `raw` and its repair `out`:
   - **(N1) Alphabet.** Removing every character of A = `{ } [ ] , "` and JSON whitespace from `raw` and from `out` leaves identical sequences.
   - **(N2) String lexemes.** Every string lexeme of `out` occurs verbatim in `raw`, and no edit falls inside a string lexeme of `out`.
   - **(N3) Generated documents.** For a document generated from a string set S and corrupted by the observed operators, every decoded string leaf and key of the gate's output is in S.
   - **(N4) Idempotence.** `repair(out) == (out, 0)`, scoped to documents generated from S with the observed operators and to the real fixtures. *Delta (orchestrator, 2026-10-16, reviewer A):* N4 does not hold for every `raw`. For example, `'{"{"]a":1}'` repairs in two passes, because dropping `]` creates a new duplicated-opener context; 3 of 200k random junk strings behave like this. There is no safety impact: the gate repairs once and grounds against the original `raw`, and N1/N2 had 0 violations.
   - **(N5) Defense in depth.** The gate still grounds every message against the **original** `raw`, including when the repaired text parses strictly.
4. **The observed classes are repaired.** On the curated real canvases fixture (criterion 13), each repaired class gives the hand-written expected text and then yields a surface:
   - the duplicated opener;
   - the missing separator;
   - the wrong closer, in both variants ("drop a spurious closer when the expected one follows" and "insert the expected closer");
   - the stray quote after a closer.

   Unrepaired classes keep today's handling: duplicate id, missing `component` key, inline children, and a canvas cut inside the header.
5. **Linear, iterative, bounded.**
   - The adversarial families, at 4096 and 8192 chars: `]`×n, `[`×n, `{"{"`×n, `"`×n, a whitespace run followed by a mismatched closer, and `"x" "{"id":`×k.
   - The repair takes ≤ 10 ms at 8192 (median of 5), t(8192)/t(4096) ≤ 3, and it never raises at any depth up to 8192.
   - **Amended by T-0129 (2026-10-24):** wall time under load was red in 177 of 360 trials, so the row now measures two things.
     - *Work:* traced line events, with L(2n)/L(n) ≤ 2.25 at n ∈ {1024, 2048}, which is deterministic.
     - *CPU:* `thread_time` with gc off, minimum of 5, sizes interleaved: ≤ 10 ms at 8192, and t(16384)/t(4096) ≤ 8.
     - *Families:* two are added, `"[{]" + ws run + "}"` and `"[" + "{"*(n-2) + "]"`, which catch two recursion mutants the old row missed.
   - On the 376 A0 canvases, the repair alone has p95 ≤ 1 ms and the whole gate has p95 ≤ 20 ms (baseline 13.2 ms).
6. **Streaming and multi-canvas (ruling A10).**
   - The repair keeps no state between calls.
   - For every real fixture body cut at each canvas boundary and at every 64th char, the gate does not raise, and every emitted string leaf is grounded in the union of that turn's bodies so far.
     *Delta (2026-10-17, T-0108b criterion 9(i)):* "string leaf" means every string **value**. A dict **key** in the catalog vocabulary of the enclosing component's kind is exempt, because the component stage may rename a key to its catalog property (`placeholder` → `label`). The exemption is per kind, never global. The reserved namespace (`__gate_<id>_label`, `__gate.clicked`) is the only exempt value.
   - The last call of every body yields the expected surface.
   - The existing progressive-render, deferred and restore tests pass unmodified.
7. **Nothing that fails validation reaches the renderer (negative).** A surface is emitted only when `report.ok`. For the D3 arm of 3ac00a1 (16 gated calls, 0 emitted, non-A2UI JSON), the re-score still emits 0.
8. **No per-trial regression (negative).** In both run dirs, no trial whose last call was OK under the 14cde78 gate (baseline fixture, criterion 13) fails under the new gate. At most 2 individual calls per run dir go from surface to no surface.
9. **The gate never raises (H-T108 (e)).**

## Implementation notes

- **Shape:** one left-to-right, string-aware pass with an explicit stack and bounded lookahead. No recursion, no backtracking regex, and no per-character work over the output buffer.
- **Edit rules:** only the four observed classes plus the closer rule. A mismatched closer is dropped when the expected closer follows; otherwise the expected closer(s) are inserted. A closer with no opener is dropped. Every decision is made outside a string, with escapes respected.
- **Partial-canvas rule:** at end of text, close nothing. json_repair closes truncations.
- **Grounding:** keep `_grounded(m, raw)` against the **original** `raw` on every path. The strict-parse early return stays only for text valid *before* repair.
- **Per-turn gate state:** unchanged. Repair the whole cumulative body on every call, with no caching.
- **Totality:** catch `RecursionError` and `ValueError` as "no A2UI message could be recovered", plus a nesting problem; a depth pre-check is also acceptable. `_grounded` and the validator recurse too.
- **session.py:** additive and local. Do not touch `_publish_final_surface` (criterion 11; T-0109 changes that path).
- **Contracts:** `GateResult` gains a defaulted field; no wire or fake change.
- **Out of scope:**
  - json_repair's quadratic cost on pathological input (H-T108 (f));
  - required-prop pruning (T-0108a);
  - executing resamples (T-0108b);
  - the seeded retry (T-0109).
- **Hook rules:** agents create no files outside their owned paths by any means.
- **Fast suite:** the serial run is already ~350 s against a 120 s ceiling, so new tests stay small.
