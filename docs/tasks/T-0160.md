## Goal

Today `--tools live` acts only on Gearvis's own loopback start pages: hostname fence, start-page origin allow-list, no egress.

After this task, a live session's agent browser can open public websites over https. This is **on by default in live** (ruling 2); `--no-web`, or `browser_web = false` in the profile, turns it off.

The web is reached through a new start page, `/web.html`, which has a web-address field. In web mode `Ctrl+T` and `Ctrl+L` bring the model back to it, so it can go somewhere else.

All of the browser's traffic goes through an in-process egress proxy bound to 127.0.0.1. The proxy resolves each host once and refuses these:
- loopback other than the start-page origin;
- private, link-local, CGNAT, multicast, reserved and documentation addresses, including IPv4-mapped, NAT64 and 6to4 forms;
- every port but 443;
- plain http.

It then connects to the exact address it checked.

The guards:
- **Profile.** The browser keeps a fresh, ephemeral profile per session, with no saved logins or cookies. A user data dir is refused in web mode.
- **Passwords and cards.** The executor deterministically refuses to type into a password or card field, and refuses to type a card-like digit string anywhere.
- **Clipboard.** Pasting is off in web mode, because headed Chromium's clipboard is the user's.
- **Files.** Downloads and uploads stay blocked.
- **Sandbox.** Chromium runs with its sandbox on in web mode, or web mode refuses to start.
- **Confirmation.** T-0107a ask-first and T-0107e honour-no apply unchanged. There is no new confirmation gate.

The injection risk is stated in a startup notice, on `/web.html`, and in the README (ruling 3).

## Acceptance criteria

**Definitions.**
- **Web mode:** `BrowserToolExecutor(..., web=True)`, built by `cli` for `--tools live` unless `--no-web` or the profile's `browser_web = false`.
- **Start origin:** the `StartPageServer` origin `http://127.0.0.1:<port>`.
- **Public address:** an IP address for which `fence.is_public_address` is true (A-1).
- **Secret field:** a focused element that `fence.secret_field` classifies as `"password"` or `"card"` (A-4).
- **Card-like:** text holding a run of 13–19 digits, optionally separated by single spaces or hyphens, that passes the Luhn check (A-3).

### Group A: the fence and the egress proxy (pure plus asyncio; no Playwright)

**A-1. `fence.is_public_address(ip: str) -> bool`.** True only for a globally routable unicast address.

It is false for all of these:
- loopback, unspecified, private (RFC 1918, `fc00::/7`), link-local (`169.254/16`, `fe80::/10`), CGNAT `100.64/10`;
- benchmarking `198.18/15`, documentation, multicast, broadcast, reserved;
- IPv4-mapped (`::ffff:a.b.c.d`), NAT64 `64:ff9b::/96`, 6to4 `2002::/16` and Teredo, whenever their embedded IPv4 is not public.

Unparseable input is false. The function is total and never raises (Hypothesis).

**A-2. `fence.web_url_allowed(url: str, start_origin: str) -> bool`.** True for exactly these:
- (a) a URL whose `scheme://host:port` is the start origin (T-0111g's exact-origin rule, reused);
- (b) an `https` or `wss` URL with no userinfo, port absent or 443, whose host passes the checks below.

The host checks for (b):
- If the host is an IP literal in any WHATWG-parsable form (dotted quad, single decimal `2130706433`, hex `0x7f.1`, octal `0177.1`, short `127.1`, bracketed IPv6), it must be public.
- If it is a name, it must have at least two labels, and its last label must not be numeric or `0x…`.
- It must not be `localhost`, `*.localhost`, `*.local`, `*.internal`, `*.lan`, `*.home.arpa`, `*.localdomain` or `*.test`.

Everything else is false: `http:` (other than the start origin), `ws:`, `file:`, `chrome:`, `about:` other than `about:blank`, `data:`, `blob:` and `javascript:`.

`is_loopback_url`, `egress_record`, `check_profile_dir` and `runtime.url_allowed` are unchanged (differential with BASE, A-7).

**A-3. `fence.card_like(text: str) -> bool`** follows the definition above. It is pure, linear and total. False rows: a 10-digit phone, a date, a 12-digit number, a 16-digit Luhn-invalid number.

**A-4. `fence.secret_field(attrs: Mapping[str, str]) -> Literal["password", "card"] | None`**, over the keys `tag, type, autocomplete, name, id, aria_label, placeholder, label`. All matching is case-insensitive.
- **`"password"`** when either holds:
  - `type == "password"`;
  - the autocomplete tokens include `current-password` or `new-password`.
- **`"card"`** when any of these holds:
  - the autocomplete tokens include `cc-number`, `cc-csc`, `cc-exp`, `cc-exp-month` or `cc-exp-year`;
  - `name` or `id`, lowercased with non-alphanumerics stripped, contains one of `cardnumber`, `ccnumber`, `ccnum`, `cardnum`, `cvc`, `cvv`, `csc`, `securitycode`, `cardexpiry`, `ccexp`, `expdate`;
  - `aria_label`, `placeholder` or `label` contains `card number`, `security code`, `cvc` or `cvv`.
- **`None`** otherwise. Negative rows: `name=giftcard_search`, `name=postcode`, `autocomplete=cc-name`, `type=search`.

**A-5. `EgressProxy` (`local_astra/computer/egress_proxy.py`, new).** An HTTP CONNECT proxy on its own thread and its own asyncio loop, bound to `127.0.0.1:0`. It has `start()`, `stop()` and `.origin`.

Constructor seams: `start_origin`, `on_blocked(record)`, `on_host(host)`, `resolve` (default `getaddrinfo`) and `connect` (default `asyncio.open_connection` to an IP literal).

- **(a) Allowed tunnels.** `CONNECT host:443` resolves the host once. If every resolved address is public, it connects to one of those exact addresses, replies `200`, and pipes both ways. `on_host(host)` gets the host only.
- **(b) Refusals.** Each of these gets a `403` and `on_blocked(fence.egress_record("https://host/"))`, with no connect attempted:
  - any resolved address is not public;
  - the port is not 443;
  - the target is loopback, other than the start origin's port when P1 shows the start pages go through the proxy.

  A resolution failure is `403` and logged the same way.
- **(c) Other request forms.** An absolute-form plain-http request is refused (`403`) unless its origin is the start origin (only if P1 needs it). Malformed request lines are `400`, and request heads over 8 KiB are `400` and close.
- **(d) Caps.** At most 64 concurrent tunnels (more is `503`). Idle tunnels close after 60 s.
- **(e) Shutdown.** `stop()` closes the listener and every tunnel within 1 s and joins the thread.
- **(f) Address passed to `connect`.** `connect` receives the checked IP literal, never the hostname.
- **(g) Resolution count.** The resolver is called exactly once per CONNECT (no TOCTOU).

**A-6. Thread safety.** `on_blocked` and `on_host` may run on the proxy thread. Under 8 concurrent tunnels, every record reaches the consumer, with no loss and no duplicate.

### Group B: web mode in the runtime and executor

**B-1. Launch in web mode.** `PlaywrightDriver(..., web=True, start_origin=…, proxy_resolve=None, proxy_connect=None)` does the following:
- starts an `EgressProxy` before the launch and stops it at teardown and close, including when a launch fails or is cancelled;
- launches with `proxy={"server": proxy.origin}` and the bypass rules P1 settles;
- passes `chromium_sandbox=True`;
- adds `--disable-quic`, and keeps every flag P1 shows still works with the proxy.

The context routes are rebuilt so that:
- start-origin requests keep T-0111g's no-redirect fetch;
- public URLs (`web_url_allowed`, (b)) are `route.continue_()`, so Chromium fetches them through the proxy and follows redirects through it;
- everything else is aborted and logged as BASE.

`web=False` launches exactly as BASE: no proxy, the same args and routes.

**B-2. Fresh profile.** In web mode, a `user_data_dir` given to `BrowserToolExecutor` raises `ValueError`, whatever the path. Each launch, including a relaunch after a crash, is a new non-persistent context.

**B-3. Password and card guard (deterministic, in the executor).**
- **(a) Card-like text.** A `type_at` whose `text` is card-like is `refused` with `CARD_TEXT_REASON` before anything is dispatched. This holds in every mode.
- **(b) Check after the click.** For a `type_at` that passes (a), the executor clicks, then reads the focused element through the driver's optional `focused_field()`. It walks into same-origin and cross-origin frames and open shadow roots, and is bounded by `FOCUS_TIMEOUT_S` (0.5 s) inside `ACTION_TIMEOUT_S`. This runs before any keystroke.
- **(c) Secret field.** If `secret_field(attrs)` is not `None`, the outcome is `failed` with `SECRET_FIELD_REASON`. No `type_text` is dispatched, no Enter is pressed, the frame is re-captured, and `resolved` has `secret_field: "password"|"card"` and `typed: 0`.
- **(d) Fail closed in web mode.** In web mode, a missing `focused_field`, a timeout or an exception is the same `failed` with `FOCUS_UNKNOWN_REASON`.
- **(e) Outside web mode.** With `web=False` and a driver class lacking `focused_field`, the BASE path runs unchanged. The real `PlaywrightDriver` always has it, so the guard runs on loopback too.
- **(f) Overview frames.** The overview-frame path (`_act_on_overview`) applies (a)–(d) identically.
- **(g) Logged text.** On any guarded outcome, no value in `resolved` contains the typed text.
- **(h) Wording.** `SECRET_FIELD_REASON = "will not type into a password or card field; ask the user to type it themselves"`.

**Named spec change:** T-0111c criterion 1's `failed` now also covers "a `type_at` the executor stopped after its click because the focused field is a secret field or could not be checked".

**B-4. Navigation without a new tool.**
- In web mode, `press_key` `Ctrl+T` or `Ctrl+L` navigates the active page to `<start origin>/web.html`, settles, captures, and is `executed` with action `opened the start page`.
- In web mode, `Ctrl+V` is `refused` with `"pasting is off on real websites"`.
- With `web=False`, `Ctrl+T`, `Ctrl+L`, `Alt+Tab` and `Ctrl+W` are refused exactly as BASE (`tests/unit/test_computer_executor.py` rows unedited), and `Ctrl+V` dispatches as BASE.
- `tools_v1.json` is unchanged.

**B-5. `/web.html` (new).**
- It has one labelled web-address field, autofocused, and a Go button.
- Its JS adds `https://` when no scheme is given and upgrades `http://` to `https://`. It visibly refuses any other scheme, any input with spaces and any input with no dot ("Type a web address like en.wikipedia.org"). Otherwise it calls `location.assign`.
- It carries the notice text of C-7.
- Security never depends on this JS (B-7 (e)).
- `index.html` and the other pages are byte-identical.

**B-6. What is logged.**
- **Blocked attempts** go to the existing `egress_log` (B15's `browser_egress_blocked` on the turn line). This covers route refusals and proxy refusals, `{host, scheme}` only.
- **Each executed action's `resolved["hosts"]`** is the unique hosts the proxy tunnelled since the previous action, host only, at most 32, with `hosts_more: <n>` beyond that.
- **Guarded outcomes** carry their reason and `secret_field` kind, never the text.
- No URL path, query or fragment is recorded anywhere (T-0111g B15 invariant).

**B-7. Browser e2e, fenced (marker `browser`).** The real executor in web mode, with an injected proxy resolver/connector and loopback fixtures posing as `*.example` hosts:
- **(a) Navigation.** Typing `shop.example` into `/web.html` reaches the fixture page.
- **(b) Password field.** `type_at` on a password field is `failed`, and the field's value is empty afterwards. On the username field it is `executed`.
- **(c) Card fields.** These are `failed`, value empty:
  - `type_at` on an `autocomplete=cc-number` field;
  - a card field inside a cross-origin iframe;
  - a field that switches `type` to `password` on focus.
- **(d) Redirects to loopback or private addresses.** A public-posing page that redirects (302) to `http://127.0.0.1:<canary>/`, or to a name resolving to `10.0.0.5`, never reaches the canary or the connector: 0 accepts and 0 connects. Both are in the egress log.
- **(e) Subresources to loopback ports.** `fetch`, `img`, `iframe`, `WebSocket` and `location=` from a public-posing page to a second loopback port (standing in for vLLM and the HUD): 0 accepts.
- **(f) Files.** A download link is reported under `blocked: download` and no file exists. A file-input click is reported under `blocked: file_chooser` and no file is set.
- **(g) Navigation keys.** `Ctrl+T` from a public-posing page shows `/web.html`.
- **(h) No phone-home.** With the browser idle on `/web.html` for 5 s, the proxy sees 0 CONNECTs.
