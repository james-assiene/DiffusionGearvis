## Goal
Build a small, labelled eval set of the real tools and a driver that runs pass 1 once per case, then every pass-2 arm on the same pass-1
output, paired. Every number T-0080c needs gets recorded: accuracy, schema validity, CS, wall per pass, steps and prefix-cache hit.

## Acceptance criteria
1. **Eval set** (`tests/eval/toolcall/`, authored by the test-author from this spec, reviewed by the human at H-T80): 120 tool cases
   plus 20 no-tool conversational cases.
   - **Tool cases:** 30 `google_search` (keywords as ground truth), 30 `click_at`, 30 `type_at`, 15 `scroll`, 15 `press_key`.
   - **Screens:** each computer-control case carries one screenshot (1280 long side, JPEG like the product's resolution policy) and the target
     bbox in 0–999 coordinates.
   - **Split:** stratified by tool, fixed in the file: dev 40 (+ 8 no-tool) and test 80 (+ 12 no-tool). The split's sha256 is pinned in a MANIFEST.
   - **Synthetic screens:** generated deterministically from local HTML pages rendered offline (no network, file:// only) with bboxes read from the DOM;
     the generator is committed beside the set. Whether to use synthetic screens or desk captures is Q4.
2. **Prompting.** One fixed system prompt for both passes: the tool instructions, the v1 declarations as text, and the `<cc>` convention
   (Q3). Its sha256 goes in the regime. `enable_thinking: true` in both passes. The image list is identical across the passes of a case. No `tools`
   request field unless Q3 says native.
3. **Driver** (`local_astra/eval/cd/twopass.py`, CLI `scripts/gpu/cd_toolcall.py`).
   - **Pass 1:** sent once per case (unconstrained, `max_tokens` 1024), routed with `toolcall.router`.
   - **Pass 2:** for each arm in the run's arm list, in an order rotated per case (T-0011 R17), the driver builds the pass-2 request for the
     thought variant (T1: same messages, `max_tokens` 1024; T2: same messages, 256; T4: messages + assistant prefix up to `<cc>`,
     `continue_final_message`, 256) and the scope (`union`, or `named` = the draft's tool if `draft_name` is valid, else union). The CD
     xargs come from `arms.cd_xargs` (read-only) with the knobs from `docs/cd/calibration-bfcl*.json` through `load_frozen(arm=)`.
   - **Derived policies, computed offline from the same rows with no extra requests:** `draft_only` (pass 1's draft parsed and scored, no pass 2) and
     `cd_on_invalid:<arm>` (the draft if schema-valid, else that arm's pass-2 result; latency adds pass 2 only on invalid drafts).
   - **Row contents per case and arm:** ids, text, route, parse, schema_valid, exact, CS by host replay with the request's automaton,
     wall_ms of pass 1 and pass 2 (send to last byte, loopback, concurrency 1), executed steps per canvas from the `ASTRA_CD`
     records joined on `record_tag`, bucket, the position of `101` for T1, and prefix-cache hit tokens for the request.
4. **Guards.**
   - Loopback-only base URL (`runner.check_loopback`).
   - Refuses a dirty tree.
   - Refuses a frozen file whose arm is not the arm's source.
   - An `http_error`/`timeout` row is an engine stop: report written, exit 1 (T-0071b C9/C12).
   - Any constrained terminated row with CS ≠ 1 or a loud error (`z0`, `empty_delta`, `infeasible`, `internal`) stops the run (T-0071 criterion 11 pattern).
   - Bucket histogram per (scope, thought) printed on CPU before the first request.
5. **Report** (`twopass.report`, from artifacts only), per arm, stage and tool:
   - exact and schema_valid with Wilson CIs;
   - pass-2 and end-to-end wall p50/p90;
   - mean/p90 executed steps;
   - prefix-cache hit fraction;
   - route recall on tool cases and false-tag rate on no-tool cases;
   - McNemar against `draft_only` and between CD arms (both-parsed restriction reported).
   The selection rule of T-0080c is implemented here as a pure function `select(rows, rule)` and unit-tested.
6. **Locked script** `scripts/locked/t0080_toolcall.sh`, t0071b pattern:
   - refusals;
   - `make plugin-wheel`;
   - engine-only `services/vllm.sh` (prefix caching is on there; check);
   - `/health`;
   - `--stage dev|test`;
   - `--stage test` refused unless a `selection-dev.json` from the same SHA's dev stage is given;
   - real exit code captured;
   - `nvidia-smi … || true`.
7. *Negative:* `local_astra/eval/cd/{runner,arms,calibration,cuts,hardstop}.py`, `plugin/**`, `local_astra/conductor/**` are unchanged. No
   request leaves loopback. `google_search` is never executed.

## Implementation notes
- Prefix-cache evidence: read `/metrics` (loopback, same port) before and after each pass-2 request at concurrency 1. Check
  (unverified) the v0.29.0 counter names (`vllm:prefix_cache_queries`/`_hits` or similar) on a boot before relying on them. If none
  exist, report the hit as unavailable; never guess it.
- Check (unverified) that `continue_final_message` works on v0.29.0 for this model with `--reasoning-parser gemma4`. The parser
  may file the continuation under `reasoning`. The driver scores from `return_token_ids` decoded by the host, never from the parsed
  fields.
- Executed steps: the record's `steps` is the step counter at commit. With T-0081's `draft_start_step` k0 > 0, executed steps =
  steps − k0. Compute it in one place.
- Memory: T1 with per-step CD over several canvases at bucket 256 is the peak. Serial only; print free memory after boot.

  computed over **tool cases**; no-tool cases are reported separately (false-tag rate, their wall).
- **Routing** is on the model's answer only, never on the case label: a no-tool case whose answer contains `<cc>` gets a pass 2 and counts as a
  false tag.
- **APIs confirmed:** `twopass.select(rows, rule)`, `twopass.run(TwoPassConfig(...))`, `twopass.derive(rows, policy)`, the artifact layout,

## Implementation log (implementer, 2026-10-08, branch `T-0080b-impl` from 1886148)
- **`local_astra/eval/cd/twopass.py`.** `run(TwoPassConfig)` as ratified (+ defaults `request_timeout_s` 600, `record_wait_s` 5,
  `flush_wait_s` 2, `max_states` 512, `whitespace` json) -> `TwoPassResult(exit_code, artifact, stopped, n)`. Order of guards:
  `runner.check_loopback`, stage/cells (`<T1|T2|T4>/<named|union>/<end_projection|perstep_mar|perstep_mar_qargmax>`), per Mar arm
  `calibration.load_frozen(path, task="bfcl", arm=arm)` (wrong source or missing file: `ValueError`), `cases.jsonl` sha256 must equal
  `MANIFEST.json`'s `cases_sha256` (`ValueError`) -- all before any socket; then `hardstop.check_tree` (dirty/mismatch: artifact with
  `stopped`, exit 2, no request); then the bucket print, `GET /v1/models` (no answer: engine stop, exit 1), the loop.
- **Requests.** Pass 1: system (`twopass.SYSTEM_PROMPT`: instructions, the `<cc>` convention, 0-999 coordinates, `tools_v1.json`
  declarations as indented JSON) + user (`[image_url (data:image/jpeg;base64), text]` with a screen, else a string), thinking on,
  1024, `return_token_ids`. Pass 2 per `pass2_body`: T1/T2 = a deep copy of pass 1's body + `vllm_xargs` + `max_tokens` 1024/256;
  T4 = + assistant `spoken_prefix + "<cc>"`, `continue_final_message` true, `add_generation_prompt` false, 256. Cell order rotated by
  the routed-case count (k-th routed case starts at cell k mod n). Record tags `t0080b.<run_id>.<case>.<cell>.<request>`.
- **Routing and scoring from ids.** Pass-1 and pass-2 texts are `replay.detokenize` of the returned `token_ids` cut at the first stop
  id; `router.route` on that text (so an unclosed thought routes `none` even when the served `content` shows the tag). Missing
  `token_ids` is an engine stop. Pass-2 call text = the answer channel with a leading `<cc>` dropped; `score.parse_call` /
  `schema_valid` / `exact` (case `gt`; no-tool case: exact False). Name picker: `route("<cc>" + picked text).draft_name`; no v1 name ->
  row error `picker_no_name`, no second request.
- **CS and the join.** Per request: records joined on the tag (E9 flushes as the runner), executed steps per canvas via
  `executed_steps(steps, k0=0)` (the one place; k0 = T-0081's `draft_start_step` when it exists), host replay of the committed ids
  through that request's automaton; the row's `cs` is the AND over its requests. **Added check (unverified on the engine):** the
  served `token_ids` must equal the records' committed ids up to the first stop, else `join_error`.
- **Stops (exit 1, `stopped` in the trailer, rows so far kept):** `http_error`/`timeout` (pass 1 or 2), no `token_ids`, `join_error`
  (my choice: the guarantee needs every constrained row replayed, so an unjoinable row stops rather than being scored), loud
  `z0`/`empty_delta`/`infeasible`/`internal`, replay != plugin `in_final`, terminated output rejected by replay. Quiet record errors
  (`bucket_too_large` ...) and `too_large` (> `max_states`) are row errors and the run goes on.
- **Prefix cache.** `/metrics` at the server root before and after each request (pass 1 too), `vllm:prefix_cache_{queries,hits}_total`
  summed over label sets; `prefix_hit_tokens`/`prefix_query_tokens` are the deltas (sum over a picker's two requests), `None` if the
  endpoint or a counter is absent.
- **Rows.** Pass 1: `pass, case, kind, tool, error, wall_ms, prefix_*, token_ids, text, route{kind, tag, draft_name, spoken_prefix},
  draft_call_text, draft_parse, draft_call, draft_schema_valid, draft_exact`. Pass 2: `pass, case, cell, thought, scope, arm, scopes,
  requests, record_tags, text(s), committed_ids, parse, call, schema_valid, exact, cs, error, wall_ms (+ per request), steps (+ per
  request), bucket(s), n_states, close_101_pos (T1: index of 101 in the final request's committed ids), prefix_*, flush_requests,
  knobs`.
- **`derive(rows, policy)`** for `draft_only`, `cd_on_invalid:<cell>`, `cd_always:<cell>` and a bare cell (= cd_always, named after the
  cell, the stage-1 input). Row `steps` = total executed steps of the pass 2 (0 without one); a routed case whose pass-2 row is missing
  is `missing`, not schema-valid.
- **`select(rows, rule)`** exactly as the module docstring of `test_twopass_select.py` reads the rule; all comparisons in `Fraction`
  (exact rate, `best - 1/10` / `1/20`, `median <= 21/20 * min`, mean steps). Stage 1 candidates are only `T*/named/perstep_mar`;
  stage-1 mean steps over the cell's rows with a pass 2, stage-2 mean steps over tool cases. Median = `statistics.median`; p90 =
  nearest rank (`ceil(0.9 n)`-th smallest).
- **`report(paths)`** (dict) + `render_markdown`: per policy overall and per tool -- exact, schema_valid, CS with Wilson 95 %; pass-2
  and e2e (tool cases) p50/p90, no-tool e2e separately; steps mean/p90; prefix hit pooled and median fraction; route recall (also per
  tool) and false-tag rate; exact McNemar vs `draft_only` and between cd_always cells, both-parsed restriction beside, Bonferroni
  over the report's own family; T1 `101` histogram; pass 2 equal to a valid draft and repair rate on invalid drafts (T-0080c 6);
  and the stage's `select` result.
- **CLI `scripts/gpu/cd_toolcall.py`.** `--stage dev` (default the three stage-1 cells) writes `report-dev.{json,md}` and, on exit 0 with
  a choice, `selection-dev.json` (`stage, rule, choice, commit, expected_commit, head, artifact, artifact_sha256, cells, policies`);
  `--stage test --selection` refuses (exit 2) a selection whose `commit` is not `--expected-commit`, and runs the chosen
  (thought, scope) under `end_projection`, `perstep_mar`, `perstep_mar_qargmax` (the T-0081 seeded arm is not wired). Default
  calibration files `docs/cd/calibration-bfcl.json` and `-perstep_mar_qargmax.json`.
- **Locked script `scripts/locked/t0080_toolcall.sh`** (t0071b pattern): REFUSED/exit 2 for no/unknown stage, dirty tree, `--stage
  test` without a `--selection` whose `commit` (and `stage == dev`) matches HEAD, `services/vllm.sh` changed since 806da12 (it has

## Implementation log, R-W and the run-crash advisory (implementer, 2026-10-08, branch `T-0080b-impl-2` from 18094b9)
- **R-W.** `twopass.williams_orders(k)`: row 0 = `0, 1, k-1, 2, k-2, ...`, row i = row 0 + i mod k; odd k appends the k mirrored rows. The
  driver takes row `routed % len(rows)` (routed-case count) instead of the cyclic rotation. Checked for k = 2..6: every ordered pair
  adjacent exactly once (even k) / twice (odd k), each cell first equally often; k = 3 gives `[0,1,2] [1,2,0] [2,0,1] [2,1,0] [0,2,1]
  [1,0,2]`. The old rotation row (`test_pass2_order_is_rotated_per_case`) is red until the test-author's balance row lands.
- **Advisory.** Any exception inside `run` after the artifact is opened (bucket print, `/models`, the loop) now ends the run with
  `stopped = "crash: <last line>"`, the traceback in the trailer (and on stderr), exit 1 — so the CLI writes the report; exit 2 stays for
  the pre-request refusals (`ValueError` before the artifact, dirty tree / commit mismatch).
