## Goal

A correct client never puts `<|channel>…<channel|>` in a `thought_open=False` answer commit. A buggy client or stream can, and today, with tools on, the session voices that thought's words and stores them in history:
- the T-0092c answer cleaner runs `drop_special_literals`, which deletes the markers and keeps the words in between;
- so `Sure, <|channel>thought SECRET<channel|>here it is.` is spoken and stored as `Sure, thought SECREThere it is.`;
- this happens at every voiced step: step 1 on `main` today, and step 1 and the report step with `--tool-loop`.

After this task, the tools-on answer cleaner removes thought blocks before it releases anything, using the router's own thought rule:
- a closed block is removed with its markers and its words;
- everything from a `<|channel>` that nothing later in the stream closes is dropped;
- the words around a block are kept, byte for byte.

It applies to:
- the streamed release (`feed`), the end-of-stream release (`flush`) and `spoken_prefix`, so voice, `TtsSpeak.source`, `astra.spoken`, history, the `tool.call` record and the repair seed agree;
- one `note` per stream that dropped anything, giving the dropped character count and never the text.

When no thought marker appears in a tools-on answer stream, output stays byte-identical to `c7e04f0`. That covers the loop-off and loop-on turns of the base differential (criterion 9), since T-0114 left the loop off by default. The tools-off path does not change at all.

## Acceptance criteria

The test plan's P4 is the thought splice: "no unclosed-thought text is ever voiced or stored". These criteria extend it from `thought_open=True` commits to thought markers inside `thought_open=False` answer text. They also apply CLAUDE.md ("never voice text the LLM has not committed … inside an unclosed thought"; "never store assistant thinking in history") and `.claude/rules/conductor.md` (thought text never reaches TTS, history, `astra.spoken` or HUD panes; it is logged only in the session log's `llm.commit`).

Throughout, **C(raw)** is the cleaned text of the concatenated raw `thought_open=False` answer texts of one stream. It is defined in criterion 1.

1. **The cleaned text C(raw) (I4 amended).** The cleaner applies these to the concatenation, repeated until none of them changes the text:
   - delete every special literal other than the two channel markers;
   - remove each closed block `<|channel>…<channel|>`, where the first `<channel|>` after an open closes it (the router's rule; H-T117-3);
   - truncate at a `<|channel>` that nothing after it closes.

   Then it applies `drop_special_literals`, which also removes stray `<channel|>` markers.
   - Removing a block inserts nothing. The bytes before and after it are kept exactly, including whitespace (H-T117-2).
   - A literal or marker spliced together by a deletion is handled like one that was written in full.
2. **Voiced step 1, loop off (P4; CLAUDE.md).** Tools on (default kit), `tool_loop` off. Step-1 commit `answer("Sure, <|channel>thought SECRET-THOUGHT<channel|>here it is. ")`, with no call:
   - every `TtsSpeak.source` and `.text` joins to exactly `Sure, here it is. `, and so do the `astra.spoken` texts, the audio plays' sources and `history[-1].assistant_spoken`;
   - `SECRET-THOUGHT`, `thought SECRET`, `<|channel>` and `<channel|>` appear in none of them, nor in `turns.jsonl` or the memory episodes.
3. **Voiced step 1 with a call, loop off.** Step 1 is `answer("Let me look. <|channel>thought SECRET-THOUGHT<channel|>")` followed by a valid call:
   - voiced and stored text: `Let me look. `;
   - the `tool.call` record's `spoken_prefix` holds no `SECRET-THOUGHT`.

   With a repairable draft:
   - the repair request's continued assistant text holds no `SECRET-THOUGHT`;
   - `call.spoken_prefix` equals C(raw).
4. **Voiced step 1, loop on.** Same as criterion 2 under `TurnPolicy(tool_loop=True)` (a final answer at step 1, no call).
5. **The report step, loop on.** Step 1 is a prefix plus a search call. The step-2 report is `answer("Found it: <|channel>thought SECRET-THOUGHT<channel|>the café opens at nine. ")`:
   - the report's voiced and stored text is `Found it: the café opens at nine. `;
   - nothing of the thought is voiced, stored, published or in any later step request (T-0114 criterion 5 still holds).
6. **Unclosed at the end (P4).** A stream ending with `answer("Okay. <|channel>thought SECRET-THOUGHT")`, with `thought_open=False` (the buggy-client case):
   - voices and stores `Okay. `;
   - releases nothing after the open marker, neither during the stream nor at `flush`.

   If a later commit in the same stream closes the block, the text after the close is voiced (`Okay. <|channel>x` / `y<channel|> fine. ` → `Okay.  fine. `).
7. **Streaming and chunk independence.**
   - The concatenation of every `feed` output plus `flush` equals C(raw) for every way of splitting raw into commits.
   - No `feed` output, read at the moment it is returned, ever contains thought text.
   - Every released prefix is a prefix of C(raw): released text only grows (I12).
   - The I12 hold still releases ordinary text before `llm.done`, so the T-0092c test `test_i12_p5_a_maths_answer_is_voiced_before_pass1s_llm_done` stays green.
8. **The note.** One session-log `note` per stream whose thought stripping removed at least one character, written at the end of the stream before `llm.done`:
   - `{"what": "thought text in an answer commit was not voiced", "request_id": <machine id>, "step": k, "chars": n, "unclosed": bool}`;
   - `chars` is the number of characters removed by the thought stripping, markers included. For criterion 2 it is `len("<|channel>thought SECRET-THOUGHT<channel|>")`;
   - no key of the note holds any substring of the thought;
   - no note is written when nothing was removed;
   - the `llm.commit` records keep the raw text verbatim. Thinking is logged (`.claude/rules/conductor.md`), so this does not change.
9. **Negative: byte-identical when no marker appears (differential against the literal base `c7e04f0`).** The scenarios below run at `c7e04f0` (`git archive c7e04f0`, run in a subprocess, origin checked, as in T-0114's `_base_tree`/`_BASE_RUNNER`) and on the branch. The machine steps, HUD messages, prompts, request bodies, every session-log record and the `turns.jsonl` lines must be equal. Scenarios:
   - tools on, loop off: a toolless turn; a tool turn with a spoken prefix and a valid call; a repairable-draft turn with a repair; and an answer with `Press <back> now. `, a literal split across commits (`Press <|tool` / `_call> now. `), a held tail across a `thought_open=True` commit (I15), the plain word "thought" (`I thought so, and I still do. `), a partial `<|chan` that never completes, and a stray `<channel|>` with no open;
   - tools on, loop on: a two-step search turn.
10. **Negative: other paths unchanged.**
    - The tools-off path does not go through the cleaner. `test_session_tools_off_golden.py` stays green unedited.
    - `thought_open=True` commits still bypass the cleaner unchanged (I10, I15).
    - `step_text` is still `router.route(cleaner.raw).spoken_prefix`.
    - T-0114's `test_loop_off_records_equal_base` (d3bc6ce) and `test_machine_and_contracts_byte_identical_to_base` (the `PINNED` hashes) stay green unedited.
    - `turn_machine.py`, `speech_gate.py`, `local_astra/contracts/**` and `tests/fakes/**` are byte-identical to `c7e04f0`.
11. **Negative: the router's routing is unchanged.** For any `str` `x`, `route(x)` and `route(x, thought_open=True)` on the branch equal the `c7e04f0` router's (a Hypothesis differential). `template_content` is unchanged. `tests/unit/test_toolcall_router.py` stays green unedited.
12. **The word "thought" is speech.** `I thought so. ` (no marker) is voiced and stored verbatim. A cleaner that matches the word instead of the markers fails here.

## Implementation notes

- This is a guard against a buggy client or stream. `llm_client` already splits thoughts out (docs/02 §5). Do not change the client or the gate to make tests pass.
- Do not use `router.route()` for the cleaner. It cuts at the first `<cc>`/`<genui>`/`<|tool_call>` tag, and normal answer text containing one would change (criterion 9). Use the new router helper, which shares `_strip_closed_thoughts`'s rule.
- I12's hold argument still applies, but only on C(raw). A character that is outside `_LITERAL_CHARS`, or is a `>`, and lies before any open marker, can never be deleted, spliced, or end up inside a later thought. Everything after an unclosed open is withheld, because C(raw) is truncated there. Prove monotonicity with the property test rather than by argument.
- Count `chars` from the thought stripping step, not as `len(raw) - len(C(raw))`, because literal deletions are not thought text. One note per stream, written in `_end_tools_on_stream` before `llm.done`, so loop steps and withheld steps are covered too.
- Mypy strict applies. The machine stays pure and untouched (`TURN_MACHINE_SHA256` pinned). Commits that clean to nothing are still not submitted (`test_i13_m26`).
- Do not write around hooks: no heredocs to the scratchpad. If a test looks wrong, tell the reviewer.
