## Goal

The model is told its name is Gearvis, and the strings users read about its browser say Gearvis. `session.DEFAULT_SYSTEM_PROMPT`, `twopass._PROMPT_HEAD` and `twopass.NATIVE_SYSTEM_PROMPT` change only in the persona sentence ("You are Astra, …" → "You are Gearvis, …"), byte for byte otherwise. The `--tools` help and `tools_refusal` say "Gearvis's own sandboxed browser". Tests that pinned the old text keep their meaning: content pins are re-pinned by a stated generator, golden diffs keep their historical fixtures and allow exactly one declared difference, and frozen-harness tests run the harness with the persona it had at its merge commit and also show the harness refuses today's text.

Unchanged here: the package name, the `astra` CLI command and prog (T-0156), `astra.*` wire types, `ASTRA_*` env vars, the plugin's `Astra*` class names, the HUD and the start pages (T-0155b).
