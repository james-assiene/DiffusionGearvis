## Goal

The T-0134 locked A/B at e59aa69 measured, per arm (n = 100):

| Arm | What | Success | S4 | False claims (non-S4) | Over-clicks | coord mismatch |
|---|---|---|---|---|---|---|
| A | pixel echo, no label | 61/100 | 0/20 | 25 (5) | 4/60 | 4 |
| B | echo in model units + label | 64/100 | 0/20 | 24 (4) | 3/60 | 0 |
| C | B + page extent | 70/100 | 0/20 | 25 (5) | 2/60 | 1 |

Regime: lean, CL 256, 48 steps, thinking on, NVFP4 rev 2ea8372, vLLM 0.29.0, `vllm.sh` 806da12, tools native bbfc53ccdd80, `LIVE_TOOL_GUIDANCE` 768a973b, 1120 visual tokens, ReGround off, headless Chromium 156 at 1280×800, 5 tasks × 20 per arm, order seed 0, concurrency 1, engine unseeded, STT down.

The label was `inconclusive`: arm C was ineligible after one engine timeout. The human ruled on 2026-10-23 (James) that the live default becomes arm B. That means `BrowserToolExecutor(echo="model")` and `Session(live_feedback=LiveFeedback(screen_label=True, page_extent=False))`. The page extent stays available but off.

This task moves the default into `cli`, the only place defaults live (T-0132 R-f):
- a resolver `feedback_of` with a source (`flag` / `profile` / `default` / `unset`) per value;
- a startup line that states them;
- flags and profile keys to override them;
- `off` and `dry_run` unchanged.

## Acceptance criteria

**A1. Constants and profile keys (`config.py`).**
- Add `LIVE_DEFAULT_FEEDBACK: LiveFeedbackChoice = "label"` and `LIVE_DEFAULT_ACTION_ECHO: ActionEcho = "model"`.
  - `LiveFeedbackChoice = Literal["off", "label", "label+extent"]` and `ActionEcho = Literal["pixels", "model"]` are defined in `config.py`. `config` must not import `local_astra.computer` or `conductor.session`.
- `Profile` gains two fields: `live_feedback: LiveFeedbackChoice | None = None` and `action_echo: ActionEcho | None = None`. Every other field, type and default equals BASE.
- **Load refusals:**
  - an unknown value gives a `ValueError` naming the allowed values;
  - a non-`None` value with `tools != "live"` gives a `ValueError` naming `live` (the T-0131 `reground_without_live_refusal` pattern: no silent no-op).

**A2. Resolution (`cli.feedback_of(profile, args, mode) -> Feedback`).** `Feedback` is a frozen dataclass with:
- `live_feedback: LiveFeedbackChoice | None`, `live_feedback_from: GroundingSource`;
- `action_echo: ActionEcho | None`, `action_echo_from: GroundingSource`;
- `session_value() -> LiveFeedback | None`.

Rules:
- In the resolved mode `live`, each value is resolved independently: the flag, else the profile key, else the `LIVE_DEFAULT_*` constant with source `"default"`.
- With no flags and no keys: `("label", "default")` and `("model", "default")`.
- In `off` and `dry_run`, both values are `None` with source `"unset"`.
- `session_value()`:
  - `"label"` gives `LiveFeedback(screen_label=True, page_extent=False)`;
  - `"label+extent"` gives `LiveFeedback(True, True)`;
  - `"off"` gives `LiveFeedback(False, False)`;
  - in non-live modes it gives `None`.
- `feedback_of` is pure: it opens nothing and imports `local_astra.computer` lazily or not at all.

**A3. Flags.**
- `--live-feedback {off,label,label+extent}` and `--action-echo {pixels,model}`.
- An unknown value exits 2 through argparse.
- Either flag in a resolved mode other than `live` exits 2 with a message naming `live`, builds no graph, and starts no page server. This holds with `--dry-run` and without.

**A4. What is built.**
- `_start_live` builds `BrowserToolExecutor(..., echo=<resolved action_echo>)`.
- `_build_graph` passes `live_feedback=<feedback.session_value()>` to `Session` in live, and passes no `live_feedback` keyword in `off`/`dry_run`.
- By default:
  - an executed live `click_at` reads `clicked at (X, Y)` in the call's 0–999 units (T-0134 A2);
  - every live step request whose final user message carries the current frame has exactly one T-0134 A3 label after it;
  - no `Page beyond this screen` clause appears.

**A5. Saying it.**
- **(a)** In live, a new line is printed immediately after the `grounding` line, both under `--dry-run` and at a real start. With defaults it reads exactly:
  `astra session: feedback: live_feedback=label (default), action_echo=model (default)`.
  The values and sources follow A2, for example `live_feedback=label+extent (flag), action_echo=pixels (profile)`. Nothing is printed in `off`/`dry_run`.
- **(b)** The `--dry-run` tools line and `cli.tools_line(...)` are BASE's strings, byte for byte.
- **(c)** The turn line in live carries T-0134 A5's `live_feedback` dict on every turn (`{"screen_label", "page_extent", "echo"}`), now present by default because a `LiveFeedback` is always passed in live.
  - `--live-feedback off` gives `{"screen_label": false, "page_extent": false, "echo": <resolved>}`.
  - No `*_from` key is added to the turn line (ruling R-k).

**A6. `--live-feedback off --action-echo pixels` is arm A.**
- In live, compared with BASE's default live session for the same other flags, the request bodies and executor action strings are byte-identical.
- The turn lines differ only by the added `live_feedback` key.

## Implementation notes

- **Keep the default in `cli`** (T-0132 R-f, T-0134 R-d). `Session`, `BrowserToolExecutor` and every GPU harness keep explicit values and their own BASE defaults.
- **Reuse the shape of `Grounding`/`grounding_of`:** the same `GroundingSource` literal, the same source order and the same line style. Do not merge feedback into the `grounding` line: that would move T-0133's exact pinned literal.
- **Imports.** `feedback_of` needs `LiveFeedback` only in `session_value()`. `cli` already imports `Session`'s module, so import `LiveFeedback` from there. Do not import `local_astra.computer` at module level (the `off`/`dry_run` rule of `_start_live`).
- **Name.** It is `action_echo`, not `echo`. In this project "echo" is acoustic, as in duplex, headset vs speakers. The executor's keyword stays `echo` (T-0134's, frozen here).
- **`off` is `LiveFeedback(False, False)`.** T-0134 A1 allows it, `_live_label` places nothing for it, and the turn line records the state. Do not change `Session` to make that true. If it is not already true at BASE, stop and report.
- **No characters-per-token arithmetic** (B10). The implementer never edits `tests/`. No heredocs around a blocked Write. Never export `GIT_DIR`/`GIT_WORK_TREE`.
