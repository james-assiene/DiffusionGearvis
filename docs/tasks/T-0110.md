## Goal

The Stop hook runs `make fast-parallel` (`-n 8 --dist loadfile`), which measures **59.97 s** against a 60 s budget on an idle box. The canonical serial run measures **435 s** against a 120 s ceiling. The cost is repeated work, not coverage:

- **(A) Harness rows** run the real `UiGate` and jsonschema on the same `UI_EXAMPLE` canvas hundreds of times per row.
- **(B) Session-rig rows** spend wall time in real 0.3–1 ms `asyncio.sleep` calls that only yield between virtual-clock fakes.
- **(C) Stub HTTP services** each pay `serve_forever`'s 0.5 s poll on `shutdown()`.

This task removes those three repetitions without dropping, moving to another tier, marking or weakening any row.

**Targets:**

- parallel ≤ 45 s on an idle box (projection 36–40 s);
- serial ≤ 280 s (projection about 262 s).

The 120 s serial ceiling is **not reachable by test-only work** (H-T110-3).

## Implementation notes

- **Order:** A (memo), then C (stub), then B (rig), measuring after each. If B slips, A + C alone project about 350 s serial and about 48 s parallel, which misses criterion 1.
- **Memo key:** everything except `request_id`. Return a deepcopy.
  - Wrap `h.ui_reading` on the harness instance that `build_report` calls; it is looked up as a module global.
  - For `old_harness()` (the git-blob exec), wrap only the object built for that row.
  - Never cache across rows.
- **B's sites.** All of them must change, or producers starve:
  - `test_session_loop.py:488`;
  - `_hud_rig.py:560`;
  - `test_session_listening.py:157, 159, 712`;
  - `fakes/stt.py:219`;
  - `fakes/audio.py:194, 286, 296`.

  These real-thread waits stay as they are (T-0057 criterion 13):
  - `fakes/audio_device.py:611, 633, 757`;
  - `contract/test_audio_capture_conformance.py:65`;
  - `contract/test_audio_late_consumer.py:88`.
- **Landmine:** under `sleep(0)`, a poller runs about once per pump round instead of about three times. A "nothing voiced yet" negative row could become vacuous; M1–M5 exist to catch that.
- **C:** pass `poll_interval` to `serve_forever` in the fake only.
- **Measured and left alone:**
  - the audio, STT-client and cli_up real-thread or wall-window waits (about 80 s);
  - the hook subprocess modules (about 34 s);
  - `hud_static.py`'s 0.5 s poll (about 6.5 s; product code);
