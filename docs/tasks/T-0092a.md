# T-0092a — A playback run never outlives its turn; terminal events of an earlier turn's run are dropped before the machine

**Status:** done 2026-10-12 (verified at 34d23d6; rulings G1–G8) · **Blast radius:** high (audio path and session; two reviewers) · **Branch:** `T-0092a-stale-drains`
from `main` · **Depends on:** nothing. **Blocks:** T-0092b. Umbrella `T-0080d.md`, index `T-0092.md`. Origin: the T-0089 ruling T15
follow-up, and criterion 10 of the 2026-10-11 T-0092 plan. Human decision Q-a (2026-10-12): flush on turn close.

## Goal
Today a terminal playback event (`playback.drained`, `playback.stopped`) carries no run or turn identity, and a run can stay open
across a turn boundary.
- **The known path.** `_on_tts_error` emits no `PlaybackFlush`, so turn 1's audio run drains during turn 2, or is joined there by turn
  2's speech.
- **The effect today.** That drain marks turn 2 `playback_drained` early. A toolless turn 2 can then complete before its answer has
  played, and its history can carry turn 1's tail.
- **The effect once tools are on.** With a pending valid call, the same drain would execute the call before the answer has played.

After this task:
- every playback run has a session-minted run id and belongs to exactly one turn;
- a run still open when its turn closes is ended by the session;
- any terminal event that belongs to an earlier turn's run is dropped before it reaches `_note_event` or `machine.step`.

## Acceptance criteria
1. **Run ids.** The session mints a run id, monotonic per session, each time it starts a playback run: a `play()` while it holds no
   open run, clips included. It records the turn id of each run.
   - **Attribution.** Terminal events from `audio.playback_events()` are attributed, in arrival order, to the oldest run whose terminal
     has not yet arrived. Each run yields exactly one terminal (T-0006 criteria 7–8; `flush()` is idempotent).
   - **Scope.** This is session bookkeeping only. No contract, protocol, audio module or fake changes (criterion 6).
2. **A run never outlives its turn.**
   - **When.** A turn closes (`_rotate_turn` yields `closing`) while that turn's run is still open: no terminal has been received, and
     no `PlaybackFlush` has already been issued for it.
   - **What.** The session ends the run with `audio.flush()` after the closing tuple's commands have run. The run's terminal is then
     outstanding, and criterion 3 drops it.
   - **Rows:**
     - tts.error in SPEAKING;
     - llm.error in SPEAKING;
     - client.disconnected in SPEAKING;
     - a run that holds only the ack clip, still open when a THINKING turn ends;
     - the INTERRUPTED timeout path, where the machine has issued the flush but `playback.stopped` arrives late.
3. **Stale terminals are dropped.**
   - **Which.** A terminal attributed to a run whose turn is not the machine's current turn when the event is handled. When no turn
     is open, the terminal counts as stale.
   - **What "dropped" means:**
     - no `machine.step`;
     - no `astra.spoken.played`;
     - no span on any turn record;
     - `_playback_open` is unaffected unless that run is the newest.
   - **The log.** One session-log `note` records each dropped terminal: `{what: "stale playback terminal", run_id, run_turn,
     current_turn, type, played_ms, played_text}`.
4. **The reproduction** (T15, toolless form).
   - **Sequence.**
     1. Turn 1 speaks, gets `llm.done` and has its drain marked.
     2. `tts.error` ends turn 1.
     3. Turn 2 opens (typed), commits an answer and gets `llm.done`.
     4. Turn 1's drain arrives.
   - **Required.**
     - Turn 2 does not complete on that drain; it completes only on its own drain.
     - Turn 2's `HistoryTurn.assistant_spoken` holds no text from turn 1.
   - **Baseline.** The same sequence on `main` at the base SHA fails at least one of these. The test's docstring records that.
5. **The drain gate stays.** `_maybe_mark_drain` still marks only in SPEAKING with `llm_done` (T-0089 note). It is neither widened nor
   removed.
6. *Negative.*
   - **Unchanged files.** `contracts/**`, `conductor/audio_io.py`, `null_audio.py`, `turn_machine.py` and `executor.py` do not change,
     and neither do the semantics of `tests/fakes/audio.py`.
   - **Same-turn terminals.** They reach the machine byte for byte as today. `tests/contract/test_session_audio_seam.py` stays green
     and unedited; its point 3 is read as "every same-turn terminal".
   - **Golden.** Take a scripted session in which every run ends inside its own turn: a spoken turn, a typed turn, a UI action, an A2UI
     surface, and a barge-in with a timely `playback.stopped`. These must be identical to the base SHA:
     - machine events, commands and states;
     - HUD messages;
     - turn records;
     - LLM request bodies.
   - **Permitted differences.** In a session that does close a turn with an open run, the only permitted differences are the fake
     audio's call log (the added `flush`) and the added `note` records.

## Rulings (orchestrator, 2026-10-12, on the test-author's questions)
- **G1. A run with no turn.** A run minted while no turn is open has `run_turn = None`.
  - If its terminal is handled while still no turn is open, it is **same-turn**: delivered to the machine, as today.
  - If a turn has opened in between, it is stale.
  - This keeps `test_spoken_played_egress.py::test_a_clip_only_run_publishes_nothing_and_a_clip_mid_run_only_under_reports` green and
    unedited. The test-author adds the in-between row (an IDLE clip, then a turn opens, then its terminal arrives: dropped).
- **G2.** The note's `current_turn` is `None` when no turn is open.
- **G3.** `run_id` is an int, monotonic per session, starting at 1.
- **G4.** Criterion 6's "permitted differences" applies only to the golden scenario, where every run ends in its own turn. The
  close-path rows pin the other differences directly. Accepted.
- **G5.** The order of the close flush (after the closing tuple's commands) is not pinned beyond the device call log. Accepted.

## Implementation notes
- **Part of the gap.** `_pump_playback` sets `_playback_open = False` on every terminal. With an old terminal still in flight, that
  closes the new run.
- **Where to decide.** Attribution decides whose terminal it is, following the arrival order from `playback_events()`. The staleness
  decision is taken on the pump, against the machine's turn at the moment the event is handled, because an INTERRUPTED timeout can
  close the turn between arrival and handling.
- **Synthesised drains.** A drain the session synthesises in `_maybe_mark_drain` (when no playback is open) belongs to the current
  turn. It is never attributed to a run.
- **Rules:**
  - a duration is never computed from two clocks;
  - a subsystem that drops something says so (`note`);
  - `turn_machine.py` stays pure and is not touched (`TURN_MACHINE_SHA256` does not move).
- **Source-grep landmines in `session.py`:**
  - `test_prompt_budget.py` bans the substrings `tokenizer` and `chars_per_token`, and any `/ 4` shape, in code *and* docstrings;
  - `test_session_fence_record.py` asserts that `_segment` returns the gate's sentences unmodified.

## Rulings after review (orchestrator, 2026-10-12; reviewer 2 APPROVE, reviewer 1 REQUEST CHANGES at 8ad8499)
- **G6. A closed turn's speech is never played after it closes** (reviewer 1, F1/F2).
  - **The problem.** tts.error, llm.error and client.disconnected close the turn without `TtsCancel`, so the speech worker still holds
    that turn's queued or in-flight utterances. After the close flush, the worker played them and minted a new run. That run then
    swallowed the next turn's drain, which hangs the next turn in SPEAKING for good, or leaked turn 1's text into turn 2's history.
  - **The fix.** `_Utterance` carries its turn id. `_speak_one`/`_play` refuse an utterance whose turn is not the machine's current
    turn: it is not played and not minted, and one `note {what: "stale utterance", turn, current_turn, source}` records it.
  - **Normal turns are unchanged.** The golden must stay green.
- **G7. A turn never joins another turn's run** (defence in depth).
  - **The case.** A play arrives while a run is open whose `turn_id` differs from the current turn. Example: a G1 run with `None`, or
    any misattribution.
  - **The rule.** The session flushes that run first, then mints a new run for the current turn. The old run's terminal is then stale
    and dropped (criterion 3).
- **G8. Rows (test-author):**
  - **F1:** the hang sequence, for llm.error and for tts.error. Turn 2 must complete on its own drain.
  - **F2:** the history-leak sequence. Turn 2 is typed before the queued utterance plays. Turn 2's history must hold no turn 1 text.
  - **F3:** a failed `audio.play` rolls the minted run back, with `fail_play` on the ack clip. It kills the no-op `_forget_run` mutant.
  - **G7:** an IDLE clip run still open when a turn's answer plays. The clip run is flushed, a new run is minted, and the turn
    completes on its own drain.
  - **Re-check in T-0092b.** The same-turn drift case (a turn that speaks again after its drain is marked, as with a tool result) must
    be re-checked in T-0092b.
