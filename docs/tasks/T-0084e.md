**Status:** done (2026-10-11; run 2 at 794161d, winner native; H-T84-1: test split approved) · **Blast radius:** high (two reviewers per `/launch`; human at H-T84-0 before and H-T84 after) ·

## Goal
One dev run in one boot at one reviewed SHA: a fresh pass 1 in both formats per case, all 16 cells, and the decision by
`select_format(…, "dev")`. The question is whether native wins dev.

## Acceptance criteria
0. **Pre-flight (amendment, 2026-10-10, from the T-0084c review).** Before the dev run, a separate reviewed `/launch` runs the `gpu` rows of
   `tests/cd/contract/test_twopass_fake_contract.py` (the T-0084c section) against the real engine. They cover:
   - `tools` together with `continue_final_message` (the render cut right after `<|tool_call>`);
   - `tool_choice: "none"` still rendering the 5 declarations;
   - `prompt_token_ids` present.
   
   A failure there returns to the planner before any dev request.
   **Ruling E1 (orchestrator, 2026-10-10): criterion 0 is folded into the dev run itself.**
   - **Why there is no separate pre-flight.** No locked script boots the engine and runs those host `gpu` rows, so a separate pre-flight would
     need a new script and a task of its own. The dev run's prompt guards (T-0084c criterion 6) check exactly the same three things, on the
     first native requests, and stop the run loudly (exit 1, `stopped` set):
     - a missing `prompt_token_ids` → `prompt_guard: missing`;
     - declarations not rendered under `tool_choice: "none"` → `prompt_guard: declarations`;
     - the continuation not ending in 48 → `prompt_guard: continuation`;
     - a 400 on `tools` + `continue_final_message` → `http_error`.
     The cost of a failure is one boot plus seconds.
   - **What a stop means.** A guard or http stop in the first native requests counts as the pre-flight failing: report it and return to the
     planner, with no patching on the fly. The `gpu` contract rows stay available for a later dedicated run.
1. **Run.** `/launch` of `scripts/locked/t0084_native.sh --stage dev` from a pinned detached worktree.
   - Dev split 40 tool + 8 no-tool; both formats; 16 cells.
   - **Gate:** exit 0, no stop, every prompt guard passes, CS = 1.000 on every constrained terminated row, and no loud error.
2. **Decision.** `selection-native-dev.json` is written with θ_n, the choice and the winner. Two reviewers re-derive both steps independently
   from the raw rows (Fraction; median = mean of the two middle values; p90 nearest rank) and must agree.
3. **Guarantee (T-0080c criterion 4).** A violation stops the run and becomes a failing test first.
4. **Report** `docs/cd/toolcall-native.md` (new), from artifacts only:
   - every number with its regime;
   - the step-1 and step-2 tables, per format and per tool;
   - T-0084d criterion 3's lines, including the spoken-prefix share per format. Q6 assumes the model speaks a sentence before the call, so a
     much lower native share is stated as a product finding.
   - the parse-reason histograms;
   - a cross-boot sanity line beside T-0082c R-dev;
   - the caveat "dev pilot, n 40; not a held-out result".
5. **Hard stop H-T84.**
   - Winner cc: the program ends and the provisional default stands.
   - Winner native: the human decides H-T84-1 (test-split reuse). T-0084f stays dormant until then.
6. *Negative.*
   - The test split is never sent.
   - `thresholds.py`, the T-0080c/T-0082c artifacts and `docs/cd/toolcall-v1*.md` are unchanged.
   - A stopped run is not re-run without the human.
   - The provisional default is unchanged.
