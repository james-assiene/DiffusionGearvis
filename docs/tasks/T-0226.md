## Goal

T-0223 showed Gearvis finding planted mistakes on ten designed, typeset-looking pages. This task asks the same question about real student work. The input is a private manifest of 39 phone-scanned pages: 19 with a mistake, 15 correct and 5 unclear, mixing portrait and landscape at 1240x1755, 1755x1240, 1241x1754 and 875x1241. One typed, neutral question goes to a fresh Session per page. The settings path sets the shipped "Education tutor" built-in (T-0225). Gearvis sees the page as a shared-screen frame. The run records, per page:

- what Gearvis said and showed;
- whether it located the mistake (mistake pages);
- whether it said the work was correct or invented a mistake (correct pages);
- how much it thought;
- how fast it started speaking.

It is report-only: no bar, no default change, no product code change. The new script reuses T-0223's machinery (as T-0223 reuses T-0208's) rather than copying its 1,637 lines.

## Acceptance criteria

**Group A — the harness (CPU; tests in the fast suite).**

A1. **Inputs and pins.** `scripts/gpu/t0226_real_attempts.py` takes `--manifest PATH`, `--manifest-sha256 HEX` (required, 64 lowercase hex, no default), `--base-url` and `--out-dir` (default `REPO/logs/t0226-real-attempts-<sha7>/`). The manifest shape is:

```
{"version": 1, "pages": [{"id", "png", "sha256", "kind", "key", "judge_keywords"}]}
```

Here `png` is relative to the manifest's directory and `kind` is one of `mistake`, `correct` or `unclear`. A `judge_keywords` entry holds `|`-separated alternatives and every entry must hit: T-0223's R-2 semantics, read through T-0223's `keyword_hit`.

A2. **Refusals before any socket (exit 2, each with its own message), in this order:**

- `--base-url` is not loopback.
- The tree is dirty (paths named).
- The out-dir exists.
- The out-dir is not under `REPO/logs/`, or `git check-ignore` does not ignore it.
- No merge whose subject starts with `Merge T-0226-a:`, `Merge T-0223-b:`, `Merge T-0213-a2a:` or `Merge T-0225:` is reachable from HEAD. Branch merges do not count.
- `--manifest-sha256` is malformed.
- The manifest is not a regular file.
- The manifest's sha256 differs from `--manifest-sha256`.
- The manifest directory, resolved with symlinks followed, is the repo, is inside the repo, or is inside any git work tree (`git -C <dir> rev-parse --is-inside-work-tree`).
- The manifest is not version 1, or is malformed: ids missing or duplicated, a `kind` outside the three, or no pages.
- A `png` is absolute, contains `..`, or resolves (symlinks followed) outside the manifest directory.
- A `png` is missing, or its sha256 differs from its manifest entry.
- A `mistake` page has no non-empty `judge_keywords` list of non-empty strings, or an entry has an empty alternative.
- A `correct` or `unclear` page's `judge_keywords` is not a list. An empty list is valid.
- `prompt_builder.validate_instructions(TUTOR_INSTRUCTIONS)` is not None.
- 1120 visual tokens are not in force (`cli.grounding_of`, tools off, as in T-0223 B1).
- **P-S** fails. P-S is T-0223's CPU settings probe run on a synthetic white page generated at the first ordered page's size, never on a private page.

No engine: exit 1. (Satisfies T-0223 B1's pattern; docs/09 §5.)

A3. **Run shape.**

- **Pages:** one turn per page (n = 1), all manifest pages. The order is the sorted page ids shuffled once by `random.Random(ORDER_SEED = 0)`, written to `order.json` before the first socket-using step after P0. Concurrency 1. The engine is unseeded.
- **Each turn:** a fresh Session (empty history and memory), tools off, search off, `visual_tokens=1120`, FakeStt/FakeTts, and its own SessionLog under `<out>/sessions/`.
- **Sequence:** hello → `AstraSettingsSet(rev=0, changes={"user_instructions": TUTOR_INSTRUCTIONS})` via `HudServer.route` → echo at `rev == 1` with `refused == []` → one `astra.frame` → `UserText(QUESTION)`. The frame is the page through T-0223's `frame_jpeg`: `policy.target_size(bucket_for(SCREEN, w, h))`, JPEG at `policy.JPEG_QUALITY`, 16-hex phash.
- `TUTOR_INSTRUCTIONS` is byte-equal to the `education_tutor` built-in text in `hud/src/settings/prompts.js` (T-0225).
- `QUESTION = "Here's my work on this page. Is it right? If there's a mistake, tell me where."` It must not presuppose a mistake, because controls exist.
- **Timing:** `TURN_TIMEOUT_S = 90`. `RUN_BUDGET_S = 20 * 60`, measured from process start with the probes included. No turn starts unless 90 + 45 s still fit, so the last start is at 1065 s. `ERRORED_STOP = 3` consecutive non-clean turns stops the run. Every turn not run is written as not run.
- **P0** (engine, as T-0223): one text and one image generate at `max_soft_tokens` 1120 must return 200, else the run is void (exit 3). It also records each page frame's image-token count via `/tokenize` beside `policy.expected_soft_tokens`. This only goes into the report and never gates.

A4. **Per-turn evidence.** These are T-0223's B3 (a)–(c) checks applied unchanged to each executed turn, with the instructions block being `USER_INSTRUCTIONS_HEADER + "\n" + TUTOR_INSTRUCTIONS` as defined here:

- the stored frame equals the posted one, and every prefill and generate body carries exactly that one image;
- the instructions are in every system message, the turn line has `settings_rev == 1` and one `settings.change` applied immediately before `UserText`;
- no body carries `tools`, and every body carries `max_soft_tokens == 1120`.

Any violation makes the run void (exit 3).

A5. **Judge, pre-registered here (R-1 carries over).**

- **Judged text.** Every `assistant_spoken` of the turn plus the shown A2UI card text, joined with spaces. Thoughts and clips are never judged.
- **Clause split.** The judged text is casefolded, curly apostrophes become `'`, and it is split into clauses on `.`, `!`, `?`, `;`, newline, and the word `but`.
- **Phrase lists.** These are module constants, listed verbatim in the report, with English and French forms because the pages are French and the model may answer in French:
  - `NEGATED_CLAIM`, which reads as a claim despite a negation: e.g. "not correct", "isn't correct", "is not correct", "not right", "isn't right", "not quite", "pas correct", "pas juste", "n'est pas".
  - `NO_MISTAKE`, e.g. "no mistake", "no mistakes", "no error", "no errors", "don't see any", "do not see any", "didn't find any", "couldn't find any", "can't find any", "nothing wrong", "nothing is wrong", "nothing went wrong", "is correct", "are correct", "all correct", "looks correct", "looks right", "is right", "well done", "checks out", "aucune erreur", "pas d'erreur", "pas de faute", "c'est correct", "c'est juste", "tout est juste", "bravo".
  - `CLAIM`, e.g. "mistake", "error", "wrong", "incorrect", "should be", "should have", "forgot", "missing", "instead of", "erreur", "faute", "faux", "fausse", "oublié", "au lieu de".
- **Clause rule.** A clause containing a `NEGATED_CLAIM` phrase is a claim clause. Otherwise a clause containing a `NO_MISTAKE` phrase is a correct clause, and its `CLAIM` words are ignored. Otherwise a clause containing a `CLAIM` word is a claim clause.
- **Turn flags.** `claims_mistake` means any claim clause. `says_correct` means any correct clause and no claim clause.
- **Verdict per kind:**
  - `mistake` pages: `located` = every `judge_keywords` entry hits the judged text (T-0223 `keyword_hit`). Otherwise `missed`, sub-flagged `said_correct` when `says_correct`.
  - `correct` pages: `claimed a mistake` if `claims_mistake`, else `said correct` if `says_correct`, else `no verdict`.
  - `unclear` pages: no verdict; both flags are reported.
- Errored, timed-out, not-run and empty turns get the verdict `errored` and count in their kind's denominator. The report also shows the spoken-only verdict per turn.

A6. **Measures per turn.**

- **Thinking:** characters and canvas count of the turn's `llm.commit` records with `segment == "thought"`, plus a token count from the engine's `/tokenize` on the joined thought text, posted after the turn ends (no generation). The token count is null when `/tokenize` fails. `TurnRecord.thought_tokens` is not used: it is unpopulated, 0 on every turn of the T-0223 run.
- **Latency:** time to first spoken word, from the UserText stamp to the `tts.first_audio` span start (FakeTts, so this is the hand-off to TTS, said so).
- **Other:** `speech_refused` from the turn line, clip kinds, wall time, prompt tokens vs `expected_soft_tokens`, min free VRAM.

A7. **Report** (`report.json` and `report.md` in the out-dir).

- **Counts:** pages per kind; mistake pages located / missed (of which said correct) / errored; correct pages said correct / claimed a mistake / no verdict / errored; unclear pages with their flags.
- **Per page:** id, kind, verdict, spoken-only verdict, verbatim spoken and shown text, matched keywords, thinking chars, canvases and tokens, first-word ms, and the frame size and image tokens.
- **Aggregates:** first-word p50/max over turns that spoke, with the cold first turn marked; thinking p50/max; `llm.error` count; label; full regime; the three phrase lists verbatim.
- **Notes:** FRAME_NOTE as T-0223, plus scan sizes and Pillow vs browser canvas. The built-in tutor text presupposes a mistake ("find the line with the mistake"), so correct-page results measure the product as shipped. Phone scans may include a teacher's red notes that can hint at the answer; this is not controlled.
- **Hand audit:** a placeholder section, one blank line per page under the heading `## Hand audit (main session)`.
- **Reading line:** "L of M mistake pages located; S of C correct pages said correct, F claimed a mistake; U unclear pages reported". No bar.

A8. **Labels and binding lessons** (as T-0223 B6):

- **void:** P0 failed or any A4 violation (exit 3).
- **incomplete:** any not-run, errored or timed-out turn (exit 1). A not-run turn counts as errored.
- **measured:** exit 0.

`tests/eval/test_t0226_real_attempts.py -m gpu` re-derives every A4 check, A5 verdict, count, the reading line, latency, thinking chars and canvases, and the label from `sessions/*.jsonl`, `turns.jsonl`, `order.json` and the manifest, and compares them with `report.json`. ## Regime

- **Model and engine:** DiffusionGemma 26B-A4B NVFP4 (rev from `services/versions.lock`, 2ea83723 at T-0223), vLLM 0.29.0, lean profile, canvas 256, 48 denoising steps, thinking on, KV 4 GiB bf16, `max_num_seqs` 3, prefix caching on, vllm.sh at 806da12, one boot, STT down.
- **Frames:** tools off, search off, 1120 visual tokens, HUD screen bucket (portrait scan about 1106x1566, landscape 1566x1106, small scan 874x1240 unscaled), JPEG 85, one frame per turn.
- **Turns:** typed, FakeStt/FakeTts. Instructions are the T-0225 "Education tutor" built-in, sent through the settings path; the question is as in A3.
- **Sample:** n = 1 per page, 39 turns (19 mistake, 15 correct, 5 unclear), order seed 0, engine unseeded, a fresh Session per turn.

**Budget estimate.** From the T-0223 run at 90645329 (lean, same regime, 30 turns): median turn wall time 17.5 s, max 44.7 s, sum 532 s, reported wall time 554 s.

- For 39 turns that is about 11.5 min at the median, and about 14.3 min at 22 s per turn. Real scans may cost more thinking.
- `RUN_BUDGET_S = 20 min` (last turn start at 1065 s) fits 39 turns at up to about 26 s each plus the probes. The wrapper timeout of `21m` leaves 1 min of margin for the report.
- Total GPU time is about 4 min of boot plus 12–20 min of run. If turns average over about 26 s, the run ends incomplete and is reported as such.
