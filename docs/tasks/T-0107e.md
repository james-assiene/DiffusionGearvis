# T-0107e — Honour "no": a turn whose user transcript is a clear no executes no call

**Status:** done 2026-10-20 (merged 411d217); tests at 7596c02; implementation modules: `local_astra/toolcall/user_declines.py`, `local_astra/conductor/session.py` · **Blast radius:** high (the conductor session's tool path decides whether a drafted call executes; two reviewers, A and B) · **Branch:** `T-0107e-honour-no` from `main` at the SHA current when the branch is cut (record it as BASE) · **Parent:** T-0107; H-T107; the human's T-0107b ruling of 2026-10-20 (`docs/tasks/T-0107b.md`, Rulings) · **Sequencing:** owns `session.py` while open; T-0111c and any other `session.py` task wait until it merges · **Depends on:** T-0107a/T-0107d (merged; reads `ask_first`, read-only).

**Protocol cannot be skipped:** this changes which drafted calls a tools-on session executes.

## Goal

When the user's turn is a clear no ("no", "stop", "cancel", "don't" and close forms), the conductor refuses every tool call drafted in that turn:
- at step 1 and at every loop step;
- before any repair, whatever the call's verdict.

The turn then ends with the model's committed text voiced as at BASE.

This is the only new rule:
- it never interrupts the user;
- it holds nothing across turns;
- it adds no HUD element;
- it does not touch the turn machine.

Every turn that is not a clear no is byte-identical to BASE.

**Evidence.** The T-0107b GPU run at 8387447 is written up in `docs/cd/toolcall-high-stakes-ab.md`, Results. After "No, leave it." the model still drafted a call in 40/80 (A0) and 22/80 (H1) trials: it sent the message, clicked Post, cleared the todos and cancelled the transfer.

The planner's CPU prototype of the rule below refuses all 62 of those trials. It refuses none of the 290 S1, 160 S2-yes or 58 S3 trials with a tool commit, and none of the 3,570 earlier routed trials.

## Acceptance criteria

**Definition (the spec; the test-author's oracle encodes it).** `user_declines(transcript: str) -> bool` lives in the new pure module `local_astra/toolcall/user_declines.py`, alongside `USER_DECLINED_REASON = "the user said no"`. The function is total, deterministic and linear, imports only the stdlib, and never raises.

- **Normalise.**
  - Apply NFKC, then `casefold()`.
  - Map U+2018, U+2019 and U+02BC to `'`.
  - A `no.` followed by optional whitespace and a digit means "number" and is never a head (`No. 10 Downing Street`).
- **Clauses and words.**
  - Split the text into clauses at `, . ! ? ; : … — – ( ) " “ ” « »` and at line breaks, then drop empty clauses.
  - A word is a maximal run of letters or digits, which may be joined by an inner `'` or `-`.
- **Leading hesitation.** Skip `uh`, `um`, `er`, `erm`, `euh`, `hmm`, `actually`, `wait` and `attends` at the very start, across clause boundaries.
- **Heads.** These are the 84352ca NO set plus `dont`:
  - interjections: `no`, `nope`, `non`, `no thanks`;
  - verbs: `stop`, `cancel`, `annule`;
  - negators: `don't`, `dont`, `do not`.
- **Word sets.**

  | Set | Words |
  |---|---|
  | P (pronouns) | `it`, `that`, `this`, `them` |
  | D (determiners) | `the`, `my`, `your`, `that`, `this`, `these`, `those`, `any` |
  | T (tail) | `please`, `yet`, `now`, `thanks`, `thank you`, `merci` |
  | R (reversal) | `wait`, `actually`, `instead`, `rather`, `but`, `mais`, `plutôt`, `plutot`, `attends` |
- **True iff both of these hold:**
  - (a) The first clause is one or more heads, followed by one of:
    - only T words;
    - (verb head) one P word, then only T words;
    - (negator head) any one word, one P word, then only T words;
    - (negator head, only when the first clause is the whole transcript) any one word, one D word, any one word, then only T words.
  - (b) No word after the first head, in any clause, is in R.

1. **The predicate.** The test-author may add rows to each list but never flip one.
   - **True for:** `No, leave it.` · `No thanks, I'll do it myself` · `Stop!` · `Don't send it` · `Don’t send it` · `Dont send it` · `No` · `nope` · `NO!` · `no.` · `no thank you` · `Non, laisse.` · `Non merci` · `Annule` · `Cancel.` · `stop it` · `cancel that please` · `Don't send it yet` · `Don't send the message.` · `Do not delete them` · `no no no` · `no don't` · `Actually no, don't send it` · `Wait, no, don't.` · `Uh, no.` · `Stop, stop.` · `No, don't send the message, I'll do it` · `No, the other one` (an accepted over-refusal).
   - **False for:** `no wait, send it to Bob instead` · `No, but send it tomorrow` · `No. Open the settings instead.` · `nothing` · `know` · `I know, do it` · `Nobody is there` · `Notify Bob` · `No problem, go ahead` · `No worries, send it` · `No need to ask, just send it` · `Cancel my 3pm meeting` · `Stop the timer` · `Annule la commande` · `Don't forget to save` · `Don't close the tab, click Save` · `Don't send it to Alice, send it to Bob` · `Don't worry, send it` · `Don't worry about it` · `Do not disturb mode on` · `Non-stop flights to Paris` · `No-code tools` · `No. 10 Downing Street opening hours` · `Oh no, the page crashed, reload it` · `Which mark do you have ever seen? No` · `Yes, go ahead.` · `""` · `[ui] __gate.clicked {"label": "No"}`.
   - **Known misses, pinned false** (widening is H-T107e-1): `Okay, no, leave it` · `I don't want that, leave it` · `no leave it` · `Leave it.` · `Never mind` · `Ne l'envoie pas`.
   - **Hypothesis:** the function is total and deterministic.
2. **Step 1.** With a `ToolKit` set and `user_declines(<the turn's transcript>)` true, `_judge_tool` hands the machine `ToolDraft(status="refused", reason=USER_DECLINED_REASON)`. This applies whatever the verdict and whatever `asks_user` says. Through the existing rows (R5) this gives:
   - no execute;
   - no repair;
   - `tool.cancel(refused)`;
   - the card `refused` with the reason;
   - the committed answer voiced and stored as at BASE;
   - `tool_loop_end == "refused"` with the loop on.

   Voice turns and typed `astra.text` turns behave alike.
3. **Loop step k ≥ 2.** The same check runs at every judge. A declined step ends the loop, and no step k+1 request is sent.
4. **The transcript read.** It is the live turn's words as the machine holds them at judge time, joined with single spaces. That equals the `user_text` stored in history.
   - It never reads the previous turn, history, `next_words`, `astra.transcript` or the model's text.
   - A ui-origin turn reads its `[ui] …` transcript and never declines (H-T107e-2).
5. **Log fields.**
   - `tool.call` records of declined calls, and only those, gain `user_declined: true` and `verdict_status`.
   - When `asks_user` is also true, `asked_first: true` is written too, and the reason is still the decline.
   - Ordinary records and turn lines are byte-identical to BASE.
6. **Nothing held.**
   - After a declined turn, an ordinary next turn whose model re-issues the call executes in dry run as at BASE.
   - A "No, leave it." in history does not decline a later turn.
   - No new `MachineState` field, command, event, timer or `ToolCancelReason`.
7. **Barge-in: no double handling.**
   - A spoken interruption still yields BASE's `tool.cancel(interrupted)` for the interrupted turn's call.
   - The turn that the interruption opens ("Stop.") refuses its own draft with the decline reason.
   - Each call id has exactly one final `astra.tool.call` (I2).
