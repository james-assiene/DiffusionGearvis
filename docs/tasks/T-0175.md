## Implementation notes

- **Why HOME and not a new env var.** `brave_key.default_key_path()` is `Path.home() / ".config/diffusion_gearvis/brave_api_key"`, read at each call, and `Path.home()` honours `HOME` on POSIX. Old BASE trees (d486bcb9 and later literals) know only `HOME`. A product env var (such as `ASTRA_BRAVE_KEY_PATH`) would be a credential-path product change and would not protect old BASEs, so it is rejected.
- **Timing.** The switch runs at the top of `tests/conftest.py`, which pytest imports before any sub-conftest or test module. Three things make anything later too late:
  - initial conftests load before `pytest_configure` (`tests/unit/conftest.py` imports `local_astra.search.ddgs_backend`);
  - `memory/store.py:61` computes `DEFAULT_DIR` at import;
  - three hook test modules (`test_stop_hook.py`, `test_protect_paths_hook.py`, `test_guard_bash_hook.py`) build `GIT_ENV = {**os.environ, ...}` at module import.
- **Existing jail.** Use a marker variable (e.g. `ASTRA_TEST_JAIL`, plus the recorded pre-switch home and the creator PID). The session is already jailed iff `HOME == marker` and the directory exists. Otherwise create a new jail with `tempfile.mkdtemp`, never under the repo. Record the pre-switch home as a string, so xdist workers and nested runs know the real home without having it in `HOME`.
- **Real home: strings only.** Use `os.path.normpath`, never `realpath`, `resolve` or `exists`. Create the symlinks with `os.symlink` without checking the target; dangling links are fine. Never list the real home.
- **Mirror allowlist** (symlinks `<jail>/<p>` → `<real>/<p>`):
  - `.cache`, covering the uv cache, `huggingface/hub` (hard-coded in `toolcall/detok.py:78`, `decoding/vocab.py:49` and `preflight.py:1085`), `ms-playwright` and `fontconfig`;
  - `.gitconfig` and `.config/git`;
  - `.config/uv` and `.local/share/uv`;
  - `.docker`;
  - `.Xauthority`;
  - `.local/share/fonts`, `.fonts` and `.config/fontconfig`.

  `<jail>/.config` and `<jail>/.local/share` are real directories. Never mirror `.config`, anything on the path to `.config/diffusion_gearvis`, or `.local/share/local_astra`. With HOME moved, tests also stop touching James's real memory DB.

  An env-pin alternative (`UV_CACHE_DIR`, `HF_HOME`, `PLAYWRIGHT_BROWSERS_PATH`, `GIT_CONFIG_GLOBAL`, …) is rejected, for two reasons: it misses the product's hard-coded `~/.cache` paths, and it changes default-rule rows (`test_host_detok.py` deletes `HF_HOME` and expects the default).
- **Audit hook.**
  - `sys.addaudithook` cannot be removed, so install it once per process.
  - The fast path is one frozenset membership test on the event name, because the hook fires on every open and import (criterion 12).
  - Event arguments:
    - `subprocess.Popen`: executable, args, cwd, env;
    - `os.posix_spawn`: path, argv, env;
    - `os.exec`: path, args, env;
    - `os.spawn`: mode, path, args, env.
  - `env is None` means check `os.environ`. Raising in the hook aborts the call.
  - Accepted gaps:
    - `multiprocessing` and `_posixsubprocess` spawns are not seen directly; they inherit `os.environ`, which the hook checks at the next event;
    - grandchildren of a non-pytest child are not guarded. They inherit the jail unless a script scrubs its env, and `local_astra/` and `scripts/` contain no `env -i` or HOME-less spawn today (grepped).
- **Escape.** The fixture sets a process-local flag on setup and clears it on teardown; the guard permits the pre-switch home only while the flag is set. Under xdist the flag is per worker. Without `ASTRA_LIVE_SEARCH=1` the fixture must `pytest.fail`, not skip, so a misuse in the fast suite is loud.
- **Cleanup.** Only the creator PID removes the jail, in `pytest_unconfigure`. `shutil.rmtree` unlinks symlinks without following them; never call it on a link target.
- **Keep the existing patch.** `brave_key_nowhere` stays, as belt and braces; T-0163 criterion 10 rows pin it.
- **Speed.** Nested pytest rows cost a few seconds each. Keep them to the six listed, and select inner rows by nodeid.
- **No tests weakened.** If the guard refuses an existing rig beyond `test_prompt_ui_block.py`, stop and report it to the planner. Never loosen the guard to admit it.
