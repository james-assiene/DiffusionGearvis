## Goal

Every clip is silent today.
- `Session._clip_pcm` reads `<data_dir>/clips/<kind>.s16le`, and no such file exists on this box or in git, so `_ClipUtterance` plays zero-length audio.
- The machine emits `PlayClip(kind="ack")` at every thinking turn's `llm.start`; thinking is always on (D11).
- `_interim_filler` sends `clip:still_working` 4 s into any think.
- So installing assets naively would make the assistant say "let me look" on every turn, against James's ruling.

After this task:
1. **One command renders the assets.** It renders each clip kind's `.s16le` once through the running Pocket TTS service on loopback, with the same client, voice and format as speech. `doctor` warns when a default-enabled kind has no current asset.
2. **No ack or hmm by default.** With defaults, no `ack` or `hmm` clip is ever emitted. `filler_clips` (or `--filler-clips`) restores them.
3. **still_working only in long live tool loops.** It plays at most once per turn, only in a live session's tool loop, after the turn has run 20 s.
4. **Ending clips are unchanged.** `out_of_steps`, `not_finished` and `lost_thread` play whenever their T-0178/T-0179 condition fires.

No clip ever enters history, `astra.spoken` text or `TtsSpeak.source`.

## Acceptance criteria

### Group A: assets and doctor (CPU)

**A1. `local_astra/reflex/clips.py`** is pure apart from file reads. It provides:
- `clip_path(data_dir, kind)`: the exact path `Session._clip_pcm` reads.
- The kind sets:
  - `ENDING_KINDS = {"out_of_steps","not_finished","lost_thread"}`;
  - `PROGRESS_KINDS = {"still_working"}`;
  - `FILLER_KINDS = {"ack","hmm"}`.
- `default_enabled(registered)`, which returns `ENDING_KINDS ∩ registered` in group A.
- `ClipManifest` (Pydantic v2) for `<data_dir>/clips/manifest.json`. Each entry holds:
  - `text`, `text_sha256`;
  - `pcm_sha256`, `bytes`, `duration_ms`;
  - `peak_dbfs`, `rms_dbfs`;
  - `sample_rate` 24000, `channels` 1, `sample_format` `s16le`;
  - `tts`, the pin from `services/versions.lock`;
  - `rendered_at`, `git_commit`.
- `status(data_dir, kind, text, tts_pin)`, which returns `current`, `missing` or `stale`. Stale means any of: no manifest entry, a different text sha, or a different TTS pin.

"Registered" means the kind is in `get_args(ClipKind)` and has a `CLIP_TEXT` entry.

**A2. The render script:** `uv run python scripts/render_clips.py [--data-dir D] [--profile P] [--kinds …] [--force]`.
- **Which kinds:** by default, `default_enabled(registered)`. It refuses an unregistered kind, naming the registered ones, and refuses `ack` or `hmm` unless `--kinds` names them.
- **How it renders:** from `CLIP_TEXT[kind]` verbatim, through `PocketTtsClient(profile.services)` with `DEFAULT_VOICE`.
- **Output format:** raw 24 kHz mono s16le, the concatenated `audio()` chunks. No header, resampling, gain, normalisation or trim.
- **Idempotent:** a `current` kind is skipped unless `--force` is given. Each kind gets one line: `rendered`, `skipped (current)` or `failed: <reason>`.
- **Atomic:** each asset is written as `.tmp` and renamed. The manifest is rewritten the same way, after the assets.
- **Validated before the rename.** Each kind must have:
  - a non-empty body with an even byte count;
  - a duration of 0.3–6.0 s;
  - audio that is not all zeros;
  - no full-scale sample.

  `TtsFormatError` and `TtsClientError` count as failures. A failure writes nothing for that kind, and the script exits non-zero.
- **Network:** no socket beyond the loopback TTS (`Services` already validates its URL).

**A3. The doctor row** (WARN, never FAIL, since a missing clip only means silence).
- `preflight.evaluate` gains a `clips` row after the browser rows, from `Facts.clips` via `collect_clips()`. It uses the default data dir, `memory.store.DEFAULT_DIR`.
- Outcomes:
  - **PASS:** every kind in `default_enabled` is current.
  - **WARN:** a kind is missing or stale. Each such kind is named, with the fix "start the TTS service (`services/tts.sh`) and run `uv run python scripts/render_clips.py`".
  - **WARN** "not gathered" when the collector raises.
  - **PASS** "no default clips registered" when the set is empty.

**A4. Negative: nothing audible changes.**
- Every file outside the owned list is byte-identical over BASE_A..TIP_A.
- The existing doctor rows are identical on every `tests/fixtures/box/` fixture.
- With defaults, the script never writes `ack`, `hmm` or `still_working` assets.

**A5. Docs.** `services/README.md` gains the render step: it needs `tts.sh` up, runs on CPU only, and must be re-run after a clip-text or pin change.

### Group B: the default policy (CPU)

**B1. ack is off by default** (re-scopes docs/02 §4 row 6, docs/03 §3 and I5).
- `TurnPolicy.ack_clip: bool = False`.
- The llm.start row emits `PlayClip(kind="ack")` if and only if `ack_clip` is set and the existing condition holds.
- With `ack_clip=True`, the machine is byte-identical to BASE_B's (F2).

**B2. The opt-in.**
- `Profile.filler_clips: bool = False`, and `--filler-clips/--no-filler-clips`. The flag beats the profile, which beats the default.
- On:
  - `TurnPolicy(ack_clip=True)`;
  - `_interim_filler` runs as at BASE_B;
  - startup prints `astra session: filler clips: on (<flag|profile>)`.
- Off: `_interim_filler` is never called.
- Negative: with defaults, stdout and `--dry-run` output are byte-identical to BASE_B.

**B3. hmm.** No rule produces `clip:hmm` (T-0013 A4). None is added, so `hmm` is never emitted (F1).

**B4. still_working only in long live tool loops.**
- `TurnPolicy.still_working_after_ms: int | None = None`.
- `cli` sets it to `Profile.still_working_after_s * 1000` (default 20, `ge=5`) only when `tools = live` and the loop is on. Otherwise it stays None.
- The machine emits `PlayClip(kind="still_working")` once per turn, on the first `Tick` where all of these hold:
  - `THINKING`, with `tool_steps_executed >= 1`;
  - `t_ms - llm_start_ms >= still_working_after_ms`;
  - no clip is playing;
  - no `still_working` has played this turn (a new state field, cleared at turn end and on reset);
  - no ending clip has played this turn.
- It sets `clip_playing`, so barge-in, takeover and reset emit `StopClip` (G6/G7).
- Time arrives only as `Tick`.
- `fillers_this_turn` is unchanged.

**B5. Rules between clips** (refines T-0178 L10 and T-0179 B-7; H-T182-3).
- At most one progress clip and at most one ending clip per turn.
- An ending clip after a `still_working` still plays. The two are serialised by the playback queue and never overlap.
- A clip never counts as voiced, so it never suppresses T-0178 B4's honest ending.
- With `filler_clips` on in a live loop, at most one `still_working` plays per turn in total.

**B6. Registry and doctor follow the policy.**
- `default_enabled(registered, filler_clips=False)` adds `PROGRESS_KINDS`, and adds `FILLER_KINDS` when `filler_clips` is true.
- `doctor` passes `profile.filler_clips`.
- `diffusion_gearvis render-clips [--data-dir D] [--kinds …] [--force]` is a thin `cli` wrapper over the script function, with the same output and refusals.

**B7. A barge-in silences a playing clip.** Once assets exist this is a must (bench B4 budget: 300 ms from onset to silence).
- Today `StopClip` only sets `_ClipUtterance.cancelled`, while `audio_io._feed` has already moved the whole asset into `_pending`. So the clip keeps playing.
- After B, a `StopClip` silences the clip within 300 ms on the fake device's played clock.
- It does not cut other queued speech of the turn, such as the step-1 prefix.
- If that is impossible without editing `audio_io.py`, stop and report: it becomes its own task.

**B8. Invariants; none weakened.** New Hypothesis properties:
- **F1:** with defaults, no `PlayClip(ack|hmm)`.
- **F2 (differential):** default commands equal the `ack_clip=True` commands with every `PlayClip(ack)` removed, along with any `StopClip` caused only by it. With `ack_clip=True` and `still_working_after_ms=None`, the result equals the frozen BASE_B machine.
- **F3:** `still_working` plays at most once per turn, only under its guards, never after the ending clip. The turn reaches IDLE, and no `PlayClip` follows IDLE.
- **F4:** with `still_working_after_ms=None`, P9 and L8 are unchanged.

`TURN_MACHINE_SHA256` is re-pinned, with the reason recorded in docs/02. No `TtsSpeak` is added.

**B9. The turn line.** It gains `extras.clips: {"fillers": bool, "still_working_after_ms": int|null, "played": [...]}`, including zero-length clips. T-0179's `system_clip` is kept.

**B10. Negatives.**

- With `--filler-clips`, off and dry_run behave byte-identically to BASE_B through the T-0092a/T-0092b golden rigs, apart from `extras.clips`.

## Implementation notes

**Machine**
- **Purity.** The B4 deadline is compared on each `Tick` (the session ticks every 50 ms). If a new `TimerName` is needed, stop: `commands.py` is not owned.
- **Why the machine, not `filler_policy.py`.** The machine owns `clip_playing`, and therefore `StopClip` and the ending-clip ordering. The session-side `_interim_filler` is acceptable only as the opt-in.
- **D16.** `still_working` is a fixed system clip. It names no action and no host, and plays once per turn at 20 s. It is a long-wait signal, not narration.
- **The 20 s threshold.** A cross-check on 18 live loop turns from this box gave p50 ≈ 11.5 s and p90 ≈ 23.9 s; 3 of the 18 reached 20 s. At T-0178's web budget of 20 (about 54 s for a full turn), every budget-length turn crosses it.

**Audio**
- **B7 is the landmine.** `_ClipUtterance.audio()` yields the whole asset in one chunk, and `audio_io._feed` drains every chunk into `_pending` at once. Silence only the clip's samples, never the turn's queued committed speech.
- **The render client.** Use `PocketTtsClient(profile.services)`, as `cli` does. Read the `pocket_tts` pin from `services/versions.lock`.

**Assets**
- **Where they live.** In the user's data dir, not git. CC-BY-4.0 would allow committing, but rendering tracks text and pin changes and keeps binaries out of the release (H-T182-1).
- **`doctor`** reads the default data dir only, and names it.
