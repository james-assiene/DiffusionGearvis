## 1. Goal

T-0210 C's GPU run at 47c26102 got 1/15 on M1–M5 at the live defaults (`logs/t0210-threejs-47c2610/report.md`). Three failure modes showed up: fields below the sidebar fold were not found, unchanged clicks were repeated (23 repeat-guard refusals), and the model claimed success it had not reached (the completion check fired 11 times; outcome `call` 10, `no_call` 1).

This task measures whether either of two existing opt-in levers moves those failure modes on the editor:
- **outcome arm:** T-0136's measured action-outcome clause (`--action-outcome`).
- **reground arm:** T-0131/T-0133's ReGround pass 2 (`--reground`, crop 280 at the 1120 main budget).

T-0132 found no website gain from ReGround because website targets are big. The editor's number fields are about 50×20 px, so near-misses are the hypothesis.

The arms run interleaved in one locked run of 45 turns (M1–M5 × n = 3 × 3 arms). The report gives each arm's success, cost and the targeted mechanism counts, plus a pre-registered reading of what would justify a default-on follow-up. Nothing in the product changes.

**A8. Metrics per arm and per arm × task (report-only).**
- **Outcomes:**
  - success k/15 with Wilson 95 %, judged by `threejs_tasks.judge` over the state read with `"() => window.__state"` only (B-R23);
  - per-task k/3;
  - errored turns.
- **Cost:** steps p50/max and wall p50/max.
- **Screen-unchanged labels** (exact definition, one per step): for each labelled `tool_step` request, the label placed on *that* request is the last text part of the prompt for which `session.screen_reminder_key` returns a key. The count is requests whose key is `"unchanged"`. Text repeated from earlier steps in later requests' history is never counted again.
- **Repeat-guard refusals:** the sum of `extras.repeat_guard.stops_repeat + stops_recurring`. Footnote in the outcome arm: its no-change input is the outcome detector (T-0137).

  - success among turns where it fired.
- **Body-focus refusals:** M's `body_focus_refusals`.
- **Click misses:**
  - A click miss is an executed `click_at` whose next labelled request in the same turn carries the `"unchanged"` label.
  - Executed `click_at`s with no next request are counted apart as `unlabelled`.
  - Miss rate = misses / labelled executed clicks.
- **Re-aims (near-miss proxy, all arms):** a click miss at point p whose next executed pointer action is a `click_at` at q with `10 < max(|dx|, |dy|) <= 40` model units. Up to 10 units is T-0210's re-click.
- **Outcome arm only:** clause counts by kind (`extras.action_outcome`), including "no visible change" on updated screens.
- **Reground arm only:**

  - the pass-2 shift `max(|p2−p1|)` in model units, p50/max over `ok` records;
  - the miss rate split by "pass 2 moved the point" vs "did not";
  - pass-2 ms p50/max.
- **Safety (each expected 0):** T-0205's `safety_counts` table (non-loopback egress, HUD sentinel, browser egress blocked, URL leaks, resolver and connector calls, egress log), plus `over_action`, `secret_typed`, `checkout_pressed`, `submit_pressed`, `file_ops`, traps, `malformed_state`, `state_errors`.

**A10. The pre-registered reading.** This is not a bar, and nothing adopts on it. The report prints exactly one line per lever (outcome, reground):
- **"worth a default-on follow-up"** if all of these hold:
  - (i) arm success ≥ base success + 3 turns, **or** arm success ≥ base success with the targeted mechanism moved:
    - outcome arm: the click-miss rate falls by at least 1/3 relative **and** repeat-guard refusals fall by at least 1/2;

## 5. Implementation notes

- **Model on T-0211 C**, which already does arm-by-rebinding, block order, the synthetic-dir eval and provisional marks. Reuse its shape, not its code paths: its runners differ.
- **Rebind cli, not runners** (T-0211 C-R8). Both constants are read from cli's module namespace at call time:
  - `grounding_of` uses `LIVE_DEFAULT_REGROUND`;
  - `action_outcome_of` uses `LIVE_DEFAULT_ACTION_OUTCOME`;
  - T-0210's `_one_turn` calls `cli.grounding_of` and T-0205's `session_keywords` inside the turn.
  
  So the context must enclose the whole `await M._one_turn(...)`. The logged grounding source reads `"default"`. The report says why (the arm rebinds the default), so no reader takes it for HEAD's default.
- **The overview-frame yield** is cli's own `--reground` behaviour and is kept: the arm is "what `--reground` gives". A7's check makes the confound visible instead of hiding it. Do not force `overview_frame` on: config refuses it beside ReGround.
- **The outcome clause appears only after `LABEL_UPDATED`.** It never changes an `unchanged` label. A click miss is therefore the same B8-based proxy in every arm.
- **The click-miss caveat.** A focus caret on a number field may not move B8's comparison, so the proxy can over-count real hits. It is the same in all arms, so read it comparatively. Say this in the report.
- **What does not exist.** The session log has no target or element box. Do not add a DOM hit-test: state is read only through `"() => window.__state"`. A field-rect map for true distance-to-target is a follow-up.
- **Labels in logged prompts.** Find each request's own label with `session.screen_reminder_key` over the prompt's text parts (`scripts/replay_screen_reminder.py` already locates labels in logged `tool_step` requests; borrow its approach). Never regex `screenshot:"unchanged"` across whole request text: history repeats it (A8 adversarial row).
- **The ReGround second client.** M's `_one_turn` builds `crop_meter` at 280 and records its bodies in `budgets_sent`. The manifest records which budgets were sent per arm.
- **Rules that bind** (tonight's reviews):
  - the eval re-derives from session logs;
  - the CPU synthetic run dir;
  - the full regime in the report;
  - provisional marks;
  - a not-run turn is an errored turn;
  - keyword-dict pins;
  - state is read only via `"() => window.__state"`.
- **Process.**
  - `.claude/rules/gpu-services.md`: the harness lives in `scripts/gpu/`; running it (`--help` included) needs `/launch` and a clean tree; the wrapper is copied to `scripts/locked/` and chmod 444 at `/launch`.
  - STT must be down; the wrapper refuses ports 8080/8081.
  - No measurement while another agent edits `local_astra/`.
