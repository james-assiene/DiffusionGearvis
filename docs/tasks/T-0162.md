## Goal

**Restart (a new session; ruling H-T162-1).** A Restart button in the header, after a confirm:
- ends whatever turn is running, the way a page disconnect does (abort generation and prefill, cancel tools, stop TTS and playback);
- then starts a fresh session:
  - the model's history is empty;
  - the held frames and frame tags are dropped;
  - the tool calls and the turn journal are cleared;
  - **the long-term memory is wiped** (`memory.forget_since(0)`, the same deletion `diffusion_gearvis forget` uses);
  - the page's thread, cards, tool cards, Tools pane and denoising view are cleared;
  - the screen share stops.

The CLI keeps running and its services stay warm. Session logs on disk are kept: they are the user's local record, not the model's memory.

**Tools pane.** The right rail's Context pane is replaced by a Tools pane. Per turn, it lists each tool call with:
- the tool;
- its arguments in short form;
- its status (proposed / executed / refused / failed / cancelled / timeout, plus dry run and repairing, which the wire has today);
- its result in short form.

Each call is expandable for detail. Nothing in the pane is model thinking text.

**Context assists.** The four assist switches (Page text, PDF text, Spreadsheet cells, Accessibility tree) move into a Settings (gear) menu in the header. The badge stays visible in the header whenever an assist is on (D12a).

**Plain sentence for the tooltip and README (from D12a):**
> "Gearvis reads your screen from pixels only; these optional helpers also send it the page's text, a PDF's text layer, spreadsheet cells or the accessibility tree. They are all off by default, and every turn records which ones were on."

## Acceptance criteria

### Group A — the session reset (server, contract, machine, memory)

**A-1. Contract.** These are added to `contracts/protocol.py`, the codec round-trip and docs/02 §5:
- `AstraSessionReset`: type `astra.session.reset`, client→server, no fields.
- `AstraSessionCleared`: type `astra.session.cleared`, server→client, with `resets: int ≥ 1` (the count of resets in this session), `ended_turn_id: str | None` (the turn the reset cut, if one was open), `memory_forgotten: int ≥ 0` (episodes deleted) and `replay: bool = False`.

Both join `CLIENT_TO_SERVER` / `SERVER_TO_CLIENT`. `hud/src/protocol.js` mirrors `SERVER_TO_CLIENT` and the field table in the same commit (`test_hud_constants_parity.py`). Unknown fields are malformed.

**A-2. Machine row (pure).**
- `contracts/events.py` gains `SessionReset` (type `session.reset`). `contracts/commands.py` gains `ResetSession(ended_turn_id: str | None)`.
- `turn_machine.py` handles it from **any** state:
  - emits `_abort_live(state)`, the llm and prefill aborts, for whatever is live;
  - emits `_tool_cancel(state, "reset")`;
  - emits `tts.cancel` and `playback.flush` in SPEAKING, PAUSED and INTERRUPTED, and `stop_clip` in THINKING if an ack clip may be playing;
  - emits **no** `commit_history` and no `schedule_summary`;
  - then `_end_turn(state)` with `history=()` and `next_words=()`, and emits `ResetSession`.
- `turn_seq` keeps counting: turn ids are never reused. `first_canvas_ms` survives.
- The row goes into the docs/02 §4 table and is checked by Hypothesis:
  - after `SessionReset` the state is IDLE, history is `()`, and nothing is live;
  - every request that was live has exactly one abort;
  - there is no `TtsSpeak`;
  - a later `PlaybackStopped`, `LlmCommit` or `LlmDone` for a pre-reset request or turn emits nothing.
- `test_no_new_event_or_command_types` and `test_every_event_type_is_delivered_by_some_rule_of_the_stateful_model` gain `session.reset` and `reset_session`. That is the named spec change and the only edit to those tests. `TURN_MACHINE_SHA256` is re-pinned with a provenance comment.

**A-3. Executing `ResetSession` (`session.py`).**
- The session clears every piece of cross-turn conversational state, at least:
  - the frame list, `_frame` and `_frame_tags`, so `_history()` is empty;
  - `_calls` and `_executions`: running tasks and deadlines are cancelled;
  - the gate, the run ledger and `last_truncation`;
  - the T-0137 repeat-guard visits;
  - any carried UI fence;
  - perception frames held from before the reset. The session ignores frames whose `ts_ms` is at or below the session-clock time of the reset; this holds only if `BrowserFrameSource` is on the session clock. If it is not, stop and report.
- **Memory (ruling H-T162-1):** the session awaits `memory.forget_since(0)` through the existing `Memory` protocol. No `memory/**` code changes, and there is no `memory.ingest` for the cut turn.
  - A memory deletion that raises is logged as one `error` record. The reset still completes, and `memory_forgotten` is 0.
  - The deletion runs off the reflex path's 20 ms budget: it is awaited on the session loop as an async call, never synchronously in the pump.
- It publishes `AstraSessionCleared` and writes one session-log record: `{"kind": "session.reset", "resets", "ended_turn_id", "state_before", "memory_forgotten"}`. A turn ended by a reset has `ended_by: "reset"` on its turn line.
- Assist flags and the log toggle survive.

**A-4. Classification of every session attribute.** Every attribute that `Session.__init__` sets is listed in a module-level table, either `RESET_CLEARS` or `RESET_KEEPS`. A new attribute in neither fails a test.

**A-5. Transport (`hud_server.py`).**
- `route` sends `AstraSessionReset` to `session.submit(E.SessionReset(t_ms=clock.now_ms))`, on the one pump.
- The journal is cleared when `AstraSessionCleared` is published.
- `hello_reply` begins with `AstraSessionCleared(replay=True, resets=n, …)` when `n ≥ 1`.

**A-6. Nothing stale after the echo.** After `AstraSessionCleared`, the session publishes no `astra.canvas.*`, `astra.spoken*`, `astra.transcript`, `astra.ui.*` or `astra.tool.call` belonging to a pre-reset turn or request. Messages already in an outbox are delivered before the echo (FIFO).

**A-7. Negative (A).**
- With no reset sent, every existing golden passes unedited: `test_session_tools_off_golden.py`, `test_session_tool_loop.py`, `test_hud_hello_replay*.py`, every `*_no_egress.py`, and `test_hud_endpoint.py`'s loopback-only socket row.
- `cli.py`, `config.py`, `prompt_builder.py`, `memory/**` and `toolcall/**` are byte-identical.
- Thinking is never stored in history.

### Group B — the Tools pane and the Settings menu (page only)

**B-1. Tools pane.**
- **Panel:** a new `hud/src/tools/index.js`, mounted through `PANEL_SPECS`. It renders a rail pane headed "Tools" in the slot where Context was (between Thinking and the session log).
- **Input:** it subscribes to `astra.tool.call` only, plus `astra.turn.state` for grouping.
- **Order:** calls are grouped per turn, newest turn first; within a turn they appear in arrival order.
- **Lines:** one per `call_id`, giving the tool, its arguments in short form, and the status label.

**B-2. Short forms.** A pure, node-testable `shortArgs(name, args)` gives:
- `click_at (x, y)`;
- `type_at "…"`, with the text truncated at 40 code points, plus `at (x, y)` and `+ Enter`;
- `scroll down`;
- `press_key ctrl+l`;
- `google_search "query"`, truncated at 60;
- `page_overview`;
- for any other tool, its name plus compact JSON, truncated at 80.

All model strings are set with `textContent`.

**B-3. Status in B.** The six wire statuses are shown verbatim: proposed, repairing, dry run, executed, refused, cancelled. Failed and timeout arrive with C, from a real field, never derived from wording.

**B-4. Expandable detail.** A native `<details>` per call shows:
- every argument as `key: value`;
- the source (from the draft or repaired);
- `action`, `reason` and `query_problem`;
- the statuses seen, in order.

**B-5. No thinking (adversarial).** A canary string in a thought commit and in a canvas-step piece is absent from the pane's `textContent`.

**B-6. Settings menu.**
- A header button with `aria-label="Settings"` (a gear: a system glyph or inline SVG, no web font) opens a popover.
- The popover holds the moved assist panel:
  - the same `#assist-panel` element, `data-assist-*` hooks and gate behaviour;
  - the heading "Context helpers";
  - the plain sentence above, as a paragraph and as the button's `title`.
- The popover closes on Escape and on an outside click. Keys typed in it never trigger `m` (mute).
- Keyboard (added 2026-10-27 after review): opening it moves focus to its first enabled switch and sets the gear's `aria-expanded="true"`; Escape closes it from inside or outside the popover, returns focus to the gear when it was inside, and sets `aria-expanded="false"`.
- `assists/index.js` mounts into `host.settingsSlot` when it is given one, else into `main` as before.

**B-7. Badge stays visible.** While the server's badge is not `pixels`, the header shows it verbatim beside the gear (D12a). With every assist off, or no `astra.assist.state` received yet, nothing shows. A state that arrives while the popover is closed, including on a new socket after a reconnect, updates the badge.

**B-8. Negative (B).**
- The inline tool cards in the thread are unchanged: `tool_call.test.mjs` and `thread.test.mjs` pass unedited (ruling H-T162-5).
- The theme select stays in the header (H-T154-3).
- These are byte-identical: `hud/vendor/**`, `protocol.js`, `ws.js` and `assists/gate.js`. No `local_astra/**` file changes.
- The page requests nothing off loopback.

**B-9. Mockup parity, a named spec change (James 2026-10-26).**

### Group C — real failed/timeout statuses and short results (contract + session)

**C-1. Contract.** `AstraToolCall` gains two fields:
- `step: int ≥ 1 | None`;
- `result: ToolCallResult | None`, set only on a final message, with:
  - `outcome: Literal["executed","dry_run","refused","failed","cancelled","timeout"]`;
  - `hosts: list[str]` (at most 3 on the wire, host only);
  - `hosts_more: int ≥ 0`;
  - `results: int | None`.

`ToolCallStatus` is **not** widened. `protocol.js` mirrors the fields, and docs/02 §5 is updated.

**C-2. Filled from data, never from model prose.**
- `hosts` comes from `outcome.resolved["hosts"]` (T-0160 B-6).
- `results` comes from the search backend's count (T-0125).
- `outcome` is `failed` for a live executor failure, and `timeout` for the session deadline or a backend timeout.

**C-3. Pane.** The Tools pane shows `result.outcome` when present, else the wire status. It adds a one-line result:
- browser: `<action> · reached h1, h2 +n`;
- search: `N results (h1, h2, h3)` or `no results`;
- otherwise: the action.

**C-4. Negative (C).** With no tool calls, every message is byte-identical. The inline cards' text is unchanged.

### Group D — the Restart button and the page-wide clear

**D-1. Button.**
- A header button labelled "Restart", with a two-step inline confirm (ruling H-T162-3): "Start a new session? This clears the conversation and everything Gearvis remembers.", with **Restart** and **Cancel**.
- Confirming sends exactly one `astra.session.reset`, through a new `hud/src/session/gate.js` whose own `SESSION_CLIENT_TYPES = ["astra.session.reset"]`.
- The button is disabled while the socket is closed.

**D-2. Page-wide clear.** On `astra.session.cleared` (live or replayed), every panel clears once per new `resets` value:
- the thread: articles, card slots, A2UI surfaces and inline tool cards;
- the Tools pane;
- the denoising view: its sections, its label (back to its empty line) and the thinking meter;
- the transcript and the spoken and played state.

A repeated `resets` value clears nothing. These are kept: local errors in the error strip, assist flags, the log checkbox, the theme and the diagnostics counters.

**D-3. Capture.** The reset also stops the capture, as Mute does, so the next Share picks the new page (ruling H-T162-2).

**D-4. Negative (D).**
- Restart never fires on a key press, and `m` still mutes.
- Before the reset, older cards stay `inert` (T-0154 B8). After it, the first new surface is the newest one and sends actions.

## Implementation notes

- **The machine.** It stays pure. Model the reset on `_on_client_disconnected`, without `Degrade` and without committing history.
- **Two clocks.** The A-3 floor compares session-clock times only. Check what `BrowserFrameSource(now_ms=…)` gets in `cli.build_session`.
- **Turn ids** never repeat after a reset.
- **Memory.** `commit_history` writes episodes; a reset must not ingest the cut turn. The wipe is `forget_since(0)` on the existing protocol (`local_astra/memory/store.py:312`).
- **T-0135.** `from_thought` calls carry arguments from inside a thought. The Tools pane shows the call, never the thought around it.
- **T-0154 rulings.** Theme in the header. Older cards inert. Tokens only, system fonts. Panes self-append to `<main>`.
- **Assist panel.** Keep the `#assist-panel` id, so its own `<style>` and the tests follow it into the popover.
- **The badge** is D12a's honesty rule: hiding the switches must not hide that an assist is on.
