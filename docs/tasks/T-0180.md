## Goal

Each turn in the thread gets a native `<details>` with the summary "Model thoughts", closed by default (▸, then ▾ when opened).

**What it shows.** What the model committed in its thought channel during that turn, one labelled block per request: step 1, each tool step, re-asks, the retry after a degenerate abort, repair, and ReGround pass 2.

**Where the text comes from.** A new server message, `astra.thought`. The session publishes it from the same `segment == "thought"` commits it already logs as `llm.commit`. The page never derives thought text from canvas frames, so a draft is never presented as a thought.

**What stays unchanged:**
- history and every request body;
- `astra.spoken`, TTS, `turns.jsonl` and memory;
- the denoising view;
- every other message type.

## Acceptance criteria

### Group A: the wire, the fake, the journal

**A1. Contract.** A strict `AstraThought` (`type: "astra.thought"`), added to `AstraMessage`, `ASTRA_MESSAGE_TYPES` and `SERVER_TO_CLIENT` only. Fields:
- `turn_id`, `request_id`, `attempt_id`: non-empty strings;
- `step: int ≥ 1`;
- `kind: Literal["step","reask","retry","repair","reground"]`;
- `text: str`: cumulative committed thought text, at most `THOUGHT_MAX_CHARS` code points;
- `omitted_chars: int ≥ 0`;
- `end: Literal["open","done","stopped_repeating","interrupted","error"]`;
- `replay: bool = False`.

Refuse any of these: `len(text) > THOUGHT_MAX_CHARS`, `omitted_chars > 0` with `text` below the cap, an unknown field.

**A2. JS mirror.**
- `hud/src/protocol.js` decodes `astra.thought` with the same rules.
- `THOUGHT_MAX_CHARS` is covered by the constants parity row.
- New `tests/fixtures/hud/decode_corpus.jsonl` cases, each with the same verdict in Python and JS:
  - valid open, valid done, valid at the cap with `omitted_chars`;
  - over the cap, `omitted_chars` without the cap;
  - unknown `end`, `step: 0`, an extra field;
  - the client-to-server direction refused;
  - `text` containing `<|channel>`, a newline and `</script><b>`.

**A3. The fake.** `tests/fakes/hud_server.py` learns the type, plus a `thought_script(...)` builder. It changes in the same PR.

**A4. Journal (T-0037, T-0090 U10).**
- `TurnJournal.record` keeps the latest `astra.thought` per `attempt_id` for the current turn, in first-seen order, up to `REPLAY_MAX_THOUGHTS = 16`. Past that, it drops the oldest and sets `truncated`.
- A thought for a superseded turn is published but never recorded, and clears nothing.
- `REPLAY_MAX_MESSAGES` includes the new term and stays below `DEFAULT_OUTBOX` (512).
- `messages()` puts thoughts after tool calls and before played reports (played stays last). They carry `replay=True`.
- T-0177's `astra.vision.state` stays last in the hello reply.

**A5. Compact wire.out.** The `wire.out` row for `astra.thought` holds every field except `text`, plus `n_chars`. The thought text is already in the log as `llm.commit`.

**A6. Size.**
- `THOUGHT_MAX_CHARS = 16000`.
- A message at the cap made entirely of `\uXXXX`-escaping characters encodes under `codec.MAX_MESSAGE_BYTES`.
- 16 such messages fit in one hello reply.
- No chunking: the tail past the cap is not carried, and its length goes in `omitted_chars`.

**A7. Outbox.** `astra.thought` is non-droppable, handled as today.

**A8. Negative.**
- With no `astra.thought` published, hello replies, journal rows and `wire.out` rows are byte-identical to BASE.
- `plugin/**`, `canvas_relay.py`, `turn_machine.py`, `speech_gate.py` and `hud/src/denoise/**` are not modified.

### Group B: the session publishes (after Merge T-0180-a)

**B1. Source of truth.** For every turn request whose commits are logged as `llm.commit`, publish `astra.thought` for each `segment == "thought"` commit of each attempt.
- That covers `_stream_commits` (step 1, steps, re-ask, the T-0171 resend, the T-0179 retry), `_run_repair` and `_pass2_stream`.
- `text` equals the in-order concatenation of that attempt's thought `llm.commit` texts, up to the cap.
- An attempt with no thought commit publishes nothing.
- Prefill and the captioner never publish.
- Implicit thoughts (T-0170) and an open thought at the end of a canvas are included.

**B2. Never a draft.**
- Only committed text is published: no denoise frames, `argmax`, `text_preview` or pieces.
- An `answer` commit never contributes, even when it holds thought markers. The T-0124 splice `<|chan<eos>nel>thought SECRET` stays absent everywhere.

**B3. One end per attempt.** Every attempt that published `open` publishes exactly one final message:
- `done`: a normal end, including an end on a tool call;
- `stopped_repeating`: a T-0142 or T-0142b trip;
- `interrupted`: a barge-in or `ClientDisconnected` abort;
- `error`: the backend raised.

The only exception is a T-0162 reset or session close, after which nothing more is published.

**B4. Barge-in.**
- Thoughts committed before the abort are shown, ending `interrupted`.
- Nothing received after the abort is ever published.
- Adversarial row: the fake keeps yielding thought commits after the abort, and their sentinel appears nowhere.

**B5. Degenerate trip.**
- The tripping commit is included, and the attempt ends `stopped_repeating` (H-T180-3).
- The T-0179 retry is its own block, with `kind="retry"`.

**B6. Labels come from the session.** `step` is the session's loop step number, and `kind` the reason for the attempt. The page never infers either.

**B7. Reset fence.** `is_pre_reset` judges `astra.thought` by its `turn_id`, so a thought from before a reset is never published or journalled.

**B8. Negative: nothing the model sees or hears changes.**
- **Method:** a differential over BASE..TIP, ignoring only `astra.thought` and its `wire.out` rows.
- **Regimes:** a tools-off answer; a dry-run loop with two steps and a re-ask; a live loop with a degenerate trip and retry; a barge-in.
- **Byte-identical:**
  - every request body;
  - history;
  - `astra.spoken` and `astra.spoken.played`;
  - TTS;
  - `turns.jsonl`;
  - memory;
  - every other published message;
  - the system prompt bytes.

**B9. The narrowed leak rows** (spec change R-1; the test-author edits them). These rows change:
- `test_hud_egress.py::test_no_thought_token_ever_reaches_the_wire` (T-0028 criterion 11);
- `test_hud_hello_replay.py::test_no_thought_token_reaches_a_replayed_message` (T-0037 criterion 4);
- `test_hud_text_mode.py::test_the_typed_turn_leaks_no_thought_and_synthesises_no_stt` (criterion 21);
- the leak scan in `test_hud_rehearsal.py`.

What each narrowed row asserts:
- The thought sentinel may appear only in `astra.thought`'s `text`, and in the DOM only inside `[data-model-thoughts]`.
- Each row also asserts the sentinel **does** appear there whenever the script had a thought commit (anti-vacuity).
- Each row still asserts it is absent everywhere else, and from `turns.jsonl` and history.

**B10. No new socket**, and no change to the egress exceptions.

### Group C: the page (after Merge T-0180-a and Merge T-0177-c)

**C1. One disclosure per turn.**
- The first `astra.thought` for a turn creates its article if needed, plus one `<details data-model-thoughts>` in the assistant body.
  - **Placement (James, 2026-10-28):** it sits right under the turn's spoken/written answer. It is placed after the utterances and the turn's inline cards, as the last child of the assistant body.
  - It stays last when later utterances or cards arrive for the same turn.
  - The Thinking pane (denoising view) does not change.
- The summary reads `Model thoughts`, plus ` · N steps` when there is more than one block.
- It is never rebuilt.

**C2. Collapsed by default; the page never opens it.**
- Only the viewer's click or keyboard (Enter or Space on the summary) toggles it.
- Updates keep the current open state.
- Nothing persists across reload (H-T180-2).

**C3. One labelled block per attempt**, keyed by `attempt_id`, in first-seen order.
- **Labels:** `Step 1`, `Step 2`, `Step 2 · re-ask`, `Step 1 · retry`, `Step 3 · repair`, `Step 2 · ReGround`.
- **Body:** `textContent` with `white-space: pre-wrap`, never HTML.
- **Status lines:**
  - `thinking…` while open;
  - `stopped: repeating`;
  - `interrupted`;
  - `stopped: error`.
- **When `omitted_chars > 0`:** `… N more characters not shown (full text in the session log)`.

**C4. Latest message wins per attempt.**
- Replay is idempotent.
- Once a block is final, a later `open` message is ignored.

**C5. Reset.** `astra.session.cleared` removes the disclosures together with their articles.

**C6. Isolation.** `thoughts.js` reads only `astra.thought`, and never reads or writes canvas or denoise state. T-0159 B-4 holds.

**C7. Scrolling.** An update to a closed disclosure does not re-pin a reader who has scrolled away (T-0154 B9 unchanged).

**C8. Accessible and themed.**
- Native disclosure semantics, reachable by keyboard.
- Muted body text at ≥ 4.5:1 contrast in both themes.
- The block scrolls inside a 24 rem `max-height`, so the page never overflows sideways at 1280, 1440 or 1920.

**C9. Negative.**
- A stream with no `astra.thought` gives a thread DOM identical to BASE.
- The denoise digests are unchanged.

## Group C review rulings (2026-10-28, orchestrator)

- **C-R1. Opening or closing "Model thoughts" never moves the reader.** A viewer's toggle (click, Enter or Space on the summary) does not re-stick the thread to the bottom: the summary stays where it was on screen (anchored), whether or not the reader was pinned. Updates while the disclosure is open keep C7's rule (a pinned reader stays pinned only to new turns, not to growth caused by their own toggle). A Chrome row pins it with a thread taller than the viewport, pinned at the bottom: open the last turn's disclosure by a real click at the summary's rect, then by Enter, and the summary stays inside `[data-thread]`'s rect.

- **C-R2. A toggle does not unpin.** A reader who was pinned before toggling a disclosure stays pinned: when a new turn (a new article) arrives, they are stuck to the bottom again. Until then, updates to existing turns (thought updates, utterances, cards growing in the turn they are reading) do not move them. A reader who was not pinned stays unpinned. Rows: pinned, open the last turn's disclosure by a real click, push a new turn → `from_bottom` ≤ 2; same with an older turn's disclosure left open; pinned, open the live turn's disclosure, push a thought update to that turn → the summary does not move.

- **C-R3. Only the reader's own input releases the hold.** A scroll the reader did not make (the browser's own scroll anchoring when content above the viewport grows) neither releases the hold nor unpins them; the hold is released by a new article, `clear()`, or a scroll that follows the reader's own wheel, touch, key or pointer input. A held reader who scrolls back to the bottom by hand is pinned again and follows the live turn's growth. Rows: (1) pinned, open r6's thoughts, push an utterance to r1 (growth above the viewport), push r7 → `from_bottom` ≤ 2; (2) held reader scrolls back to the bottom by wheel, the live turn grows → still at the bottom. Utterances added above an open summary may push it down (no auto-scroll); C-R2's "do not move them" means no auto-scroll.

## Implementation notes

**B, the session.**
- **Publish point.** Publish at the three sites that log `llm.commit` (≈ `session.py` 4078, 5068 and 5657), after logging, when `segment == "thought"`. Use `self._publish` so the reset fence applies.
- **Accumulator.** Keep one accumulator per attempt. The T-0142 `thought` string exists only when the guard is on, so don't rely on it.
- **Final message.** Send it from the abort, cancel and raise paths: `try/finally` around the attempt. Never publish after a reset cancel.
- **No throttle.** Thoughts commit about once per canvas.

**C, the page.**
- `thoughts.js` exports a helper that `thread.js` calls per article.
- No DOM at module top level, and no `Math.random`.

**Privacy.**
- Thought text can quote untrusted page or search text. Showing it on the loopback HUD is accepted.
- It is rendered as text only: never HTML, links or A2UI.
- A screen recording also exposes it, which is one reason it is collapsed by default.

**Tests.** Oracles come from the session log and from hand-written strings.
