## Evidence that shaped the plan

**The cua-diffusion-gemma repo** (OSWorld, 369 tasks, 15 steps, seed 0; bf16, HF transformers, H100):
- Base model: 15.1% on the early harness (n = 5) and 17.75% with more reasoning canvases plus last-line action anchoring (n = 4). The best single run was 20.05% (n = 1).
- Every fine-tuned checkpoint scored below base (8.7–11.4%), so fine-tuning is out of scope.
- Clicks were grounded correctly. The dominant failures were:
  - the wrong or inert target;
  - repeating a previous click (32.6% of actions);
  - never stopping (321 of 350 episodes hit the cap);
  - typing never committed;
  - infeasible tasks never declined.
- An executor bug failed every drag until a late fix, so executors get end-to-end tests.

**Published harness practice** (research report 2026-10-17; several 2026 figures are vendor claims):
- verification before "done" and a before/after screen check;
- a loop breaker;
- about 3 screenshots of history plus a text history of thought and action;
- a small typed action set with wait, done and fail;
- a single policy rather than a planner/worker split;
- zoom only when uncertain;
- a sandbox, plus human confirmation before irreversible actions;
- prompts alone do not stop on-screen prompt injection.
