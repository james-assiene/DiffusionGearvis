## Goal

Add the loop rows R11–R18 to `conductor/turn_machine.py`, behind `TurnPolicy.tool_loop` (default `False`), exactly as T-0111a §2 specifies:
- the new event `ToolResult` (it carries no text);
- the new command `LlmContinue`;
- the new timer `tool_result`;
- the new `ToolCancelReason` value `"step_budget"`;
- the new per-turn `MachineState` fields;
- history joined across playback runs;
- a takeover after an action that does not re-run that action.

With `tool_loop=False` the machine is identical to a frozen copy of today's machine on every sequence (L8). The executor gets only an inert `LlmContinue` handler. Session wiring is T-0114.

## Acceptance criteria

T-0111a criteria 1–9 (the a1 block), verbatim, plus:
- **(10)** `turn_machine.py` stays pure: no I/O, no clocks and no asyncio (CLAUDE.md; `.claude/rules/conductor.md`).
- **(11)** The machine never receives tool-result text.
- **(12)** P1–P9 and R1–R10 pass unedited. New properties are added, and none is weakened.
