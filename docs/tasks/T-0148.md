## Triage (planner, 2026-10-24)

**Verdict: the oracle is wrong; the machine and the speech gate are correct.**
- **What fails.** `TurnMachineModel.step_is_pure` (`tests/unit/test_turn_invariants.py:1393-1395`) calls `self.m.step(self.s, Tick(t+1))` twice on the same state. The machine's segmenter seam is the model's own stateful `SpeechGate` fixture, so the first probe call feeds the gate and its result is thrown away. The second call then meets a gate that has moved ahead of the machine's `held_text`, and the line-704 prefix assertion fires inside the probe, not on any real step. The traceback path is `step_is_pure` → `_on_tick` → `_resume` → `_speak` → `_segment`.
- **Replay** (52d2452; Python 3.11.16, Hypothesis 6.168.0; scratchpad `t0148-planner-replay/`). The 126 rule steps fail at rule 125 every time. With the purity probe left out, every other invariant passes. With a probe that gives each call its own copy of the gate, all of them pass.
- **Minimal sequence** (`minimal.py`, times in ms):
  1. Onset 0, word "what" 400, end_of_turn 500 (t_eot 450), flushed 505, `Tick(505+eot_settle_ms+1)` → THINKING.
  2. `LlmCommit(" line four.", 1000)` → SPEAKING; the gate holds `' line four.'`.
  3. Onset 1100 → PAUSED; offset 1200 (speech_ms 300) arms `resume` at 1800.
  4. `LlmCommit(" line four.", 2000)` while PAUSED → `held_text=' line four. line four.'`, nothing spoken.
  5. The probe calls `step(s, Tick(2001))` twice. The first call feeds the gate; the second trips the assertion.

  A second shape (seed 160, `shapeE.py`) has the same mechanism, with a balance hold released while PAUSED. Two more shapes move the gate silently: `close()` on a final resume, and `pending` growing.
- **User-visible symptom: none.**
  - Without the probe, the real `Tick(2001)` speaks `' line four. '` and `LlmDone` speaks `'line four.'`. Together they equal the committed text byte for byte. Every `TtsSpeak.source` is committed text, and history is unaffected.
  - The product calls the machine once per event, at `local_astra/conductor/session.py:1488`.
  - Latent hazard: a second call with the live session gate would make `session._segment` re-feed the whole tail, so the conservation check would raise `ValueError` and the turn would go silent. Criterion 9 guards against that.
- **Why it was not seen before.** It needs a rare combination: PAUSED with a live generate, a non-tick rule passing `resume`, and an answer commit made while PAUSED that completes a sentence. The planner swept 1,260 class runs and found it once (Invariants seed 160); BoundedState gave 0 of 700. Hypothesis 6.168's literal pool adds constants from loaded local modules, so a fresh worktree with new modules and an empty `.hypothesis/` explored a new region. Once found, the reuse phase replays the failure on every run.

## Goal

`TurnMachineModel.step_is_pure` checks purity by calling `step` twice on the same state. Both calls go through the model's stateful `SpeechGate` fixture. In a PAUSED turn whose `resume` deadline has passed, with answer text committed while paused, the first call feeds and advances the gate. The second call then fails `_segment`'s prefix assertion (`test_turn_invariants.py:704`). In other shapes the gate silently drifts away from the machine (`close()` empties it, or `pending` grows).

The machine is correct. It voices exactly the committed text and nothing else, and a single real step produces no drift.

After this task, each probe call runs against its own copy of the gate as it was at the probe. The model's gate comes out of the probe unchanged, and that is asserted. The equality of the two results is still asserted. So the property keeps its full strength and gains a check that the probe cannot change the gate it relies on. Nothing in `local_astra/` changes.

## Implementation notes

- Change only the probe. Do not touch `_segment`, its assertion, or any settings object. The probe draws nothing from Hypothesis and must stay that way, so generation is unchanged.
- `SpeechGate` is a dataclass with equality, so `==` on a deepcopy compares `pending`, `emitted`, `refused_count`, `refused_sources` and `_stopped`. Snapshot once; each call gets its own copy taken from the snapshot; restore the original afterwards; compare the original with the snapshot. If both calls share one copy, criterion 1 fails again (that is mutation M1).
- Subclasses read the segmenter state only through `self.gate` (there is one `_segment` and one `step_is_pure` in the module, checked). If a subclass ever holds more segmenter state, the probe must isolate that too.
- Landmines from `.claude/rules/tests.md`:
  - run mutation checks with `settings(database=None)` and at least 2 seeds, because a saved example replays;
  - use uniquely named scratch copies, with `PYTHONPATH` set to the copy, the cwd inside it, and `__file__` printed;
  - purge `__pycache__` under `tests/` between arms;
  - Hypothesis 6.168's literal pool makes seed results depend on which local modules are loaded, so compare arms in the same file.
- Proposed rule line for the orchestrator (tests.md): "A probe that calls a pure function twice must give each call its own copy of any stateful fixture behind an injected seam (T-0148)."
