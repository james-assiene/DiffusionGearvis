## Goal

With tools off (`kit=None`, the default), answer commits reach the machine and the speech gate exactly as the backend sent them. A correct client never puts `<|channel>…<channel|>` in a `thought_open=False` answer commit. When a buggy client or stream does, the gate trims the voiced `text` at `<|channel>`, but the sentence `source` keeps every byte (the gate's conservation rule, A1). `played_text` is built from `source`, so history stores thought text and markers, and records more than was voiced. Confirmed at session level by the T-0117 test-author: `Here <|channel>thought SECRET<channel|> it is. ` voices `Here` and stores `Here <|channel>thought SECRET<channel|> it is. `.

After this task, the tools-off path removes thought blocks and stray channel close markers before anything reaches the machine, using the router's thought rule (`router.answer_channel`), the same rule T-0117 applies with tools on: a closed block is removed with its words; everything from an open that nothing later closes is dropped from voice and history; the words around a block are kept byte for byte. Every played `source` is then thought-free, history equals the join of what was played, and one `note` gives the dropped character count, never the text.

Nothing else on the tools-off path changes: no other special literal is deleted (the gate handles those as before); `thought_open=True` commits pass through unchanged; the speech gate, the machine, the router and the tools-on cleaner are untouched; when no channel marker appears, output stays byte-identical to `791dc54`, and the tools-off golden is unedited and green.

## Acceptance criteria

These apply test-plan P4, CLAUDE.md ("never store assistant thinking in history; store only what was spoken") and `.claude/rules/conductor.md` to the tools-off path, as T-0117 did for tools on.

**T(raw)** is the tools-off cleaned text of the concatenated raw `thought_open=False` answer texts of one stream. The cleaner repeats this round until a round changes nothing: (1) apply `router.answer_channel` repeatedly until its output is stable (a removal can splice a new block, T-0117 F3); (2) delete every stray `<channel|>`. Nothing is inserted; no other literal is deleted; a marker a deletion splices together is handled like one written in full (T-0117 F1).

1. **Voiced turn, closed block.** Tools off, one commit `answer("Here <|channel>thought SECRET-THOUGHT<channel|> it is. ")`: every `TtsSpeak.source` joins to exactly `Here  it is. ` (two spaces, H-T117-2), and so do the audio plays' sources, `played_text` and `history[-1].assistant_spoken`. `SECRET-THOUGHT`, `thought SECRET`, `<|channel>` and `<channel|>` appear in none of these, nor in `astra.spoken`, `turns.jsonl` or the memory episodes. The positive string is asserted exactly.
2. **History equals what was played.** For every utterance actually played in criteria 1, 3, 4 and 6: `normalise_for_tts(source) == text` (the gate's public renderer); `history[-1].assistant_spoken` equals the join of the played utterances' sources, in order; a barge-in row cutting mid-answer after a removed block stores the `played_text` the audio fake reports, with no thought bytes.
3. **Marker split across commits.** `answer("Here <|chan")` / `answer("nel>thought SECRET-THOUGHT<chan")` / `answer("nel|> it is. ")` gives criterion 1's result; a variant has the open in commit 1 and the close two commits later. No `LlmCommit` the machine receives contains `SECRET` or a marker prefix that later completes a marker.
4. **Unclosed at the end.** `answer("Okay <|channel>thought SECRET-THOUGHT")`, `thought_open=False`, the open mid-sentence: voices and stores exactly `Okay `; nothing after the open is submitted before or at `llm.done`. (A test with `Okay. ` is probably green at base and proves nothing.) When a later commit closes the block, the text after the close is voiced: `Okay <|channel>x` / `y<channel|> fine. ` gives `Okay  fine. `.
5. **Streaming and chunk independence (I12, tools-off form).** The concatenation of every released text plus the flush equals T(raw) for every split of raw into commits; each cumulative release is a prefix of T(raw); no release contains thought text when returned.
6. **Stray close.** `answer("Done <channel|>here. ")` voices and stores `Done here. `; no marker reaches history; no note.
7. **The note.** One session-log `note` per stream whose thought stripping removed at least one character: `{"what": "thought text in an answer commit was not voiced", "request_id": <machine id>, "step": 1, "chars": n, "unclosed": bool}`, after the held tail is submitted and before `llm.done`. `chars` counts only what `answer_channel` removed, markers included (criterion 1: `len("<|channel>thought SECRET-THOUGHT<channel|>")`). No value holds any 4-character substring of the thought; exactly one note per stream; none when nothing was removed; `llm.commit` keeps the raw text.
8. **The word "thought" is speech.** `I thought so, and I still do. ` is voiced and stored verbatim.
9. **Negative: byte-identical with no channel marker (differential against literal `791dc54`).** Via T-0114's `_base_tree` with `BASE_SHA` monkeypatched, as T-0117 does. Tools off: a toolless typed turn, `Press <|tool_call> now. `, the split `Press <|tool` / `_call> now. `, `x < y and y > z. `, the word "thought", `Press <b` + a `thought_open=True` commit + `ack> now. ` (I15), a `thought` segment followed by answers, a barge-in turn. Tools on, loop off: `Sure, <|channel>thought SECRET-THOUGHT<channel|>here it is. ` (contains a marker; must still be identical, the tools-on path is untouched). Machine steps, HUD messages, prompts, request bodies, every session-log record and `turns.jsonl` equal; the first difference is printed. A separate tools-off row, `Wait <|chan` never completed, compares the `TtsSpeak` (source, text) sequence, history and `turns.jsonl` with the base; its machine section may differ only in that the held `<|chan` arrives as its own commit before `llm.done`.

## Implementation notes

- A guard against a buggy client. Do not change the client, the gate, the machine or the router.
- The gate's conservation (A1) and the machine's `"".join(sources) + remainder == text` check are why the fix goes before `submit`, not at the gate.
- Use `router.answer_channel` for the thought rule; not `route()` (cuts at tags) and not `drop_special_literals` (would change the tools-off literals).
- The hold is no wider than the marker alphabet: a tail can grow into a marker only if it starts at a `<` and every following character is from `<|channel>` other than `>`; any other character is a barrier. That keeps `Press <|tool`, `x < y` and `Press <b` unheld. Prove it with the property rows.
- Commits that clean to nothing because text was withheld are not submitted; a commit with empty raw text is submitted as at base.
- The note's keys match T-0117's, with `step` fixed at 1.
- Mypy strict. No heredocs to the scratchpad. If a test looks wrong, tell the reviewer.
