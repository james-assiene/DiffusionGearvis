# T-0060 — the transcript may be written screen by screen, optional, off by default

**Status:** planned 2026-09-17 · **Blast radius:** A medium (the text of every prompt that opts in; named escalation triggers below), B high (`session.py`, the capture pump, the request that goes to the GPU — two reviewers), C `/launch` · **Groups:** A (the builder writes it) **then** B (the session measures the cut and turns it on), C the measured criterion · **Origin:** the human, 2026-09-17: *"I can imagine a scenario where someone wants to compare 2 frames by showing the first one and describing the key information and then showing the other frame, do the same and ask DG for an answer. In this case, interleaving text and frames … would make more sense … make it an optional feature."* · **Depends on:** **T-0059 group B merged** (group A) and **T-0059 group C merged** (group B) — this task owns no file until T-0059 releases it; T-0003 (turn machine, merged), T-0032 group A (the capture pump, merged), T-0020/T-0053 (prompt budget and recollections, merged)

**The protocol is not skippable.** The diff is not one sentence. It changes what the model is told about *when* the user said each thing, which is a claim that can be silently false: a segment boundary off by one word binds "this one is the renewal quote" to the invoice, and the model then answers confidently about the wrong screen. That failure is invisible in the code, invisible in the turn line unless this task puts it there, and only visible in a transcript nobody reads.

## Goal

After T-0059 a turn that spans two screens sends `[label₁][img₁][label₂][img₂][transcript]`: the model sees both screens and the whole question, but nothing tells it which half of the question was spoken while which screen was up. For the comparison the human describes — *show the first page, say what matters about it, switch, say what matters about the second, ask* — that is exactly the missing fact, and the model has to guess the binding from content. This task adds an **opt-in** rendering of the query-dependent suffix in which the transcript is cut at the scene-change times and each piece is written under the **same label T-0059 already prints beside its image**, so the text binds to the picture without a single pixel moving. It is `Budget.interleave_transcript`, default `False`; with it off the prompt is byte-identical to T-0059's, and with one frame it is byte-identical whether the flag is on or off. **The images do not move**: T-0059 ruling A1(7) stands — the frames still precede the first transcript fragment, the cached prefix still ends at the last image, and everything this task writes lives in the suffix, so the anticipatory prefill and B11 are untouched. True interleaving (`img₁ text₁ img₂ text₂`) is *Ambiguities* 1, priced there and not taken.

### Design rulings (these are what the implementer works to; the tests pin them, this prose does not)

**D1 — the interleaving lives in the suffix, and that is what makes it free.** `prefix()` is not a function of the flag: with `interleave_transcript` on or off it returns a byte-identical `Prompt` for the same arguments (criterion 6). Everything added is text appended to the last user message by `full()`, after the assists, where T-0059 already puts the transcript. Consequence, stated as the price of the shape: the model reads the pictures before it reads the words that go with them, and the binding is carried by a repeated label rather than by adjacency. The measured alternative is *Ambiguities* 1.

**D2 — the cut comes from the capture clock, not from the recogniser's output, so the 0.5 s lag is avoided rather than corrected.** Kyutai delivers a word roughly half a second after its audio (`contracts/events.py` header; T-0051 measured per-word delivery lags of 874/875/890/923 ms and a ≈ 510 ms steady-state delay on **CPU** STT on this box). A cut placed at "the last word delivered when the scene changed" is therefore late by that lag — two to four words at ordinary speech rate, which is the whole of a short clause and precisely the misattribution this feature exists to prevent. But the audio time *at the instant of the change* is already in the session: `_pump_capture` feeds `stt.feed(pcm, int(frame.t_ms))` and `frame.t_ms` is the capture clock — **the same clock the word times are based on**, because the STT client bases them on the fed-audio position. So the session records the newest capture-frame time as it goes (`_capture_now_ms`), and the cut for a scene change is that value, read when `SnapshotFrame` executes. Word times and cut times are then both capture-clock times and the comparison is a single-clock one (`.claude/rules/conductor.md`: *"a duration is never computed from two clocks"*). No lag constant is introduced, and none is needed.

**D3 — what D2 does *not* fix, recorded rather than worked around.** Three things. (i) With no capture source — `astra session --silent`, text mode, most unit rows — `_capture_now_ms` is `None` and the cut falls back to `words[-1].end_ms` (late by the emission lag) and then to `onset_ms` and then to `0`; the chain is pinned by criterion 13 and the fallback is named in the turn record. (ii) An STT reconnect mid-turn re-bases word times (T-0007a), so a cut taken before it is on the old base; the turn record carries the cuts and the per-segment word counts so the damage is diagnosable, and nothing here tries to detect it. (iii) **Pre-existing finding, not this task's to fix:** `SceneChanged.t_ms` is `Frame.ts_ms`, which `BrowserFrameSource` stamps from the injected `now_ms` — wired in `cli.py` to `clock.now_ms`, the session's *monotonic* clock — while `onset_ms` is an audio time, so today's `get_frame(at_ms=onset)` already compares two clocks and `browser_source.py`'s docstring ("``Frame.ts_ms`` is that receive time … ``get_frame(at=speech_onset)`` compares against audio time") is optimistic about it. This task is careful not to add a fourth instance: **the scene change's own `t_ms` is never compared with a word time.** Routed to whoever next owns `perception/browser_source.py`.

**D4 — one label, one segment, and the count must agree or the feature turns itself off.** T-0059's `_assemble` drops a current frame whose phash equals the newest history image still carried as pixels (its B9/D9 rule) and dedups repeats, so **the number of images in the prompt is not always the number of frames the session captured**. A segment list built from the frame list would then be off by one against the labels, and every later segment would be bound to the wrong screen — silently, with a perfectly well-formed prompt. So: the rendering is legal only when `len(segments) == the number of ImageParts in the last user message`, and on any mismatch `full()` renders **the plain transcript** and the mode recorded for the turn says which fallback fired. A wrong binding is worse than no binding; a missing feature is a line in the turn record.

**D5 — the labels are T-0059's, verbatim, and there is no second wording family.** Each segment is written under `frame_label(i)` — the same string, same index, same constant — so the model binds text to image by literal identity and the "the first screen" phrasing T-0059's criterion 24 measures is not forked into two dialects. One new constant, `INTERLEAVE_HEADER`, introduces the block. The labels are in the suffix here, so a total (`1 of 3`) would be cache-safe — and is still forbidden, because the same function also renders into the prefix where T-0059 D4 makes it fatal, and one function may not mean two things.

**D6 — no word is ever lost, reordered or duplicated, and the guard is an equality, not a review.** `split_transcript(words, cuts_ms)` is pure and total, and the concatenation of its non-empty segments is **byte-equal** to the transcript the machine built from the same words (`" ".join(w.text …)`). Cuts are clamped monotone before use, so a regressing cut (possible only on D3(i)'s fallback path) shifts a boundary and never crosses two words. An empty segment is omitted entirely rather than rendered with a "nothing said" marker: the surviving labels name their own index, so nothing is misattributed, and a screen the user said nothing about is simply a picture with no line under it.

**D7 — no change to the system prompt, and no new session-log kind.** `ui_instructions.py` is T-0055's and still owes criterion 12's token count under `/launch` (T-0059 D7); `KINDS` in `telemetry/session_log.py` is T-0043's closed vocabulary and the `llm.request` dump already carries the prompt. The instruction that makes this legible ("the user was looking at different screens while speaking; each block below says which") is **one sentence of `INTERLEAVE_HEADER`, inside the turn's own user message**, where the flag can be off without a re-count.

## Acceptance criteria

Numbering is stable; tests cite it. Criteria 1–12 are group A, 13–19 group B, 20 group C (`gpu`, `/launch`). "Today" means `main` **with T-0059 merged**, which is this task's baseline — every "byte-identical to today" below means *identical to T-0059's output*, not to pre-T-0059 `main`.

### Group A — the builder can write the transcript screen by screen

1. **The split loses nothing.** A module-level pure `split_transcript(words: Sequence[Word], cuts_ms: Sequence[int]) -> tuple[str, ...]` (the name is contract) returns exactly `len(cuts_ms) + 1` strings, and `" ".join(s for s in result if s)` equals the transcript built from the same `words` by an **independent oracle** — the `LlmStart.transcript` a real `TurnMachine` emits for that word sequence, not a re-implementation of the join inside the test. Word order inside and across segments is the machine's audio order. *(D6; `.claude/rules/tests.md`: no re-implementing the function under test.)*
2. **Boundaries are clamped monotone.** `cuts_ms=(900, 400, 1500)` is treated as `(900, 900, 1500)`: the middle segment is empty, no word moves backwards, and the criterion-1 equality still holds. A cut before the first word's `start_ms` yields an empty first segment; a cut after the last word's `start_ms` yields an empty last one. *(D6.)*
3. **An empty segment is omitted.** The rendering skips a segment with no words and prints no label for it; the labels that remain are still `frame_label(i)` for their own `i`, never renumbered. Adversarial row: the user says everything before the first switch, then switches twice in silence — one line under the first label, nothing under the other two, and the images are all still there.
4. **The rendering, with the flag on and more than one image.** `full(prefix, transcript, …, transcript_segments=segs)` with `budget.interleave_transcript=True` appends, as the **last** text of the last message and after the assist blocks: `INTERLEAVE_HEADER`, then for each kept index in order `frame_label(i)` followed by that segment. The plain `transcript` string appears **exactly once** in the message — as the segments, not additionally. *(`.claude/rules/conductor.md` prompt layout: the transcript is last in the query-dependent suffix.)*
5. **The labels bind by identity, not by resemblance.** The string `frame_label(i)` occurs verbatim in the block for segment `i`, and `prompt_builder` defines **no second per-index wording constant**: a test asserts the rendered label for index `i` is `frame_label(i)` itself for `i` in `0..max_frames_per_turn-1`, and that `frame_label` is unchanged from T-0059 (compared by hash of the module constant, never by a copied literal). *(D5; T-0059 criterion 14.)*
6. **The cached region does not move, with the flag on.** For the same arguments, `prefix(...)` returns a prompt whose serialised parts are **byte-identical** with `interleave_transcript` True and False; `prefix.shares_prefix_with(full(prefix, …, transcript_segments=segs))` is True; and the part sequence of the prefix is a strict prefix of the full prompt's, compared on serialised parts. *(D1; docs/01 D9; docs/03 B11 ≥ 0.9; T-0059 criterion 9.)*
7. **A count mismatch turns the feature off, loudly in the record.** A module-level pure `transcript_mode(images: int, segments: Sequence[str], budget: Budget) -> str` (name is contract) returns one of a closed set — `off`, `single_image`, `interleaved`, `mismatch` — and is the **only** place the decision is made; `full()` and the session both call it, so the prompt and the turn record can never disagree. With `images=2, len(segments)=3` the mode is `mismatch` and `full()` renders the plain transcript, no header, no labels. Adversarial row: the T-0059 history-dedup case — the first current frame's phash equals the newest history image, so `_assemble` attaches two images for three frames — must produce `mismatch` and a plain transcript, **not** a three-label block over two pictures. *(D4; T-0059 criterion 10.)*
8. **The flag off is byte-identical to T-0059 (negative).** With `interleave_transcript=False`, `full()` and `fit()` return prompts byte-identical to T-0059's for the same inputs **whatever is passed in `transcript_segments`** — the flag, not the argument, is the switch. `tests/unit/test_prompt_frames.py`, `test_prompt_builder.py`, `test_prompt_budget.py`, `test_prompt_recollection.py` pass with the **assertion diff empty** (`git diff main...HEAD -- tests/ | grep -E "^-[^-]" | grep assert`) and no fall in per-module assertion count. *(`.claude/rules/tests.md`.)*
9. **One image changes nothing (negative).** With exactly one `ImagePart` in the last user message the mode is `single_image` and the prompt is byte-identical with the flag on and off, for `frames=(f,)` and for `frame=f`. This also means `Budget(max_frames_per_turn=1)` — T-0059's rollback lever — is still byte-exact with `interleave_transcript=True`.
10. **Nothing else in the module moves (negative).** `system_message()` byte-identical (by hash, derived from `system_prompt` + the constants, never from a copied literal — T-0053 ruling A3, T-0055's owed token count); `frame_label`, `_caption_part`, `MEMORY_HEADER`, `RECOLLECTION_MARKER`, `NO_IMAGE_STATEMENT`, `relative_age`, `ANSWER_HEADROOM_TOKENS` and every existing `Budget` field and default unchanged; `Budget` gains exactly one field, `interleave_transcript: bool = False`; no contract in `local_astra/contracts/` changes; `prompt_builder.py` still imports no clock (the T-0053 criterion 11 AST scan still passes); `mypy --strict` clean.
11. **The added text is bounded.** `INTERLEAVE_HEADER` plus three repetitions of `frame_label` ≤ 320 code points in total, asserted numerically against the constants. **Structural bound, explicitly not a token claim** (T-0044 ruling A2); the token cost is criterion 20's.
12. **`fit()` never spends a segment.** `transcript_segments` threads through every rung unchanged; no ladder rung shortens, drops or merges a segment, and a prompt that cannot be made to fit comes back `fits=False` with the segments intact. *(T-0020 ruling A1: the user's turn is never truncated.)*

### Group B — the session measures the cut, and the turn line says what it did (after T-0059 group C merges)

13. **The cut is the capture clock, and the fallback chain is pinned.** The session records the newest capture-frame time (`_capture_now_ms`, from `frame.t_ms` in `_pump_capture`) and, when `snapshot_frame` runs for a scene change, appends that value as the cut for the frame it is capturing. Four rows: with a capture source, the cut equals the last block's `t_ms`; with no capture source it is `words[-1].end_ms`; with neither it is `onset_ms`; with none of those, `0`. The fallback that fired is named in the turn record (criterion 15). *(D2, D3(i).)*
14. **The headline row: a word spoken before the switch stays on the earlier screen.** Over `FakeStt` with a non-zero emission lag (`tests/fakes/stt.py` releases a word only once `fed_ms >= end_ms + lag_ms`, so this is the real ordering, not a hypothetical) and `FakePerception`: onset, words *w₁ w₂*, `scene.changed` B, words *w₃ w₄*, end of turn — with the flag on, the final request's block under `frame_label(0)` is `"w₁ w₂"` and under `frame_label(1)` is `"w₃ w₄"`, **including when w₂ is delivered after the scene change**. **Adversarial and the reason D2 exists:** the same row against a cut taken from the last *delivered* word must put `w₂` on the wrong screen — the test-author runs that mutation and reports it. *(docs/03 I2; D2.)*
15. **The turn line says which mode and where the cuts were.** `TurnRecord.extras` gains `transcript_mode` (the closed value from criterion 7's function, plus the fallback tag from criterion 13 when one fired), `frame_cuts_ms` (the ordered cuts) and `segment_words` (words per segment). Present on **every** turn, including flag-off turns, where the mode is `off` — the assist badge is logged whether or not an assist is on, and which screen the model was told the words belonged to is the same class of fact. **No new session-log kind** (`KINDS` is T-0043's; the `llm.request` dump already carries the prompt). *(`.claude/rules/perception-memory.md`.)*
16. **The prefill is untouched (negative).** For the same driven session, the sequence of prefill requests — count, ids, and the serialised prompt of each — is **byte-identical** between a flag-on and a flag-off run; only the final generate request differs. Asserted on the fake LLM's recorded calls. *(D1; docs/03 B11.)*
17. **The words are snapshotted on the pump, not read from live state in the task.** `begin_generate` captures the word tuple and the cuts synchronously, exactly as it already captures `transcript`, and `_run_generate` uses that copy. **Adversarial:** a barge-in (`UserTakeover`) delivered between `LlmStart` and the moment the request is assembled must not change the segments of the request already in flight; an implementation reading `self._state.words` inside the task fails this row.
18. **A flag-off session is exactly what T-0059 does (negative).** With `interleave_transcript=False`: the final request is byte-identical to T-0059's, the turn line differs only by the three additive `extras` keys of criterion 15, no new message reaches the page, `hud/**` and `local_astra/contracts/protocol.py` are untouched, and `tests/unit/test_session_frames.py`, `test_session_prompt.py`, `test_session_record.py`, `test_session_over_long_prompt.py` keep every existing assertion (assertion diff empty). Note that `test_prompt_budget.py` greps `session.py` for a slash-four shape, so a docstring written here containing e.g. "3/4" reddens an unrelated row (`.claude/rules/tests.md`).
19. **The capture pump still feeds exactly what it fed (negative).** `stt_frames_fed`, `stt_feed_errors`, the order and the byte content of the `stt.feed` calls, and the "no capture seam" degradation row are unchanged; the added line records a timestamp and gates nothing. The row is written so that a build which records the time only for frames that were *successfully fed* (rather than for every frame the source yielded) reddens it — that distinction is what keeps T-0048's feed gate from silently changing this cut's meaning.

## Implementation notes

- **Why the pure machine is not touched.** `snapshot_frame` is awaited **inline** in `Session._handle`, after `self._state = new` and before the next event is pumped (the pump has one consumer), so at that moment `self._state.words` is exactly the words delivered before the `SceneChanged` — and `self._capture_now_ms` is exactly the audio time reached. Everything the cut needs is already in the session; a `MachineState` field would put a clock-derived quantity in a module whose whole discipline is that time arrives as an event. Do not "improve" this into a machine field.
- **Indices into `words` are not stable — use times.** `turn_machine._buffer` inserts by *audio* order (an out-of-order word lands in the middle) and drops the oldest at `max_buffered_words`, so "the cut is word number 7" silently shifts. The cut is a time and the split is a comparison on `Word.start_ms`.
- **`transcript_mode()` is the single authority.** The prompt and the turn record must never disagree about what the model was told; one pure function, two callers, and the reviewer checks there is no second predicate in `session.py`.
- **`full()`/`fit()` signature.** Add keyword-only `transcript_segments: Sequence[str] = ()` to both; the default reproduces today exactly, and criterion 8 says the *flag*, not the argument, decides. `mypy --strict` clean without an overload zoo; if the honest signature needs one, that is the implementer's call and the reviewer's to check.
- **The labels are suffix parts here and prefix parts in T-0059.** `_extend` appends to the last message — that is the right place for this block, and it is the wrong place for T-0059's per-image labels. Do not unify the two call sites.
- **`_pump_capture` is contested.** One assignment, no branch, no gate, nothing awaited: T-0047 group A wants a level tap and T-0048 group A wants a feed gate in the same method. Record the time for **every frame the source yields**, before the `feed()` try-block, so a future gate that skips a frame does not move the cut (criterion 19 pins that direction).
- **`begin_generate` already shows the pattern:** `LlmStart.transcript` is passed into the task rather than read from state. Pass the words and the cuts the same way (criterion 17).
- **Do not add a session-log kind** — `KINDS` is closed (T-0043) and the prompt dump already carries the text.
- **Frames from two sources.** `Frame.ts_ms` for a screen frame and a camera frame are not on one clock (T-0059's note); this task adds nothing that computes a duration from them, and must not start. The cut is a capture-clock reading taken *when the command runs*, never a subtraction of a frame timestamp from a word time.
- After two failed corrections in a session, stop and rewrite the task rather than stacking fixes (CLAUDE.md).

## Ambiguities for the human to decide

1. **True interleaving (`img₁ text₁ img₂ text₂`) — offered, priced, not taken.** It reads better to a human and probably to the model, and it is what the request literally says. Its cost is the prefix: text that sits *between* two images depends on words that have not been spoken when the second image is appended, so the anticipatory prefill can no longer extend past the **first** image, and every scene change becomes a rewrite rather than an append (T-0059 D1 and docs/01 D9's guarantee both fall). Arithmetic from T-0059 D2's ≈ 1 120 visual tokens per screen: on a three-frame turn the cached region drops from roughly `system + history + 3 images` to `system + history + 1 image` — of a ~4 200-token prompt, from ≈ 0.92 to ≈ 0.39 hit fraction, against docs/03 B11's floor of **0.9**. That is an estimate from an unmeasured token count, not a measurement, and it is the reason this task puts the text in the suffix instead. Say so if the binding quality matters more than the cache; it is then its own task, not a flag on this one.
2. **The cut's meaning at the cap.** When T-0059 D1 replaces the last frame slot, this task keeps the recorded cut for that slot, so the final segment covers the words spoken under *both* the replaced and the replacing screen. It never loses or reorders a word, and it is mildly wrong. The alternative — move the cut to the replacement — makes the middle screen's words vanish into the previous segment instead. Neither is right; pick the one whose failure you prefer.
3. **How it gets turned on.** Today it is `Budget(interleave_transcript=True)` at the composition root and nothing else: no CLI flag (`cli.py` is contested), no HUD checkbox (that needs an `astra.*` message, a panel and a `contracts/protocol.py` edit — T-0059 *Ambiguities* 4 already queues a HUD task for the frames themselves, and the two belong together). If you want to try this at the desk without a rebuild, say so and it becomes `astra session --interleave-transcript`, a small task behind whoever holds `cli.py`.
4. **Whether it should be the default once measured.** If criterion 20's interleaved arm wins and the cache fractions really are equal, there is no argument left for the flag except caution. The flag stays until that run exists; after it, flipping the default is a one-line task with the eval attached.
5. **The emission-lag constant is avoided, not measured.** D2 sidesteps it by reading the capture clock, so no lag number is introduced. If the fallback path (no capture source — text mode, `--silent`) is ever used for a real comparison turn, its cut is late by that lag and the record says so; nobody has measured the lag on the **GPU** STT path (T-0048 changes it). Worth one line of a bench if text mode matters.
6. **Camera plus screen in one turn.** Two sources, two clocks, and the cut is a *capture*-clock reading, so a camera frame's arrival cannot be placed on the audio timeline at all. Out of scope here; if "show me this on camera, now look at my screen" is a turn you want, it needs the clock question answered first (D3(iii)).
