### Design decision: what the seed is
The pass-2 canvas starts right after the pass-2 prompt, and the three thought variants put different things at its front
(`decoding/toolcall.py`):
- T1 = `100 · name · 107 · FREE* · 101 · [<cc>] · WS · CALL`, with the prompt identical to pass 1;
- T2 = `100 · name · 107 · 101 · [<cc>] · WS · CALL`, with the prompt identical to pass 1;
- T4 = `WS · CALL`, with the prompt ending in `spoken_prefix + "<cc>"`.

No grammar admits the spoken prefix that pass 1 writes before `<cc>`. The seed therefore takes the model's own tokens for every slot the
grammar has, and drops only what no pass-2 grammar can hold:

    seed(thought) = (H(thought) + encode(T(thought) + draft_call_text) + S)[:CL]

- **H(T1)** = pass-1 `token_ids` verbatim, up to and including the first `101`, if they start with `100` and contain a `101`. Otherwise it is
  the empty-thought header `(100, 45518, 107, 101)`. The T1 prompt equals pass 1's, so these positions line up exactly.
- **H(T2)** = `(100, 45518, 107, 101)`, the empty thought, which is the only thought T2 admits.
- **H(T4)** = `()`. The prompt already ends at `<cc>`.
- **T(T1) = T(T2)** = `"<cc>"`, which the grammar admits as the optional tag. **T(T4)** = `""`.
- `draft_call_text` = the router's text after `<cc>` in pass 1's host-decoded answer, used raw: no parse, no trim, no host repair.
- `encode` = `vocab.encode` (pinned HF tokenizer, no BOS).
- **S** = `[s]`, where `s` is the first stop id (`replay.STOP_IDS`) in pass-1 `token_ids`. It is empty when pass 1 ended without a stop.
- `CL` = 256, the engine-global canvas.

Why each choice:
- **Re-tokenise rather than slice pass-1 ids after the tag.** `<cc>` is not a special token, so its pieces can merge with the neighbouring
  `{` or space. In T2/T4 the canvas also starts at a fresh token boundary. Slicing would misalign.
- **Raw text rather than a parsed and re-serialised call.** T-0081 tier 2 measured raw drafts, invalid ones included (53/53 repaired, no
  anchoring, p 1.0). Requiring a parse, or canonicalising, would be a new, unmeasured host repair, and it would leave the seed off for exactly
  the cases where `cd_on_invalid:…+seed` sends a pass 2.
- **No seed** exactly when the case goes through the name picker (K-D2: `draft_name` is None, which includes the native `<|tool_call>` tag).
  There is then no draft call for the picked tool's grammar. Neither of the two picker requests is seeded. A routed case with a valid
  `draft_name` is always seeded.

## Acceptance criteria
1. **Arm and cell (T-0080c criterion 2).** `twopass` accepts the arm `perstep_mar+seed` in a cell `<T1|T2|T4>/named/perstep_mar+seed`.
   - `*/union/perstep_mar+seed` raises `ValueError` before any socket.
   - Its CD keys are exactly `perstep_mar`'s for the same automaton, tag and frozen knobs, plus `astra_cd_draft`, `astra_cd_draft_noise` = 0.0
     and `astra_cd_draft_start_step` = 24, all produced through `contracts.cd.CdRequest(...).to_xargs()` so the validators run.
   - Knobs come from `calibration.load_frozen(<perstep_mar file>, task="bfcl", arm="perstep_mar")`. A calibration entry keyed
     `perstep_mar+seed` is refused with `ValueError` before any socket.
   - Noise 0.0 and start step 24 are module constants citing T-0081 tier 2 (dad1382, `mar_n0_s24`), recorded in the regime line, not
     overridable from the CLI.
2. **Seed alignment.** A pure function `twopass.seed_ids(thought, pass1_ids, draft_call_text, canvas_length)` returns the seed exactly as
   specified for T1, T2 and T4: H, T, S, the cut at CL, and the T1 fallback to the empty-thought header.
   - **Alignment proof:** pass-1 ids/text whose draft is a schema-valid call (each of the 5 v1 tools) and ends on a stop id give a seed that
     `replay.accepts(compile_toolcall(scope=<tool>, thought=<thought>), seed)` accepts, for every thought.
3. **No-seed fallback.**
   - A case routed through the name picker (`draft_name` None) sends no `astra_cd_draft*` key in either request; its pass-2 row records
     `seed: null` with `seed_reason: "picker"`.
   - Every seeded request's row records `seed_ids`, `seed_len`, `seed_source` (`t1_thought`, `t1_empty_header`, `t2_header` or `t4_call`),
     `seed_noise` and `seed_start_step`.
4. **No host repair (negative).** A draft that parses but is out of schema (a coordinate of 1500, an unknown argument) is sent as `encode` of
   its raw text. A truncated draft (no stop) is sent without S. The driver never edits, clamps, re-orders or completes the draft.
5. **Step accounting (T-0081 criteria 4–5; fixes `executed_steps`).** `executed_steps(steps, k0)` returns `[steps[0] − k0, steps[1], …]`;
   only the first canvas is seeded. k0 = 0 unseeded, 24 seeded, and that value feeds the row's `steps` and `steps_per_request`.
6. **New stops (T-0080b criterion 4 pattern; exit 1, `stopped` in the trailer, report written).**
   - **(a)** a seeded request whose canvas-0 record has `steps ≤ k0` stops as `seed_accounting`;
   - **(b)** a seeded request whose record carries a `draft_*` refusal reason, or `missing_key`, stops (never a row error);
   - **(c)** a seed the host contract refuses (`ValidationError`) stops as `seed_invalid`; it is never sent unseeded.
7. **Stage 2 arm set.** `cd_toolcall.stage2_cells(selection, commit)` returns the chosen (thought, named) under `end_projection`,
   `perstep_mar`, `perstep_mar_qargmax` and `perstep_mar+seed`, in that order; pass-2 order follows R-W `williams_orders(4)`. Stage-1 cells
   and `select("stage1")` candidates are unchanged.
8. **Selection unchanged (negative; T-0080c criterion 3 as confirmed at H-T80).** `select("stage2")` handles `cd_always:…+seed` and
   `cd_on_invalid:…+seed` with the existing code; in the last tie-break the seed arm ranks after `perstep_mar_qargmax` through the existing
   unlisted-arm fallback. No tolerance, ordering or `_STAGE1` pattern changes.
9. **Report.** For each seed cell, `report()`/`render_markdown` show seed coverage (seeded / routed, no-seed counts by reason) and the copy
   rate (committed ids equal `seed_ids` up to and including the seed's first stop id, T-0081 `is_copy` semantics), split by draft
   schema-validity, from artifacts only. The McNemar family grows with the extra cell (Bonferroni over the report's own family).
10. **Negative (bit-identity and scope).**
    - For every non-seed cell, pass-1 and pass-2 request bodies, sent keys, request count and artifact rows (apart from fields this task adds)
      are identical to before this task on the same scripted scenario. T1/T2 bodies still equal pass 1's except `vllm_xargs` and `max_tokens`.
    - Unchanged: `local_astra/eval/cd/{runner,arms,calibration,cuts,hardstop,replay,records}.py`, `local_astra/contracts/**`,
      `local_astra/decoding/**`, `local_astra/toolcall/**`, `plugin/**`, `scripts/locked/t0080_toolcall.sh`, `local_astra/bench/thresholds.py`.
    - No request leaves loopback.

## Ruling R2 (human, 2026-10-09): trim trailing whitespace from the draft call text
Following the review's spec note: no thought's grammar accepts whitespace between the end of the call and the stop, so a raw seed ending
in `"}\n"` can never be copied. The human chose to trim it. This amends the design decision and criteria 2 and 4:
- `seed(thought) = (H(thought) + encode(T(thought) + draft_call_text.rstrip()) + S)[:CL]`. Only trailing whitespace (Python `str.rstrip()`
  with no argument) is removed. Leading and inner text and every character of the call stay as written. Invalid drafts are still sent
  unrepaired (criterion 4 otherwise unchanged), and a truncated draft is trimmed the same way and still gets no S.
- Each seeded row records `seed_trimmed`, the number of characters removed (0 when nothing was trimmed).
- The report's seed block gives the share of seeded rows with `seed_trimmed > 0` (key `trimmed`, a rate with `k`/`n`), and the markdown
  shows it on a line naming the cell.
- Alignment proof (criterion 2) is extended: a schema-valid draft ending in `"\n"`, `" \n"` or `"\n\n"` before the stop gives a seed the
  grammar accepts, for every thought, and its untrimmed version is rejected (the control).
This departs from what T-0081 tier 2 measured only by the trimmed whitespace; T-0080c reads `trimmed` beside the copy rate.
- 2026-10-09, implementer (R2, R1; on 32bdf2e): `seed_ids` encodes `draft_call_text.rstrip()` (trailing whitespace only;
  leading/inner text, invalid drafts and truncated drafts otherwise unchanged; S unchanged). Seeded rows add
  `seed_trimmed` = `len(draft) - len(draft.rstrip())`. `report()["seed"][<cell>]["trimmed"]` = seeded rows with
  `seed_trimmed > 0` over seeded rows (a `_rate`); `render_markdown` adds a "seed trim <cell>" line. R1
  (`no_seed["missing"]`) was already implemented at 5e12879; no change.
