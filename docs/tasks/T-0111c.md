## Goal

Add `local_astra/computer/`, a `ToolExecutor` with `mode = "live"`. It performs the v1 calls on a real browser page:
- `click_at`, `type_at` (with `press_enter`), `scroll` and `press_key` are executed;
- `google_search` gets the dry-run description, so the session's search path is unchanged.

The browser is sandboxed:
- it is Playwright's pinned Chromium, in its own ephemeral context, never the user's profile;
- it can reach loopback origins only;
- downloads, file uploads, permissions and dialogs are all closed.

The executor also produces the frames the model must see. These are viewport screenshots, returned as `Frame(source=WINDOW)`. It refuses any coordinate whose frame it did not produce, and it never reports `executed` for an action that raised.

Nothing is wired in yet. Config still refuses `live` (`config.py:13-23`), `cli.build_session` still builds `DryRunToolExecutor` (`cli.py:1003-1007`), and no session behaviour changes.

Why the Playwright screenshot and not the HUD capture:
- `click_at`/`type_at` map 0–999 against `inv.frame` (`tool_executor.py:13`, `:364`), which is the newest image in the prompt (`session.py:2546-2555`).
- Today that image is the HUD tab capture (`perception/browser_source.py:1`). A coordinate read off it would land in the wrong place in the browser.
- 1280×800 at device scale factor 1 fits `screen_max` unscaled (`perception/policy.py:19-21`), and Playwright mouse coordinates are CSS pixels.

## Acceptance criteria

**Definitions.**
- **Viewport:** the page's CSS size. The default is 1280×800 at DSF 1 (H-T111c-3).
- **Own frame:** a `Frame` returned by the executor's frame method in the current browser generation. A generation ends when the browser restarts.
- **Fixture pages:** served from `tests/fixtures/browser/` by a loopback `http.server` on 127.0.0.1. Each page records the events it receives (`pointerdown/up`, `click`, `dblclick`, `contextmenu`, `keydown` with key, code and modifiers, `input`, `submit`, `scroll`) in `window.__log`.

1. **Protocol.** `isinstance(BrowserToolExecutor(...), ToolExecutor)`, `mode == "live"`, and `execute(inv)` returns a `ToolOutcome`. Statuses:
   - `executed`: dispatched without an exception;
   - `failed`: an exception after dispatch began, or the browser died;
   - `refused`: nothing was dispatched;
   - `dry_run`: only for `google_search`, described exactly as `DryRunToolExecutor` does (the outcomes compare equal field by field).
2. **Frames.**
   - `source == Source.WINDOW`.
   - `width`/`height` are the screenshot's decoded pixel size.
   - `jpeg` decodes.
   - `phash` is 16 lowercase hex characters, deterministic for identical pixels.
   - `ts_ms` comes from an injected clock.
   - At the default viewport the screenshot equals the viewport and `screen_max` leaves it unscaled.
3. **Coordinate mapping.**
   - For `click_at`/`type_at`, the target is `(to_pixels(x, viewport_w), to_pixels(y, viewport_h))` in CSS pixels, using `tool_executor.to_pixels` unchanged.
   - `resolved` carries `x_px`/`y_px`.
   - On a fixture grid, `(0,0)`, `(999,999)` and `(500,500)` reach `(0,0)`, `(W-1,H-1)` and `(to_pixels(500,W), to_pixels(500,H))`.
   - With a 1600×1000 viewport, whose frame is downscaled, `(999,999)` still reaches `(1599,999)`.
4. **Frame identity: refusals that dispatch nothing** (the fixture `__log` is unchanged). A coordinate call is refused when:
   - `inv.frame` is `None`: `no frame`;
   - its phash is not an own frame's: `frame not from this browser`;
   - its frame is from an earlier generation: `frame from before a browser restart`;
   - its coordinates are bad: `bad coordinates`;
   - its arguments are ill-typed: `bad arguments`.

   A HUD-shaped `FrameGeometry(source=SCREEN)` of identical size with an invented phash is the adversarial row.
5. **`click_at`.** Exactly one primary `pointerdown`/`pointerup`/`click` reaches the element at the target. No `dblclick` and no `contextmenu`.
6. **`type_at`.**
   - It clicks the target, then types into the focused element.
   - The input's value ends with `text`. The field is not cleared by default (H-T111c-6).
   - With `press_enter=true`, `submit` fires exactly once.
   - With `press_enter=false`, there is no `submit` and no Enter `keydown`.
   - Text containing a control character (U+0000–U+001F or U+007F, including `\n` and `\r`) is refused as `bad arguments: control character`. Nothing is clicked or typed: Playwright's `keyboard.type` would turn `\n` into Enter.
   - Non-ASCII text (`café 東京`) arrives exactly.
7. **`scroll`.**
   - On a page three viewports tall, `down` from the top raises `scrollY` by at least `viewport_h // 2` and at most `viewport_h` once settled.
   - `up` reduces it.
   - `left`/`right` work likewise on a wide page.
   - The post-action frame differs from the pre-action frame.
8. **`press_key`.** Every enum value of `tools_v1.json` `press_key.combo` is either:
   - executed, with the expected `keydown` (key plus `ctrlKey`/`altKey`) and the effect the test-author established in the pinned Chromium (for example, Ctrl+A selects a textarea's contents); or
   - refused as `not available in the browser`, dispatching nothing.

   `Alt+Tab`, `Ctrl+T`, `Ctrl+W` and `Ctrl+L` are refused (H-T111c-7). No combo is reported `executed` with no visible effect.
9. **Post-action frame.**
   - After every `executed` action, `resolved["frame_after"]` is the phash of an own frame taken after the action settled.
   - On a fixture where a click turns a 400×400 block from red to blue, that frame's JPEG shows blue at the block's centre (each channel within ±40).
   - The action text names what was done in pixels and never contains a URL path or query.
10. **Honest failure.**
    - An action reports `failed`, never `executed`, with a reason naming the exception type, when:
      - the page closes during the action;
      - the browser is killed during the action;
      - an injected driver raises mid-action (unit).
    - After a kill, the next `execute` relaunches once, does not perform its action, and returns `failed: browser restarted`.
    - Frames from before the restart are refused.
    - Nothing is retried automatically.
11. **Cancellation (barge-in).**
    - If `execute` is cancelled while typing 2,000 characters, `CancelledError` propagates and no keystroke arrives after the cancel returns: the `input` count stays stable for 500 ms.
    - No button or modifier stays down: a following `press_key("Tab")` shows all modifiers false, and a `pointermove` shows `buttons == 0`.
    - The same holds for a cancel between a click's pointerdown and pointerup (unit, fake driver).
12. **Guard hook (optional).** The constructor accepts `guard: Callable[[ToolInvocation], str | None] | None = None`, consulted before every action except `google_search`.
    - A string means `refused` with that reason, and nothing is dispatched.
    - The guard is called exactly once per `execute`, with the invocation unchanged.
    - The executor imports nothing from `conductor/` and decides nothing about confirmation.
13. **Sandbox: profile and files.**
    - Playwright's own Chromium runs: the executable is under Playwright's browser cache, never `/usr/bin/google-chrome`.
    - The context is ephemeral (no persistent `user_data_dir`).
    - A `user_data_dir` resolving inside `~/.config/google-chrome`, `~/.config/chromium` or `~/.mozilla` is refused at construction.
    - A fixture download produces no file and is reported in `resolved["blocked"]`.
    - An `<input type=file>` opens no chooser, and `files.length == 0`.
    - `alert`/`confirm`/`prompt`/`beforeunload` dialogs are dismissed and reported.
    - Geolocation, notifications, camera and microphone are denied.
14. **Egress fence (loopback only).**
    - A fixture page tries the following against `198.51.100.7` and `example.invalid`: an `<img>`, a `fetch`, `sendBeacon`, an `<iframe>`, a `WebSocket`, a service-worker registration, and a top-level navigation.
    - Every attempt fails, and each is logged as `{host, scheme}` with no path or query.
    - DNS-prefetch and preconnect hints reach nothing outside loopback.
    - Loopback fixture requests succeed.
15. **Popups.** A `target=_blank` page becomes the active page, and the next own frame shows it. At most 4 pages stay open; the oldest is closed and reported.
16. **Import hygiene.**
    - Only `local_astra/computer/runtime.py` imports `playwright` (AST scan).
    - Importing `local_astra.conductor.session`, `local_astra.cli` or `local_astra.computer.executor` succeeds with `playwright` blocked.
    - The package imports no socket client.
17. **Negative.**
    - These are byte-identical to BASE (blob hashes over the merge range): `local_astra/conductor/**`, `config.py`, `cli.py`, `contracts/**`, `toolcall/**` (so the tools sha is unchanged), `tests/fakes/**` and `services/versions.lock`.
    - `tools = "live"` is still refused with BASE's message.
    - The fast suite gains only the unit modules, and `make fast-parallel` stays under 60 s.

## Implementation notes

- **Driver seam.** Keep Playwright behind one narrow driver interface in `runtime.py`, using the async API with mypy strict.
- **Viewport and screenshots.** Use the viewport CSS size, pin `device_scale_factor=1`, and screenshot the viewport only.
- **cua lessons** (`<cua-diffusion-gemma clone>`, commit `1690dc5`, `outputs/notes/FAILURE_MODES.md` §2.2, #8, §0.2):
  - every drag died with an exception that was logged as success;
  - 61 % of writes relied on focus surviving an earlier step, which is why `type_at` clicks first;
  - `carl\enter` was typed literally;
  - pixel hashes flip on cursor moves, so don't use phash equality as "the screen changed".
- **Settling.** Settle deterministically: wait for `domcontentloaded` when a navigation started, then two animation frames, both bounded. The executor's own timeout stays well under `TOOL_EXEC_TIMEOUT_MS = 10_000`. Turn off smooth scrolling.
- **Egress must hold browser-wide.** Combine all of these:
  - non-loopback host resolution fails;
  - the route allowlist;
  - `service_workers="block"`;
  - background networking switched off.
  - Log the host only.
- **Chromium sandbox.** Playwright launches Chromium with its sandbox off by default. Don't change that silently; record it (H-T111c-S).
- **Clocks.** No clocks in logic; inject `now_ms`.
- **No heredocs.**
