## Goal
Per-step CD costs 32 / 51 / 205 / 1515 ms per call at buckets 64 / 128 / 256 / 512 against a stock step of ≈ 18.5 ms
(`logs/t0071a-microbench-9a386ee`): three dense B³ log-semiring trees (pass 1, compensated pass 2, max-plus MAP), paid on the
padded bucket rather than |S| and bandwidth-bound because `log_matmul` materialises [g, r, m, c] chunks; plus vocabulary-bound
[L, V] passes (H(q) 8.7 ms at every bucket). Cut both without changing any numerical contract and without touching B13's
thresholds. Triton 3.7.1 is in the pinned image (checked 2026-10-03; `ptxas-blackwell` present).

## Implementation notes
- `@triton.jit` modules are pure Python and ship in the wheel (`--no-deps --no-index`); no C++/CUDA extension; triton imported
  lazily inside `cd/kernels`.
- Numerics landmines (T-0073 note 3): use libdevice `exp`/`log` (not `tl.exp`/`tl.log`'s approximate ex2/lg2); ptxas contracts
  mul+add into FMA — b's `q·log q` term must be rounded on its own (explicit rn multiply) for bit-identity; in c, `_finish`'s
  `s·e^{−ls} − 1` may contract (allowed under N4).
- No host sync: grids from Python ints of shapes. Launch-bound at bucket 64 (≈ 5.7 µs per torch launch); Triton's launcher
  costs more per launch, so a kernel must replace several torch launches — criterion 3's A/B decides dispatch.
- JIT compiles on first use per specialisation; `constexpr` block sizes; the existing warm-ups absorb compiles.
- Live-state slicing assumes live states `0..n_states−1` with padding at the tail (`build_tables`: `flat = src·bucket + dst`);
  assert on the host when tables are built.
- Mosaic: taken — batched levels with odd carry, the settling arm (T-0076); rejected under N6 — `matmul_loga_logb`'s separate
  shifts and cuBLAS under TF32 (lose the pairwise anchor's two-band entries).
- **Deferred (own tasks after re-measuring):** sharing dyadic nodes across `L_eff` candidates (`steps.py`; count candidates per
  call first); exact Viterbi MAP O(L·E) (needs a near-tie ruling, not N3); CUDA graphs; sparse levels 0–1; fusing
  `class_max`/`class_mass`/draw/`_token_marginals`.
