## Goal

In a live session in web mode, the live guidance gains two sentences:
- **(S_SHARED)** When the screen Gearvis sees is the user's shared screen, Gearvis still has its own browser and does web tasks there, starting with Ctrl+L. It does not answer that it cannot act or ask the user to go to a store.
- **(S_SOURCE)** Before answering with a fix or a fact found through `google_search`, Gearvis opens the page that states it, reads it there, and names that page in its answer.

These sentences ship as **v4**: v3's text followed by `" " + S_SHARED + " " + S_SOURCE`.
- It is selectable with `--live-guidance v4` or `live_guidance = "v4"`.
- Under `--no-web` it carries v2's bytes (both sentences rely on Ctrl+L and on opening result pages, which `--no-web` refuses), exactly as v3 does.
- v1, v2 and v3 stay byte-identical and selectable.
- The default stays v3 until group D flips it after group C's GPU A/B passes.

Group A makes the T-0208 handoff harness's one-source probe correct, so the A/B is not void again.

## The exact v4 text (delta on v3)

```
LIVE_TOOL_GUIDANCE_V4 = LIVE_TOOL_GUIDANCE_V3 + " " + S_SHARED + " " + S_SOURCE
```

**S_SHARED (213 characters):**
`A shared screen shows what the user means, but you act only in your own browser, which is always available: to do a web task from a shared screen, press Ctrl+L to open your browser's start page and continue there.`

**S_SOURCE (151 characters):**
`Before you answer with a fix or a fact you found through google_search, open the page that states it, read it there, and name that page in your answer.`

v4 is 997 characters; v3 is 631. The two sentences add about 80 tokens to every live request in web mode.

**Why each clause is there:**

| Clause | Evidence (T-0208 C shared arm, unless noted) |
|---|---|
| "A shared screen shows what the user means" | The model did read the item off the picture: `identity_spoken` 7/9. It needs to read the picture as the task, not as the place to act. |
| "but you act only in your own browser" | Matches `SHARED_LABEL_SCREEN`'s "not your browser; click_at and type_at cannot act on it". It turns that refusal into a direction. |
| "which is always available" | Counters "I cannot add it to a cart without access to a browser" and "I cannot interact with the user's screen". |
| "press Ctrl+L to open your browser's start page" | The model does not know where its browser is: the shared image hides it. Ctrl+L is the one action that is valid from any page in web mode, and any executed browser action switches the step image to the browser (T-0177 follow-the-action; premise row B6). It reuses v3's taught, measured path (T-0191 smoke: N1 5/5, N2 4/5). |
| "and continue there" | Counters "Please navigate to a store where you would like me to help you". |
| "Before you answer with a fix or a fact you found through google_search" | Scopes the rule to web-search answers only. Routine browser tasks (cart, forms, reading the page in front of it) are untouched, per the constraint. |
| "open the page that states it, read it there" | T-0209 B: 5/6 answers came from snippets with `visited == ['web']`. The rtx index's snippets deliberately omit the settings path and carry the forum's wrong top answer, so reading the page is what gets the setting and avoids the trap. |
| "and name that page in your answer" | The judge's source clause (iii) and the ruling ("saying the source"). It asks for a citation in the final answer, not narration (speaking policy: speak at the end). |

Both sentences ask for no confirmation and no per-step narration, and gate nothing on a spoken prefix (docs/01 D16). Thinking stays on. The text is one fixed literal, chosen once at session construction, so the cached system prefix is the same bytes in every request.

  - `visited ∩ R1_SOURCE_PAGES ≠ ∅`;

## Implementation notes

- **Choose once.** The v4 text is chosen once at session construction from the same `web_of(...)` that builds the browser, never per request. The system message is the cached prefix and `<|think|>` stays first. Do not toggle anything per request.
- **No-web fallback.** v4 under `--no-web` resolves to `LIVE_GUIDANCE["v2"]` itself (B4 asserts `is`), and the wait sentence is appended by `_tool_guidance` as today.
- **Text is fixed.** The sentences are fixed by this task. Changing a word is a spec change: return to the planner. Do not edit tests to fit wording.
- **Speaking policy.** S_SOURCE's citation is in the final answer, so it is speaking at the end. Nothing adds per-step narration or a spoken-prefix gate (D16). Clips are untouched.
- **Separate seams.** The A/B harness passes guidance through the existing Session keyword. It never edits T-0205's or T-0209's runners. T-0208's runner gets only A4's seam. The loopback search indexes are not network exceptions; the CLAUDE.md search rule is untouched.
- **Prefix cache in the A/B.** A fresh Session per turn with alternating guidance means every turn's first request misses the prefix cache in both arms equally; D-2 compares interleaved turns.
- **Hook rules.** The implementer never edits `tests/`. No heredocs into the repo. Never export `GIT_DIR`/`GIT_WORK_TREE`. The GPU run goes through `/launch` on a clean tree.
- **Premise checks.** If B6 is red at BASE, stop. If the session log does not carry the system text needed by B7, stop and report: the replay then needs another source.
