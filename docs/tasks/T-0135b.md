## Goal

The T-0135 locked A/B at e1ae76e measured, per arm (n = 100):

| Arm | Recovery | Success (Wilson 95 %) | S3 | Over-clicks | False claims | Silent call in thought | Recoveries |
|---|---|---|---|---|---|---|---|
| A | off | 66/100 [0.56, 0.75] | 16/20 | 3/60 | 27 | 4 | 0 |
| B | on | 67/100 [0.57, 0.75] | 20/20 | 4/60 | 27 | 0 | 11 |

Regime: lean, CL 256, 48 steps, thinking on, NVFP4 rev 2ea8372, vLLM 0.29.0, `vllm.sh` 806da12, tools native bbfc53ccdd80, live, repair on, loop 8, 1120 visual tokens, ReGround off, echo in model units and the "screen now" label (the T-0134c default), headless Chromium 1280×800, 5 tasks × 20 per arm, order seed 0, concurrency 1, engine unseeded, STT down.

The label was `inconclusive`. Arm B was ineligible after one answer-channel collapse (S2#5, now T-0142b's). Every H-T135-1 clause held otherwise. The human ruled on 2026-10-23 (James) that recovery becomes the live default.

This task moves that default into `cli`, the only place defaults live (T-0132 R-f):
- a resolver with a source;
- a startup line;
- a flag and a profile key to turn it off;
- `off` and `dry_run` unchanged.

It also fixes the T-0135 eval defect that made `tests/eval/test_t0135_ab.py` exit 1 on the real run. `test_arm_setting_reached_every_turn` asserts the turn-line key `recover_thought_calls_logged` on every trial that scanned requests. A turn that hit the turn timeout writes no turn line, so B S2#5 (`timed_out: true`, `session_id: null`) has `None`. T-0135 A8 requires the key on "every live turn line", and that trial has none. The eval exceeded the spec, and the eval is what changes.

## Acceptance criteria

**A1. Constant and profile key (`config.py`).**
- Add `LIVE_DEFAULT_THOUGHT_CALL_RECOVERY: bool = True`.
- `Profile` gains `thought_call_recovery: bool | None = None`. Every other field, type and default equals BASE.
- **Load refusals:**
  - a non-bool value gives a `ValueError` naming `true`/`false`;
  - a non-`None` value with `tools != "live"` gives a `ValueError` naming `live` (the T-0134c A1 pattern).
- `config` imports nothing from `conductor` or `computer`.

**A2. Resolution (`cli.recovery_of(profile, args, mode) -> Recovery`).** `Recovery` is a frozen dataclass with:
- `thought_call_recovery: bool | None`;
- `thought_call_recovery_from: GroundingSource`;
- `session_value() -> bool | None`.

Rules:
- In the resolved mode `live`: the flag, else the profile key, else the constant with source `"default"`.
- In `off` and `dry_run`: `(None, "unset")`.
- `session_value()` returns the bool in live and `None` elsewhere.
- Pure: it opens nothing, imports no `local_astra.computer` module, and reads `args` with `getattr`, so `Namespace()` resolves the default.

**A3. Flag.**
- `--thought-call-recovery {on,off}`. An unknown value exits 2 through argparse.
- The flag in a resolved mode other than `live` exits 2 with a message naming `live`, builds no graph and starts no page server. This holds with `--dry-run` and without.
- The same refusal applies to the profile key when `--tools off|dry-run` overrides a live profile (the T-0134c orchestrator ruling).

**A4. What is built.**
- `_build_graph` passes `recover_thought_calls=<recovery.session_value()>` to `Session` in live. That is `True` by default and `False` with `off`.
- In `off`/`dry_run` it passes no `recover_thought_calls` keyword. `Session` refuses `True` outside live (T-0135 A4), so this must never reach it.
- By default, a cli-built live session whose step ends with only an open thought tailed by a valid tagged call executes that call, and its `tool.call` records carry `from_thought: true` (T-0135 A5–A6).

**A5. Saying it.**
- **(a)** In live, a new line is printed immediately after the T-0134c `feedback` line, under `--dry-run` and at a real start. With defaults it reads exactly:
  `astra session: recovery: thought_call_recovery=on (default)`.
  With `--thought-call-recovery off` it reads `...=off (flag)`, and with the profile key the source is `(profile)`. Nothing is printed in `off`/`dry_run`.
- **(b)** The `grounding` line, the `feedback` line, the `--dry-run` tools line and `cli.tools_line(...)` are BASE's strings, byte for byte.
- **(c)** Every live turn line now carries T-0135 A8's `recover_thought_calls: <bool>` by default. No `*_from` key is added (T-0134c R-k).

**A6. `--thought-call-recovery off` is arm A.**
- In live, compared with BASE's default live session for the same other flags, the request bodies, session-log records and executor action strings are byte-identical.
- The turn lines differ only by the added `recover_thought_calls: false`.

**A7. Eval correction (`tests/eval/test_t0135_ab.py`, one row).**
- `test_arm_setting_reached_every_turn` still asserts the manifest-level `recover_thought_calls` for every trial that scanned requests.
- It exempts only the `recover_thought_calls_logged` assertion for a trial that has `timed_out` true or `session_id` `None`, i.e. one that wrote no turn line.
- Over `logs/t0135-thought-call-ab-e1ae76e/` the module's rows all pass, run as T-0135 O-1 prescribes. Exactly one trial is exempted, B S2#5, and the row asserts that count. No other row of the module changes.

**A8. Docs.**
- `docs/02-architecture.md` §5 gains exactly one paragraph starting `**Spec delta (T-0135b`. It states:
  - the human ruling;
  - the constant and the A2 resolution;
  - the flag and the key, and the refusal outside live;

  - that `off` passes `False`, so the turn line records the state;
  - the A/B numbers above.
- T-0135's and T-0134c's paragraphs stay verbatim.

**A9. Negative.**
- For the same flags and profile, these are byte-identical to BASE in `off` and `dry_run`: the printed `--dry-run` output, the built clients, the session keywords and the request bodies.
- `cli.grounding_of`, `cli.feedback_of` and their lines are unchanged for every input.
- `Session`'s own default stays `recover_thought_calls=None`. The T-0135 A/B harness, which sets the arms explicitly, and `test_t0135_differential.py` stay green unedited.
