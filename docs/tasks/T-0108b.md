## Goal

Under the live prompt (A0), almost no flight card is complete:
- the T-0108a run (`e6c3a81`): 1/40 and 0/40;
- the T-0103 run (`6720e56`): 0/40 and 0/40.

The gate prunes components that hold everything they need, but in the wrong shape:
- TextField `placeholder` instead of `label`;
- DateTimeInput with no `value`;
- ChoicePicker with string options and no `value`;
- inline child objects in a List;
- under K1/K2, Buttons whose single Text sits under `children`.

After this task, a new pure module rewrites a schema-invalid component into a valid one. It may rename a key to the catalog property of that kind, wrap or unwrap, lift an inline child to top level, or add the content-free `""` or `[]`. It does so only when every string value in the result is the model's own.

The repair is all-or-nothing per component. If the result does not validate, the component goes on as today, to salvage or pruning. Components that already validate stay byte-identical.

The task also fixes a gate defect on main. A re-started fence cut mid-component overwrites the as-written copy of an accepted component with a stub, so the next full canvas loses its surface.
