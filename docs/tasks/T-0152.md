## Goal

The T-0151 locked A/B at 4471255 measured, per arm (n = 100):

| Arm | Overview frame | S4 | S5 | Success (Wilson 95 %) | Non-S4 false claims | Over-clicks |
|---|---|---|---|---|---|---|
| A | off (then the default) | 0/20 | 15/20 | 72/100 [0.63, 0.80] | 3/80 | 1/60 |
| B | on | 20/20 | 19/20 | 94/100 [0.88, 0.97] | 4/80 | 4/60 |

The regime is in `docs/cd/overview-frame-ab.md` and repeated under Regime below.
- The approved rule said `no change`, only because of the over-click guard. All five over-clicks were on S1/S2. Those tasks never get the frame (`fits` on all 60 arm-B S1–S3 turns), and their step-1 requests are byte-identical between the arms.
- **Human ruling (James, 2026-10-24):** adopt `--overview-frame` as the live default, overriding the over-click guard.

This task moves that default into `cli`, the only place defaults live (T-0132 R-f):
- `config.LIVE_DEFAULT_OVERVIEW_FRAME = True`;
- `--no-overview-frame` (or `overview_frame = false`) turns it off;
- the startup line says `on (default)`.

The frame cannot be on together with the auto overview, the page overview or ReGround (T-0151 A2-1/A2-9). So a default that is on must give way when the user asks for one of those (H-T152-1). Nothing changes in `Session`, the executor, the tools or the prompt. A live session with the frame off is byte-identical to BASE's default live session.

## Implementation notes

- **Copy the T-0135b shape:** the resolver in `cli` with a source, and a separate line. The default lives in `cli`; `Session(overview_frame=False)` and every harness keep their explicit values.
- **Where to resolve the yield:** inside `overview_frame_of`, by calling the other three resolvers. `_build_graph` calls `overview_frame_of` again (cli.py ~1713), so a yield placed in `session_cmd` alone reaches `Session`'s A2-1 `ValueError`.
- **How the result records the yield (superseded by O-1):** `OverviewFrame` keeps exactly its two fields. The cause for the `off (with …)` line comes from a separate pure helper in `cli`, used only for the line. `overview_frame_with_refusal` sees `overview_frame=False` and stays as at BASE.
- **The no-keyword rule is load-bearing:** off passes no keyword. That is what makes A7a byte-identical to BASE, including the turn line, because A2-8 writes the key only when on. Do not pass `False` (unlike T-0134c R-m and T-0135b, where `False` was needed to record state; here the key's presence already records it).
- **Facts only:** no model-facing text changes. `OVERVIEW_FRAME_LABEL`, `LIVE_TOOL_GUIDANCE` and the tools are frozen.
- **Hook rules:** the implementer never edits `tests/`. No heredocs around a blocked Write, and never export `GIT_DIR`/`GIT_WORK_TREE`.
