# T-0110c — the HUD static server's shutdown poll becomes injectable (first serial-suite seam after T-0110b)

**Status:** done 2026-10-18 (merged 2da2c5b); tests at 0a94356; implementation module: `local_astra/hud_static.py` · **Blast radius:** low (one keyword-only constructor parameter on the loopback static server; the production default and the only production call site are unchanged; not the turn machine, audio path, GPU services or hooks) · one reviewer · **Branch:** `T-0110c-hud-static-poll`, from `main` at or after 8b3f6d0 · **Parent:** T-0110 H-T110-3, which the human ruled (a) on 2026-10-18 ("`hud_static` poll interval first"); T-0110b's open serial bar (human: "Merge, keep 280 s open") · **Followed by:** T-0110d (injectable waits for `PipeWireAudioIO` and capture; high blast) and T-0110e (the STT client's quiet windows), each planned separately.

**Protocol cannot be skipped:** it changes a product file (`local_astra/hud_static.py`), although production behaviour stays byte-identical.

**Scope: CPU only.** No GPU, no network beyond loopback, no new socket.

## Goal

`HudStaticServer` runs the stdlib `serve_forever()` at its default 0.5 s poll, so `close()` waits up to 0.5 s for the serving thread to notice `shutdown()`. In the fast suite this costs 13 rows × 0.50 s ≈ **6.5 s**, out of `test_hud_static.py`'s 6.57 s wall time (CPU 0.06 s; planner measurement on main 8b3f6d0, n = 1).

After this task:
- `HudStaticServer` takes a keyword-only `poll_interval`, with a default of 0.5 s (the stdlib's), and forwards it to `serve_forever`.
- `test_hud_static.py` passes a short interval.
- `cli.py` passes nothing, so `astra session` and `astra hud` behave exactly as before.

**Expected saving:** about 6.4 s serial, from 301.3–303.2 s to about 295–297 s.
- **This does not reach T-0110's 280 s bar, which stays open** and carries over to T-0110d and T-0110e.
- CLAUDE.md's 120 s ceiling is unchanged. It cannot be reached through wait seams: in-process CPU alone is 127 s (see the planner measurement below).

## Acceptance criteria

1. **The seam.** The signature is `HudStaticServer(root, port=0, *, poll_interval=0.5)`, and the value is passed to `_Server.serve_forever` as its `poll_interval`. The positional form `HudStaticServer(root, 0, 0.01)` raises `TypeError`.
2. **Production default unchanged (negative).** A server built without `poll_interval` calls `serve_forever` with an effective `poll_interval == 0.5`. The check binds the recorded call against the signature of `socketserver.BaseServer.serve_forever`. So both "passed explicitly as 0.5" and "not passed" satisfy it, and any other value fails.
3. **Production call site unchanged (negative).**
   - `local_astra/cli.py` is byte-identical.
   - Its `HudStaticServer(...)` call has exactly the two positional arguments `hud_static.HUD_DIR, services.hud_port` and no keywords (checked by AST).
   - No other file under `local_astra/` constructs `HudStaticServer`.
4. **Bad values are refused before binding.** A `poll_interval` of `0`, a negative value, `nan` or `inf` raises `ValueError` at construction. Afterwards the requested port is still free.
5. **Fast close.** With `poll_interval=0.01`, 20 sequential cycles of constructing a server and then calling `close()` take < 1.0 s in total.
6. **Existing behaviour pinned (negative).**
   - Every existing row of `tests/unit/test_hud_static.py` keeps its assertions verbatim. Only the `serve()` helper gains `poll_interval=FAST_POLL_S`.
   - The interrupt row still asserts `interrupted`, an unbound port and no live thread.
   - These pass unedited:
     - `test_closing_twice_is_a_no_op`;
     - `tests/unit/test_cli_session.py`;
     - `tests/integration/test_hud_chrome.py`;
     - the zero-non-loopback-sockets row;
     - `test_hud_server_no_egress.py`.
7. **Module speed.** `uv run pytest tests/unit/test_hud_static.py -q -p no:randomly` takes ≤ 1.0 s (was ≈ 6.6 s), all green, n = 3.
8. **Suite bars (verifier, idle box).**
   - Serial `uv run pytest tests/unit tests/contract -q -m "not gpu"`: median of 3 **≤ 297 s**, all green.
   - `make fast-parallel`: median of 3 **≤ 45 s**, all green.
   - The verifier states that the 280 s bar is still open and quotes the top 20 modules from `--durations=0`.
9. **Scope (negative).**
   - The diff touches only owned files.
   - `STOP_HOOK_BUDGET_S`, `SERIAL_CEILING_S` and every threshold in `local_astra/bench/thresholds.py` are unchanged.
   - No `slow`, `skip`, `xfail` or `pending` marker or Hypothesis setting is added or changed.
