# T-0082c — Re-measure tool-call mode with the `</cc>` strip: pass-2 replay on dev (pilot) and test, and the grammar's own value

**Status:** done (2026-10-10; H-T82 decided); H-T82-0 approved by the human on 2026-10-09 (one pass-2-only replay of the test split, amending T-0080c
criterion 7) · **Blast radius:** high (two reviewers per `/launch`; human at H-T82 after) · **Branch:** `T-0082c-replay-launch` from `main`

## Goal
Re-measure the T-0080c test split with the strip. Three questions:
- whether `cd_on_invalid:T1/named/perstep_mar+seed` stays the default;
- how much latency the strip saves;
- what the grammar adds over a stripped draft.

All four T1/named arms run pass 2 on one boot against the original pass-1 drafts, and the choice uses the unchanged pre-registered rule.

## Acceptance criteria
1. **R-dev pilot (dev, n 40 + 8, one boot).**
   - Command: `scripts/locked/t0082_replay.sh --stage dev`.
   - Input: the T-0080c dev artifact (`b0fd71cc…`).
   - Cells: `T1/named/{end_projection, perstep_mar, perstep_mar_qargmax, perstep_mar+seed}`.
   - **Gate:** exit 0, no stop, CS = 1.000 on every constrained terminated row, and every seeded row's `seed_ids` decode without `</cc>`.
   - No selection on dev; the numbers are reported.
2. **R-test (test, n 80 + 12, one boot, once).**
   - Same command, input the T-0080c test artifact (`1c69a9c2…`), same cells.
   - Runs at the same SHA as R-dev and only after R-dev passed.
   - No pass-1 request.
   - A stopped run is not re-run without the human.
3. **Guarantee (T-0080c criterion 4).** Every constrained terminated row has CS = 1.000 by host replay and no loud error. A violation stops
   the run and becomes a failing test first.
4. **Pre-registered selection (T-0080c criterion 3, verbatim).** `twopass.select(rows, "stage2")` runs over `draft_only'`,
   `cd_always:<4 cells>` and `cd_on_invalid:<4 cells>`. The rule, unchanged:
   - **Eligible:** schema 1.000, and CS 1.000 on every constrained row.
   - **Accuracy filter:** exact ≥ best − 0.05 (Fraction).
   - **Choice:** the lowest e2e p50 over tool cases; within 5 %, the lower p90; then fewer steps; then the fixed order (seed arm last, via
     the existing fallback).
   - The result is a **recommendation**. If it differs, the provisional default stays until the human rules at H-T82.
5. **The grammar's own value (reported, not gated).**
   - For each `cd_on_invalid:<cell>` on R-test tool cases:
     - (a) exact on drafts still invalid after the strip, as k / n_inv;
     - (b) McNemar against `draft_only'`. The discordant pairs must all fall on still-invalid drafts, and the reviewer asserts this.
       Bonferroni over the report's family.
   - For each `cd_always:<cell>`, on drafts valid after the strip:
     - (c) draft-right / CD-wrong against the reverse.
   - Plain sentence: "Over the stripped draft, constrained decoding adds k exact calls on n still-invalid drafts (p …)".
6. **Seeds.** For the seed cell, the report shows:
   - coverage;
   - copy rate split by the stripped draft's validity;
   - the R2 trim share;
   - that the share of seeds containing `</cc>` is 0 / seeded, asserted.
7. **Beside the selection, labelled as counterfactual or noise floor:**
   - T-0082a's offline re-score;
   - per unseeded cell, the paired agreement of `exact` between replayed and stored T-0080c pass-2 rows (same prompts, different boot) as a
     noise floor;
   - the pass-2 call rate under `cd_on_invalid'`;
   - the e2e p50/p90 change against the T-0080c table.
8. **Report** `docs/cd/toolcall-v1.1.md`, from artifacts only:
   - every number with its regime;
   - the policy and per-tool tables, with the F3 gap restated;
   - criteria 4–7;
   - route recall and false tags (unchanged by construction);
   - the pre-registration caveat: the strip was designed after seeing the test split, so this is not a held-out confirmation.
9. **Negative.**
   - `thresholds.py` is unchanged.
   - The T-0080c artifacts are byte-unchanged.
   - The test pass 1 is not re-sent, and R-test runs once.
   - BFCL/Sudoku cuts and `docs/cd/toolcall-v1.md` are untouched.
   - The selection rule is unchanged.
