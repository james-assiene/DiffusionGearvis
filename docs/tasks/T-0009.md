# T-0009 — Memory-lite

**Status:** merged 2026-09-13 (re-review MERGE) · **Blast radius:** low · **Depends on:** T-0002

## Goal
`SqliteMemory` (SQLite + FTS5) with the idle captioner contract (docs/01 D8, docs/03 §4 "Memory").

## Acceptance criteria
1. `ingest → search` round trip; FTS5 over `caption` and `window_title`; time filter excludes out-of-range episodes; top-k with recency tie-break.
2. `set_caption` makes an episode findable by any word of its caption; prefix/stem behaviour documented by test (`fraction` finds `fractions` only if the FTS tokenizer says so — assert the actual `unicode61`/`porter` choice).
3. `forget_since` deletes rows *and* thumbnail files and returns the count.
4. All files under the configured directory (default `~/.local/share/local_astra/`); nothing else touched; no sockets.
5. Idle captioner: never runs while a turn is live; aborted on speech onset; one request at a time.

## Owned files
- local_astra/memory/**

## Out of scope
Embeddings, SigLIP, LanceDB (only if a recall eval fails on visual concepts).

## Evidence required
`uv run pytest tests/unit/test_memory_lite.py -q`, fast suite, mypy.

## Rulings after test activation (2026-09-13)

**A1 — captioner API ratified.** `local_astra/memory/captioner.py` exposes
`IdleCaptioner(llm: LlmBackend, memory: MemoryClient)` with `async run_once()` (caption at most
one uncaptioned episode; single-flight) and `async abort()` (idempotent; must call `llm.abort` so
the engine slot is freed, and must discard any result that arrives after the abort). The
"next uncaptioned episode" query is a method on the concrete store, not on the `MemoryClient`
protocol — no contract change.
**A2 — `forget_since(t0_ms)` is inclusive** (rows with `ts_ms >= t0_ms`), matching
`tests/fakes/memory.py`. Time filters on `search` stay as the tests use them (strictly inside /
outside); the boundary is unspecified and not to be relied on.
**A3 — thumbnails**: `ingest` records the path it is given; `forget_since` deletes that file. Copying
into the store directory is not required by this task.
**A4 — recency**: only the equal-score tie-break is specified (newest first); a decay weight for
unequal bm25 scores is a later task with its own eval case. Retention window (7 days) is not in
scope here.

## Rulings after review (2026-09-13, verdict REVISE both — small scope)

**A5 — WAL + `synchronous=NORMAL` + `busy_timeout=250`.** Measured on this box (ext4, commit
ef64a43): `ingest` median 15.1 ms / p95 15.9 ms with the default `journal_mode=delete`,
`synchronous=FULL` — two fsyncs per commit — versus 0.03 ms median under WAL+NORMAL. `ingest` fires
on `scene.changed` inside a live turn, so the default stalls the loop at the 20 ms reflex cap the
docstring cites as the reason no thread hop is needed. Implementer: set the three PRAGMAs in
`__init__`, correct the docstring's claim to the measured numbers with regime, and shorten
`busy_timeout` from sqlite's 5 s default (a second writer must not hold the loop for 5 s; raising
`OperationalError` after 250 ms is the right failure). Test-author: a test that reads the PRAGMAs
back (`journal_mode == "wal"`, `synchronous == 1`) — the value is the policy, so pin it.
**A6 — `abort()` is exception-safe:** cancel the consumer and clear state in a `finally`; a raising
`llm.abort` propagates *after* the local consumer is cancelled. Test-author: a backend whose
`abort` raises must leave the captioner able to `run_once` again.
**Test gaps (test-author):** T1 relevance — two episodes with different bm25 scores, the older and
more relevant wins (score-sign flip must go red); T2 `segment="answer", thought_open=True` never
reaches the store (CLAUDE.md absolute; the guard survives mutation today); T3 the pre-start abort
race — `abort()` during a slow `next_uncaptioned()` issues no request; T4 the PRAGMA read-back (A5)
and the abort-raises case (A6).
**Follow-ups, not this task:** `PRAGMA user_version` schema migration for the long-lived file;
`FakeMemory` lacks `next_uncaptioned` (planner item for the captioner's wiring task); `run_once()`
propagating a backend exception is the executor's to contain (T-0007); `matched` markers in a
caption are cosmetic.

**Merged 2026-09-13 (re-review MERGE; every mutation red; WAL+NORMAL ingest 0.017 ms median vs
15.3 ms at defaults, n=100, ext4/LVM, sqlite 3.53.1).** Follow-up recorded, not this task: under
WAL+NORMAL a lost commit can *resurrect* episodes `forget_since` deleted (thumbnails already
unlinked) — a privacy surface; a `PRAGMA wal_checkpoint(FULL)` after `forget_since` costs ~10.5 ms
measured. Goes with the `PRAGMA user_version` item into the next memory task.
