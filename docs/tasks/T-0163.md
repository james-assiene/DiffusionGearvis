## Goal

In the T-0125 GPU smoke at b372eda, all three keyless engines failed in about 350 ms with "No results found." after the first two searches, which looks like anti-bot behaviour. When James has created `~/.config/diffusion_gearvis/brave_api_key`:
- a live (or `--search ddgs`) session's web search first tries the keyless engines exactly as today;
- only if they all refuse does it ask the Brave Search API at `api.search.brave.com`;
- the key goes only in the `X-Subscription-Token` header.

The key file is used only if it is a regular file the user owns with no group or other permission bits; otherwise the session says why on stderr (never printing the key) and stays keyless. Without the file, everything is byte-identical to today. The two observability fixes from the same smoke need `session.py` (T-0171 holds it now), so they are T-0163b.

## Acceptance criteria

1. **No key file is today, byte for byte (negative).** With no file at the key path: `cli._search_backend("ddgs")` returns a `DdgsSearch` (not a wrapper) and the same label as at 3e4d45b7; stdout, stderr, the session log, `turns.jsonl`, cards and the regime label of a real live start equal BASE's; neither `local_astra.search.brave_api` nor `local_astra.search.fallback` is imported (fresh-interpreter subprocess); `brave_key` may be imported, since the loader must run to find there is no file (amended 2026-10-27 after the test-author's report). Every T-0125 module (`test_cli_search.py`, `test_config_search.py`, `test_session_web_search.py`, `test_t0125_smoke_script.py` except criterion 12's additive rows), `test_ddgs_backend.py` and the existing rows of `test_search_egress_scope.py` pass unedited.
2. **The key file is read only when search is on, at a real start.** Never with search off, `--tools off`, `--dry-run`, or by `load_tool_kit`; in those cases `brave_key` is not imported (subprocess). Read once per process, at construction, never per search.
3. **Key file checks (`local_astra/search/brave_key.py`, stdlib only).**
   - Path `Path.home() / ".config/diffusion_gearvis/brave_api_key"`, computed at call time (a temp `HOME` moves it), or an injected path.
   - Outcomes: absent → "not configured", silent; a symlink → refused (even to a valid 0600 file); not a regular file → refused; owner ≠ effective uid → refused; any of `0o077` set → refused (0640, 0604, 0620, 0606, 0644 refused; 0600 and 0400 accepted); unreadable → refused; malformed → refused (after stripping surrounding whitespace, one token matching `^[A-Za-z0-9_-]{16,128}$`; at most 4 KiB read; empty, multi-line, too long, non-ASCII refused).
   - Every check is on what was actually opened (no follow, then `fstat` on the descriptor).
   - A refusal is a closed reason code (`symlink`, `not_a_file`, `owner`, `mode`, `unreadable`, `malformed`) plus a message that may name the path, the octal mode and the uids, never any byte of the content.
4. **The key is never shown.** A canary key never appears in stdout, stderr, the session log, `turns.jsonl`, HUD messages, any exception's `str`/`repr`/`args`, `repr()` of the loader result or the backends, or `caplog` at DEBUG (httpx and httpcore included). Logs say only `configured` or `not configured`. Fixtures hold only generated canaries.
5. **Egress (`local_astra/search/brave_api.py`).** Every request: scheme `https`, host `api.search.brave.com` (the module's `ALLOWED_HOSTS`, exactly that host), port 443, the fixed web-search path; built from constants, no `://` literal in the module; through `httpx` with redirects off, `trust_env=False`, no proxy; the key exactly once, in `X-Subscription-Token`, no `Authorization`, no `Cookie`; only the parameters `q` (cut to 500 chars), `count=5`, `safesearch=moderate`, plain-text snippets and web results only (the implementer confirms parameter names against Brave's API documentation). A 3xx is never followed (no second request; `SearchFailed("error")`). A proxy variable (T-0111b's `PROXY_ENV`) is refused at construction (`ValueError`). A body over 2 MiB is refused unparsed.
6. **Outcome table** (Brave → the `SearchBackend` convention, consumed unchanged by T-0125 criterion 4):

   | Brave outcome | raised / returned | detail (closed set, never the body or the key) |
   |---|---|---|
   | 200, valid JSON | `SearchResults` (0..5, rank order) | — |
   | 429 | `SearchFailed("rate_limited")` | `HTTP 429` |
   | 401 / 403 | `SearchFailed("error")` | `HTTP <code> (key refused)` |
   | other 4xx / 5xx | `SearchFailed("error")` | `HTTP <code>` |
   | 3xx | `SearchFailed("error")` | `redirect refused (HTTP <code>)` |
   | body > 2 MiB, bad JSON, wrong shape | `SearchFailed("error")` | `malformed response` |
   | httpx timeout | `TimeoutError` | — |
   | other httpx transport error | `SearchFailed("network")` | exception type name |
   | after `aclose` | `SearchFailed("closed")` | — |
   | cancelled | `asyncio.CancelledError` propagates | — |

   Result mapping: title → `title`, url → `url`, description → `snippet`, whitespace collapsed, HTML tags stripped, entities unescaped; rows lacking a title or url, or with a non-http(s) url, are dropped; cuts at most the T-0111b bounds (title 200, url 500, snippet 600, 5 results), so T-0125's 62-char untrusted note still renders uncut.
7. **Fallback (`local_astra/search/fallback.py`; H-T163-1 at its recommended order).** It wraps a primary and a fallback `SearchBackend`, names neither concretely, and satisfies `SearchBackend`. The fallback is called **only** when the primary raises `SearchFailed` of kind `error` or `rate_limited`; **not** when the primary returns results (zero included) or raises `TimeoutError`, `SearchFailed("network"|"closed")`, `ValueError` or `CancelledError`. The fallback's outcome is final. `last_engine` is the primary's on a primary success, `"brave_api"` on a fallback success, `None` otherwise and while a search runs (it matches T-0125's `^[a-z][a-z0-9_]{0,23}$`). `aclose` closes both, even if one raises. Cancelling during the primary never reaches the fallback.
8. **Wiring (`cli.py` only).** `_search_backend("ddgs")` is still the only constructor. With a valid key it returns `FallbackSearch(DdgsSearch(), BraveApiSearch(key))`; the label gains `; then the Brave Search API (key configured)`; the session log gets one note `{what: "web search fallback", brave_api: "configured"}`. Unchanged: the `--search` choices (H-T163-4), `Profile.search`, `ToolKit.web_search`, `WebSearch`, the `search:` stdout line, the regime label and `turns.jsonl`.

## Implementation notes

- **API surface the tests assume** (test-author, 2026-10-27): `brave_key.default_key_path()` and `load_key(path=None)` returning an object with `.status` ("configured"/"not configured"), `.reason` (None or a code), `.message` and `.key` (opaque, redacted repr); `BraveApiSearch(key, *, transport=None)` taking the loader's `.key`; `FallbackSearch(primary, fallback)`; owner mismatch via `os.geteuid`. Request path `/res/v1/web/search` with `text_decorations` false and `result_filter=web` — confirm against Brave's documentation and raise a mismatch with the reviewers rather than editing tests.
- **The smoke script's loader child** must tolerate the existing T2 rows' `uv` stub (exit 97, `STUB-UV-CALLED`), e.g. `2>/dev/null || echo "not configured"`.

- Plugs in only at `cli._search_backend` (T-0125 criterion 12's seam). `SearchBackend` and `SearchFailed` unchanged; `session.py` reads `last_engine` by `getattr` and already validates it.
- No threads or executors that can hold exit (see the `DdgsSearch` docstring). `httpx.AsyncClient`'s DNS may run on a worker thread: mirror `DdgsSearch`'s daemon-thread pattern with a sync `httpx.Client`, or prove the async path exits promptly with the criterion-11 row.
- httpx's `Headers.__repr__` redacts only `authorization`: never log or `repr` a request or headers object; hold the key in a wrapper with redacted `__repr__`/`__str__` and build the header at send time.
- Error detail is a closed set, never `str(httpx_exc)` or the body.
- Without a key return the bare `DdgsSearch` (not a pass-through wrapper).
- Budget: Brave client timeout 5 s, within the session's 10 s tool deadline; if keyless engines are slow to refuse the deadline can cut Brave off — accepted and recorded.
- `.claude/rules/tests.md`: a guard needs a row for being too wide; keep host, header and path strings out of docstrings in other modules (the fence counts raw text).
